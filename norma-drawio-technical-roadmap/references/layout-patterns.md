# 学术技术路线图版式库

确定骨架与配色时加载本文件。参考图不清晰、未提供参考图或参考图版式与内容不匹配时，按本文件选择默认版式。

## 默认配色

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 | `#4f46e5` | 主标题条、阶段标题条、强调卡片边框 |
| 强调色 | `#f59e0b` | 关键节点、成果节点、反馈回线 |
| 辅助色 | `#64748b` | 连线、次要说明文字 |
| 浅底蓝 | `#eef2ff` | 普通卡片填充 |
| 浅底灰 | `#f1f5f9` | 中性说明框、泳道填充 |
| 文字 | `#1f2937` | 深色底以外的一切文字 |
| 边框 | `#cbd5e1` | 泳道、分组框描边 |

同一张图内颜色数量不超过 5 种。「色随层变」用于区分研究阶段，「色随类变」用于区分内容类别，二者不同时用。

## 版式 A：纵向四段式

适用：课题申报书、教改项目、有清晰阶段推进的项目。

骨架：顶部主标题条 → 4 个横向分区，每分区左侧阶段标题条 + 右侧 2—4 个并列卡片 → 分区之间向下箭头。

画布 `850 x 1200`。坐标骨架：

- 主标题条：`x=40 y=40 w=770 h=60`
- 第 n 个分区容器：`x=40 y=140+(n-1)*250 w=770 h=210`
- 分区内阶段标题条：`x=0 y=0 w=180 h=210`（相对容器，作为泳道 startSize 区域外的独立卡片时改为 `x=60 y=...` 独立节点）
- 分区内卡片：`w=160 h=90`，`y` 相对容器 60，横向依次 `x=230`、`x=410`、`x=590`

## 版式 B：横向阶段泳道

适用：时间轴明确、每阶段有独立方法与产出的项目。

骨架：4—5 列泳道横向排列，每列自上而下为「阶段标题条 → 研究内容卡片 → 方法卡片 → 产出卡片」，列间向右箭头。

画布 `1169 x 826`。坐标骨架：

- 主标题条：`x=40 y=40 w=1089 h=60`
- 第 n 列泳道：`x=40+(n-1)*270 y=140 w=250 h=560`
- 列内卡片（`x` 相对容器 `20`，`w=210`，`h=100`）：`y=70`、`y=190`、`y=330`、`y=460`

## 版式 C：中心辐射式

适用：一个总目标下设若干并列研究内容。

骨架：中心圆角矩形放总目标，四周 4—6 个内容卡片，向外再各接 1—2 个方法或成果子节点。

画布 `1169 x 826`。中心节点 `x=460 y=380 w=250 h=90`；上方卡片 `y=200`，下方卡片 `y=560`，左右卡片 `x=120` 与 `x=900`，统一 `w=200 h=90`。

## 版式 D：闭环循环式

适用：含迭代优化、反馈验证的方法类研究。

骨架：4 个节点按顺时针排列成环，环心标注研究主题，最后一条边用虚线从末节点回指首节点。

画布 `1169 x 826`。四节点 `w=220 h=100`：左上 `x=160 y=180`、右上 `x=790 y=180`、右下 `x=790 y=540`、左下 `x=160 y=540`；环心 `x=460 y=363 w=250 h=90`。

## 版式 E：分层塔式

适用：平台类、系统类项目，强调基础—技术—应用—验证的支撑关系。

骨架：4 层横向色带自下而上堆叠，宽度逐层收窄或等宽，层间用短箭头表示支撑方向。

画布 `850 x 1100`。第 n 层色带（自下而上 n=1..4）：`x=40+(4-n)*40 y=120+(4-n)*230 w=770-(4-n)*80 h=170`。

## 选择规则

| 条件 | 选版式 |
|---|---|
| 有明确阶段推进、每阶段多任务 | A 纵向四段式 |
| 阶段与时间轴强相关、每阶段有独立产出 | B 横向阶段泳道 |
| 一个总目标下并列几个研究内容 | C 中心辐射式 |
| 含迭代、反馈、闭环验证 | D 闭环循环式 |
| 平台或系统架构，强调层间支撑 | E 分层塔式 |
| 资料阶段多于 5 个 | A 或 B，合并相邻阶段后成图 |

## 版式对齐要求

- 同层节点尺寸一致，同一列的 `x` 相同，同一行的 `y` 相同。
- 分区之间留 20，节点之间留 20—30，页边距 40。
- 连线优先正交折线；能直连时不折；折点坐标取 10 的倍数。
- 需要表达反向作用或迭代时，只用虚线，不与主流程实线同色。
