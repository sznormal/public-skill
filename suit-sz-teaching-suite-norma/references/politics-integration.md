# 思政点 → 教学过程 映射

定义"教案教学过程如何根据课标《课程思政融入表》撰写"。教学过程不是孤立设计，
必须回溯课标思政点与素材。

## 一、权威来源

课标《课程思政融入表》是唯一权威来源，三列：

```
知识点 │ 思政融入点 │ 思政案例
─────────────────────────────
工业机器人坐标系 │ 工匠精神/标准意识 │ 高凤林35年焊枪零失误
```

教案工作流在"解析课程标准"步骤已把它抽成结构化数据，供每份教案引用。

## 二、映射流程（每份教案）

1. **取子集**：从思政表筛出本教案对应模块 / 知识点的行（按"单元名称"对齐课标模块）。
2. **定落点**：在该学时实训或讲解收尾处安排 ≥1 处思政落点（优先放在"三、实训N"或知识点讲解收尾），用 1~2 句话点出**思政融入点 + 该模块具体案例**。
3. **写栏目**：教案「思政融入」栏目填"思政融入点 + 思政案例"，须与思政表对应行一致。
4. **补素材**：行业数据 / 人物 / 事件优先取自思政表与课标"教学要求"；需补充时按课标工作流的检索兜底规则处理（标注来源、经确认）。

## 三、合格句式

> **教学过程落点**：在"三、实训2：XXX 装配"结束后，结合课标思政点【工匠精神/标准意识】，引用案例【高凤林 35 年焊枪零失误，以微米级精度守护航天发动机焊缝】，引导学生体会"标准即生命、细节定成败"。

> **教案思政栏目**：思政融入点：工匠精神、标准意识；思政案例：高凤林 35 年焊枪零失误（来源：课标《课程思政融入表》）。

## 四、反模式（督导重点查这些）

- ❌ **空喊口号**：只写"培养学生工匠精神"却不落到具体案例与知识点。
- ❌ **脱离课标**：教案思政案例与课标思政表对不上（张冠李戴或自创未确认案例）。
- ❌ **教学过程无思政落点**：「思政融入」栏目有内容，但"教学过程"正文全程未见思政嵌入，两者割裂。
- ❌ **覆盖不全**：课标思政表 N 行，教案集合只覆盖其中 M 行（M < N），存在未落实的思政点。
- ⚠️ **案例无来源**：引用检索来的案例但未标注来源、未经使用者确认。

## 五、督导核对口径

督导流程会：① 统计课标思政表行数；② 逐行确认是否在教案「思政融入」栏目或教学过程落点中出现；③ 输出"思政点覆盖率"。
覆盖率低于 100% → 判 ❌，要求补齐。
