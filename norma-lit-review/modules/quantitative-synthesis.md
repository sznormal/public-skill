# 综述中的定量综合：可行性前置检查与可比性边界

> 适用：当综述需要「用数据说话」时——例如审稿人要求实验/实证组件、目标刊综述惯例附元分析、
> 或作者希望用定量对照替代纯定性罗列。
> 本模块解决两个问题：**① 手上的语料到底能不能支撑定量综合？② 哪些量可以跨域比较？**
> 实测来源：机器视觉应用综述（131 条被引）做元分析组件的全过程，2026-10-02。

---

## 一、先跑探针，再动手（不可跳过）

**核心教训：直接开做「跨域性能元分析」是一次方向性误判，探针在 10 分钟内拦下了它。**

探针要回答三个问题，缺一不可：

| 检查项 | 测什么 | 脚本化做法 |
|---|---|---|
| **A. 摘要可得性** | 有多少条文献能拿到摘要？ | arXiv API 批量 → S2 batch → OpenAlex → Crossref 逐级兜底 |
| **B. 指标可得性** | 有摘要的里面，有多少条**报告了可抽取数值**？ | 严格指标正则 + 宽松「数字+单位」双口径对照 |
| **C. 取样层级** | 数值命中是否按**文献类型**分布？ | 按 `tag`（CORE/FOUNDATION/REVIEW/FRONTIER）分层统计命中率 |

**判定闸门**：`B 的命中数 < 25` 或 `C 显示命中集中在少数类型` → **停止原方案，改口径**。

### 通道实测（2026-10-02）

| 通道 | 能力 | 坑 |
|---|---|---|
| arXiv API（`export.arxiv.org/api/query?id_list=`） | 一手题录+摘要，**批量 50/次**，免费 | 须 sleep ≥3s；摘要只有预印本版 |
| Semantic Scholar `paper/batch` | 批量 100/次，含 abstract | **易返回 429**，须退避重试 |
| OpenAlex `works/doi:` | `abstract_inverted_index` 倒排还原 | 逐条请求，0.15s 间隔 |
| Crossref `works/{doi}` | 部分出版商随题录给 abstract | 覆盖率低；**Elsevier/Springer 多数不存** |

> Crossref 与 OpenAlex 对 Elsevier/Springer 的记录**常不存摘要**（`abs=0`），这不代表该文无摘要。

## 二、硬结论：综述摘要不报数值

**这是本模块最重要的一条。** 实测分布：

| 文献类型 | 有摘要 | 含可抽取数值 | 命中率 |
|---|---|---|---|
| `CORE`（原始方法论文） | 36 | 8 | 22.2% |
| `FOUNDATION`（奠基论文） | 30 | 8 | 26.7% |
| `FRONTIER`（前沿工作） | 22 | 2 | 9.1% |
| **`REVIEW`（综述）** | **34** | **1** | **2.9%** |

综述摘要的句式是「本文梳理了…」，原始论文摘要的句式是「在基准 X 上达到 Y」。
**被引主体是综述的语料，做性能元分析等于在错误的层级取样。**

**推论（可操作）**：
- 定量综合的**取样单元必须是原始方法论文**（CORE / FOUNDATION），不是综述。
- 若被引集合中原始论文不足，**去筛选池里补**（未引用的 CORE/FOUNDATION 记录），
  补进来的同时也就成了新增参考文献——一举两得。
- 补完后若仍不足阈值，**不要硬做**，改做「代表性定量对照」并显式声明抽样性质。

## 三、可比性边界：先判定什么能比、什么不能比

**第二重障碍不是样本量，而是口径不可通约。**

| 轴 | 是否可跨域 | 说明 |
|---|---|---|
| **精度** | ❌ **不可** | 检测用 mAP、分割用 Dice/IoU、分类用 top-1、机器人用任务成功率。即便同名（如 accuracy），承载的**基准与任务定义也不同**——ImageNet 千类分类的 accuracy ≠ 缺陷二分类的 accuracy。 |
| **效率** | ✅ **可** | 参数量 / FLOPs / 延迟 / FPS / 吞吐，有统一物理口径 |
| **规模** | ⚠️ **部分** | 数量可比，但**计数单位常不统一**：工业/农业按「图像数」、医疗按「图像—掩码对」、机器人按「示教轨迹数」。单位不一致即不可直接比较。 |

**判定方法**（可复算）：把各域报告的指标名称做成集合，算**两两 Jaccard 重叠**。
实测机器视觉六域共出现 8 类精度口径，**平均两两重叠仅 39.2%**。

**写作口径**：把这条判定本身写成显式结论（「可比性边界」），而不是隐含假设。
好处：（1）跨域结论免于口径混杂；（2）为研究缺口提供文献计量层面的证据；
（3）主动回应审稿人「你为什么不做跨域性能对比」的质疑。

### 重构后的组件模板

放弃「跨域比精度」后，改为做数据支持得住的三件事：

| 子节 | 内容 | 典型产出 |
|---|---|---|
| x.1 | 分析口径与可复现性说明 | 数据来源 / 取值纪律 / 已知局限 |
| x.2 | **证据密度**：定量证据的域间不均衡 | 表：各域「报告定量结果的文献 ÷ 可获摘要的文献」+ 图 |
| x.3 | **可比性边界一**：不存在跨域统一的精度轴 | 表：口径覆盖矩阵 + Jaccard 重叠 + 图 |
| x.4 | **可比性边界二**：效率/规模可比但单位不统一 | 表：代表性方法的效率—精度对照 + 数据集规模表 + 图 |
| x.5 | 小结：回填缺口矩阵 | 指出该结果支撑哪个 G |

## 四、数据纪律（四条，不可违反）

1. **单一取值来源**：只从题录的公开摘要取值。**不采二手综述里的转引数字**——
   转引链路无法核验，且常出现口径漂移。
2. **不换算、不推算、不补全**：摘要没报的**留空**，不以「典型值」「常见范围」填充。
   表里的「——」就是原文没有。
3. **逐行留痕**：数据文件每行带 `vid`，任意单元格可回到原文复核。
4. **已知局限必须写进正文**：摘要层面统计是**代理指标**（定量结果多存于正文/图表/补充材料）；
   代表性抽样而非穷举；结论定性为**趋势判断**而非普查结论。这三句不写，审稿人一定会问。

## 五、数据核验三层闸（表格写进论文前必跑）

**最危险的一类错误：凭印象写下的可核验标识符，以及「看起来对」的名称与数值。**
只查「vid 是否存在」远远不够——三层错误各自都能漏网：

| 层 | 查什么 | 能抓到什么 | 脚本 |
|---|---|---|---|
| **L1 存在性** | vid 是否在筛选集中 | 编造的可核验标识符 | `verify_vids` |
| **L2 名称对应** | 该 vid 的题录标题是否对应表中名称 | **张冠李戴**：vid 真实存在却指向另一篇文献 | `verify_names` |
| **L3 数值回验** | 表中每个数值能否在该 vid 摘要原文找到 | 数值源自正文/转引而非摘要；单位书写不一致 | `verify_numbers` |

### L1 存在性（实测抓到 5 个编造标识符）

| 误写 | 正确 | 文献 |
|---|---|---|
| `arXiv:2110.02178` | `arXiv:1905.02244` | MobileNetV3 |
| `arXiv:2409.07736` | `arXiv:2608.07984` | AgriField-40K |
| `arXiv:2110.05074` | `arXiv:2112.01059` | Stronger Baseline for Person Re-ID |
| `arXiv:1910.08707` | `DOI:10.1109/cvpr.2019.00982` | MVTec AD |
| `arXiv:2308.16184` | `arXiv:2304.12306` | Segment Anything in Medical Images |

做法：取出表格/正文中所有手写的 vid → 逐个比对 `screened_records.json`。
记录不存在 → 硬失败，按题名回查正确 vid；记录存在但未引 → 判定为「新增参考文献」。

### L2 名称对应（实测抓到 1 处张冠李戴）

做法：取该 vid 对应题录的 `title`，与表中方法名 / 数据集名做归一化比对，不命中即报出。

实测：表中把 `SAM-Med` 写成数据集名，其 vid 指向的题录是 *Segment Anything in Medical Images*——
该文提出的**模型**叫 MedSAM，摘要中并**没有**名为「SAM-Med」的数据集 → 属命名张冠李戴，改为「MedSAM 训练数据集」。

> **须区分两类"不命中"**：① **真错**（名称指向别的对象，如上例）；
> ② **正常差异**（方法名 / 数据集名 ≠ 论文标题，如 UniAD → *A Unified Model for Multi-class Anomaly Detection*、
> Polytrack → *…Pollination Monitoring…*、SA-1B → *Segment Anything*）。**脚本只负责报出，判定必须人工。**
>
> 另注：同一 vid 可被两行复用且**均为正确**——如 OpenVLA 一篇摘要同时报告了模型（7B VLA）与其训练集
> （Open X-Embodiment，970k 示教）。此时行名宜写成「Open X-Embodiment（OpenVLA 训练集）」并在表下加来源注。

### L3 数值回验（最容易被忽略）

本文自设纪律是「仅记录摘要原文显式出现的数值」。**把这条纪律脚本化**：
把表中每个数值 token 拿到对应摘要里检索，未命中即报出。

**必须做单位归一，否则假阳性会淹没真错误**：

| 摘要写法 | 表中写法 | 归一方式 |
|---|---|---|
| `11M` / `970k` / `1B` | `11000000` / `970000` / `1000000000` | k/M/B → ×10³/×10⁶/×10⁹ |
| `third place` | `第 3 名` | 序数词 → 数值 |
| `5,354` | `5354` | 剥离千分位逗号 |
| `YOLOv4` / `SAM 2` / `RT-2` / `top-1` | 同左 | **版本号/序号须先排除**，不参与核验 |

归一后实测：27 项方法 + 8 个数据集**未命中归零**，全部数值 100% 可回溯至摘要原文。

> 摘要来源需覆盖**全部被引 vid**：新增引用的文献往往不在最初抽取的语料文件里，
> 须从储备池（`*_pool.json`）等文件合并摘要，否则会误报「无摘要」。

**三层都通过，表格才能进论文。**

## 六、常见反模式

| 反模式 | 后果 | 正确做法 |
|---|---|---|
| 用综述语料做性能元分析 | 样本虚高实则 3% 可用，表里全是「——」 | 先跑探针 C，取样单元换成 CORE/FOUNDATION |
| 把不同域精度数值并列排序 | 口径混杂，审稿人一问即倒 | 显式声明精度轴不可跨域，改用效率/规模轴 |
| 用「典型值」补全缺失项 | 编造，违反不编造原则 | 留空，并在正文说明缺失原因 |
| 引二手综述里的数字 | 转引链不可核验、口径漂移 | 只从原始文献摘要/正文取值 |
| 表格 VID 凭印象写 | 静默错误，无门禁拦截 | 写入前跑 VID 真伪核验 |
| 图序按设计顺序而非引用顺序 | 图 3 在 6.4.3、图 4 在 6.4.2，编号倒挂 | 按**正文首次引用顺序**编号，生成后回读核对 |
| **组件在独立文档里自编号，并入正文时不重排** | 图表号倒挂：表 8 出现在表 12 之后、图 2 出现在图 5 之后 | 并入前按**正文首次出现顺序**重排全部图表号；同步改引用、题注、图件文件名与 SVG 内标题 |
| 组件正文写「样本为本文**全部 N 条**被引」 | 并入后全文总数变大，口径自相矛盾 | 改写为「正文第 X—Y 章的 N 条核心文献（本节另列来源不计入分母）」 |
| 从题录抄年份手工填表 | 表格年份 ≠ 参考文献年份（预印本年 vs 正式版年常差 1—4 年） | **年代由题录层自动注入**（覆盖层 > 筛选记录），不手写 |
| 重命名产物但未改生成脚本的写出路径 | **影子文件**：脚本一直更新旧名文件，人一直在读新名旧文件，两边都不报错 | 重命名后立即全局搜旧名；产出后比对 mtime（数据源应早于产物） |

## 七、与既有流程的接口

- **前置依赖**：`modules/verified-retrieval-protocol.md`（题录与摘要的取得通道、DOI 双轨）
- **输出下游**：P4 分析（`gap_summary.md`）——本模块结论是缺口矩阵的定量证据；
  P5 撰写（新增一节，通常挂在「范式提炼」章之后、「研究缺口」章之前）
- **门禁归属**：数据核验三层闸（L1 存在性 / L2 名称对应 / L3 数值回验）应并入交付前复检脚本
  （与引用一致性、字数闸门并列）
- **字数影响**：一个完整组件约 2,500—2,800 汉字 + 4 表 + 3 图。
  **T1 中文目标上限 15,000 字，并入前须核对余量**；不足时优先精简表格行数（每域留 2—3 条代表）。
  实测一例：并入后正文 14,988 → 17,733 汉字（超目标上限约 18%，未触流水账红线 25,000）——
  此时应把**篇幅门禁改为红区分级**（<8,000 FAIL / 8,000—15,000 OK / 15,000—25,000 WARN / >25,000 FAIL），
  而不是让单点阈值把合规稿判负。

### 并入正文的固定动作（实测清单）

1. **先腾编号**：把后续章节的图表号整体后移，为新组件腾出连续编号空间
   （参考 + 题注 + 图件文件名 + SVG 内标题四处同改）。
2. **再插入**：组件插在目标章末、下一章标题之前；写入脚本须**幂等**
   （检测到目标章节已存在即退出，防重复插入）。
3. **同步导航**：摘要结论句、贡献陈述、章节组织结构三处一并更新，否则全文自相矛盾。
4. **改口径**：组件内所有「全部 N 条」类绝对计数改为相对表述。
5. **重跑全链**：finalize（重编号 + 重排题录）→ verify（全量门禁）。
6. **验收**：图表编号序列须与正文出现顺序一致；无孤儿题录（新增引用已进正文）。
