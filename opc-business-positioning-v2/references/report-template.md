## 报告生成规则

- 所有表格和字段必须填实，未确认的内容标记「待验证」而非留空
- **铁律：所有象限标注必须使用完整格式「Q1/Q2/Q3/Q4 第X象限 XX虚拟/XX实体」**
- 一句话定位的五要素句式锁定，一字不能改
- 「怎么赚」板块内容来自第一问/第二问/第三问
- 「凭什么」板块内容来自第四问/第五问
- 「服务谁」板块内容来自第六问/第七问/第八问
- 「定价与收费」板块内容来自第九问
- 「差异化锚点」板块内容来自第十问
- 「黄金三角校准」三条边逐边判断，写明依据来源（Q几）和具体判断
- 「下一步行动」必须具体到本周可执行的一个动作
- **严禁使用 HTML table 标签做彩色卡片效果**——报告中所有内容统一用纯 Markdown 格式，段落之间用空行分隔，表格用 Markdown 原生语法

## 交付前自检清单

- [ ] 怎么赚：主象限、变现载体表格全部填实、象限适配度三维全部标注

- [ ] 服务谁：目标客户身份+所处阶段、客户画布六维表格全部填实、问题强度三维全部标注
- [ ] 黄金三角：三条校准边逐一标注状态+证据句+风险句+依据来源（Q几）+校准结论
- [ ] 一句话定位：五要素句式锁定，一字不能改
- [ ] 定价与收费：收费结构+首单价格带+验证状态均已填实
- [ ] 差异化锚点：锚点+一句话不同+获客钩子均已填实

- [ ] 表达检查：无虚构、无过度承诺、无空泛形容词、客户能听懂
