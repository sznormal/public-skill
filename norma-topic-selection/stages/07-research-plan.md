# P7 · 研究计划与投稿策略

> 目标：把 P0–P6 的结论汇成一份 2–4 页的开题/讨论材料 + 一条投稿路线。

## 一、研究计划七节（结构参考 `templates/research_plan.md`）

1. **研究背景与问题**——领域已做到什么、现有方法在哪失效、这不足为什么值得解决
2. **研究空白**——列 3–5 篇最近邻：它们解决了什么、还没解决什么、你新增什么
3. **研究问题与假设**——1 主 + 2–3 子 + 1–3 可证伪假设
4. **技术路线**——数据来源、方法流程、基线、对照变量、消融、主要与辅助指标
5. **预期贡献**——按方法/实证/理论/数据集/工程分类写，不笼统写"提高性能"
6. **风险与备选方案**——见下表
7. **投稿匹配**——2–3 本目标刊的契合说明、常见实验规模、撞题复查结论

## 二、风险—备选对照（必填）

| 风险 | 备选方案 |
|---|---|
| 真实数据不足 | 用公开数据或缩小场景 |
| 基线难以复现 | 换有代码和明确配置的基线 |
| 改进效果不显著 | 转边界分析/消融分析/效率研究 |
| 设备不可用 | 先仿真或离线实验 |
| 计算成本过高 | 缩模型、缩数据规模、用代理指标 |
| 撞题（动态风险） | 换角度表述/扩贡献/换刊，**按月复查门 E** |

## 三、时间表（默认，按实际实验类型调整）

| 阶段 | 周期 | 交付物 | 通过/止损判据 |
|---|---|---|---|
| P0 方向与出口 | W1–2 | scope_lock + venue_risk_table | 无同题撞题行 |
| P1 证据矩阵 | 与 P0 并行 | evidence_matrix ≥40 行 | <20 行则补读 |
| P2 双轴定位 | W2–3 | gap_candidates 8–10 个 | — |
| P3 六重门 | W3–4 | gate_record + nearest_neighbor | 筛到 1–2 个 |
| P4–P5 定型评分 | W4 | gap_statement + scorecard | ≥70 且无否决 |
| 方案设计 | W5–7 | 技术路线/基线/消融/pilot | 导师确认基线可得 |
| **P6 MVP（止损期）** | W8–13 | mvp_plan + 结果 | **止损线事前写好**，不达标即止损 |
| 主实验 | W14–23 | 主实验 + 消融 + 鲁棒性 + 机理解释 | 显著优于基线 |
| 写作投稿 | W24–27 | 初稿 → 组内内审 → 投出 | 内审通过 |

硬件采集、现场实验、长期数据采集需**额外预留周期**，不要照搬上表。

## 四、投稿策略

- **期刊匹配在 P0 锁方向、P7 定稿**——中间允许校准，但**不得反过来为迁就期刊改科学问题**；
- **会议探路 + 期刊深挖**：若计划拆两篇，必须存在**实质性增量**（方法明显推进或结论明显扩展），**禁止切香肠式重复发表**（各刊对重复发表与预印本政策不同，P0 已记录）；
- 撞题是**动态风险**：进入 P7 后仍需**按月复跑门 E**（目标刊近 3 月新文 + 预印本）。

## 五、产出

- `outputs/topic-selection/research_plan.md`（七节完整版）
- `outputs/topic-selection/proposal_outline.md`（2–4 页开题/讨论提纲）

## 六、Hard Stop（收尾）

交付前向用户确认：
1. 七节是否齐全、有无空节（空节必须写"待补"并列入后续任务）；
2. 风险—备选是否**每条都有可执行动作**（不是"再想想办法"）；
3. 撞题复查的日期与责任人是谁；
4. 学生是否理解：**计划允许缩小题目或转变问题**，遇到卡点先回来改计划，不要硬撑。

## 七、常见坑

- ❌ 计划写成"待做事项清单" → 计划要写**通过/止损判据**，否则没有决策点；
- ❌ 风险表写"注意沟通" → 每条风险必须绑定动作；
- ❌ 投稿策略临时决定 → 撞题是动态风险，拆两篇是计划，不是补救；
- ❌ 计划不写时间缓冲 → 硬件与现场实验超期是常态。
