# 个股持仓四灯信号监控工具 v1.0

## 设计来源

吸取 `etf-three-lights` v5.1 的 5 个优点 + 保留个股持仓管理的 4 个优势，整合为统一体系。

| 吸取自 etf-three-lights | 保留自个股持仓设计 |
|-------------------------|-------------------|
| 分层架构（前三灯个股级+第四灯市场级） | 多维数据（资金+估值+技术） |
| 分流检查（按持仓类型检查不同指数） | 操作语义（卖/等/持/买） |
| 红灯解除3日确认+进度追踪 | 触发逻辑对称（风控"任一"+确认"全部"） |
| 绿灯计数0-4+分级建议 | 冲突规则（就高不就低） |
| 计时器原则（第四灯只微调时机±1-2天） | — |

## 架构概览

| 灯号 | 名称 | 级别 | 触发逻辑 | 核心维度 |
|------|------|------|---------|---------|
| 第一灯 | 资金灯 | 个股级 | 任一触发（风控优先） | 主力3日净流向+委比+量比 |
| 第二灯 | 估值灯 | 个股级 | 全量判定（确认优先） | PE/PB 5年分位+ROE+安全边际 |
| 第三灯 | 技术灯 | 个股级 | 混合触发 | MA20方向+RSI+距止损线 |
| 第四灯 | 市场环境灯 | 市场级 | 分流检查+汇总 | 按持仓类型检查对应板块指数 |

## 四灯操作语义

| 灯号 | 操作 | 含义 |
|------|------|------|
| 红灯 | 立即减仓 | 风险信号明确，卖涨不卖跌 |
| 黄灯 | 不操作 | 密切监控，等待信号变化 |
| 绿灯 | 继续持有 | 基本面/资金面正常 |
| 蓝灯 | 可分批建仓 | 严重低估+主力回流+技术企稳 |

## 第一灯：资金灯（任一触发）

### 红灯（任一条件满足）

| 条件 | 量化阈值 | 说明 |
|------|---------|------|
| 主力3日累计净流出 | > 5000万 | 连续出货信号 |
| 委比+量比组合 | 委比<-50% 且 量比>1.5 | 放量偏卖，抛压重 |
| 板块3日跑输大盘 | > 5个百分点 | 板块资金撤离 |

### 黄灯（任一条件满足）

| 条件 | 量化阈值 | 说明 |
|------|---------|------|
| 主力单日净流出 | > 1000万 | 短期资金波动 |
| 委比偏卖但量比<1 | 委比<-30% 且 量比<1 | 缩量偏卖，抛压不重 |
| 距止损线 | < 10% | 接近风控边界 |

### 绿灯（全部条件满足）

| 条件 | 量化阈值 | 说明 |
|------|---------|------|
| 主力微幅流入 | > 0（净流入为正） | 资金面平稳 |
| 委比偏买 | > 0% | 买盘强于卖盘 |
| 量比<1 | 缩量 | 无放量抛压 |

### 蓝灯（全部条件满足）

| 条件 | 量化阈值 | 说明 |
|------|---------|------|
| 主力连续2日净流入 | 转正且持续 | 资金回流确认 |
| 委比 | > +50% | 强烈偏买 |
| 量比 | > 1.0 | 放量承接 |

## 第二灯：估值灯（全量判定）

### 红灯

| 条件 | 量化阈值 | 说明 |
|------|---------|------|
| PE 5年分位 | > 90% | 极度高估 |

### 黄灯

| 条件 | 量化阈值 | 说明 |
|------|---------|------|
| PE 5年分位 | 75%-90% | 偏贵 |

### 绿灯（全部条件满足）

| 条件 | 量化阈值 | 说明 |
|------|---------|------|
| PE 5年分位 | 25%-75% | 估值合理区间 |
| ROE | > 15% | 盈利能力达标 |

### 蓝灯（全部条件满足）

| 条件 | 量化阈值 | 说明 |
|------|---------|------|
| PE 5年分位 | < 10% | 极度低估 |
| ROE | > 20% | 高盈利能力 |
| 安全边际 | > 30% | 内在价值远高于市价 |

## 第三灯：技术灯（混合触发）

### 红灯（任一条件满足）

| 条件 | 量化阈值 | 说明 |
|------|---------|------|
| 跌破止损线 | 价格 < 止损价 | 风控硬触发 |
| MA20方向 | 向下 且 收盘<MA20 | 趋势走坏 |

### 黄灯（任一条件满足）

| 条件 | 量化阈值 | 说明 |
|------|---------|------|
| RSI | < 30 或 > 70 | 超卖或超买 |
| 距止损线 | < 5% | 极度接近风控边界 |
| MA20走平且价格在下方 | 方向斜率<0.1% | 趋势不明朗 |

### 绿灯（全部条件满足）

| 条件 | 量化阈值 | 说明 |
|------|---------|------|
| MA20方向 | 向上 | 趋势确认 |
| 收盘价 | > MA20 | 价格在均线上方 |
| RSI | 40-60 | 正常区间 |

### 蓝灯（全部条件满足）

| 条件 | 量化阈值 | 说明 |
|------|---------|------|
| RSI | 30-40 | 超卖回升区间 |
| MA5金叉MA10 | 短期金叉 | 启动信号 |
| 量能配合 | 金叉日量比20日均量>1 | 有量配合 |

## 第四灯：市场环境灯（分流检查+计时器）

### 持仓类型分流

| 持仓类型 | 检查指数 | 额外解除条件 |
|---------|---------|-------------|
| 金融 | 上证+证券板块指数 | 无 |
| 医药 | 上证+医药板块指数 | 无 |
| 消费 | 上证+消费板块指数 | 无 |
| 科技 | 上证+创业板+科创50 | 科创50连续3日无>3%跌幅 |
| 周期 | 上证+资源板块指数 | 无 |
| 港股 | 上证+创业板（恒生降级） | 无 |

### 第四灯判定规则

各指数阈值：
- **上证指数**: 收盘<MA120→红; 收盘<MA20(但>=MA120)→黄; 当日跌幅>3%→红, 1.5-3%→黄
- **创业板指**: 当日跌幅>5%→红, 3-5%→黄
- **板块指数**: 当日跌幅>4%→红, 2-4%→黄
- **科创50**: 收盘<MA120→红; 当日跌幅>5%→红, 3-5%→黄（仅科技持仓检查）

汇总规则：任一指数红→红灯；任一黄(无红)→黄灯；全绿→绿灯

### 红灯解除条件（需全部同时满足）

| 条件 | 检查方式 | 说明 |
|------|---------|------|
| 1. 上证连续3日收盘>=MA120 | 脚本自动 | 从最近一日往前数 |
| 2. 创业板连续3日无单日跌幅>3% | 脚本自动 | 从最近一日往前数 |
| 3. 连续3日主力资金净流入 | neodata查询确认 | 需查询两市主力资金 |
| 4. 科创50连续3日无>3%跌幅（科技持仓额外） | 脚本自动 | 仅科技持仓 |

### 计时器原则（吸取自 etf-three-lights）

- 第四灯是**计时器不是决策器**，只能微调已计划操作时机（±1-2天），不得推翻执行计划时间表
- 第四灯红灯 = 禁止新建仓（卖出不受限）
- 前三灯是个股级别（每只股票独立计算），第四灯是市场级别（统一判断大环境）

## 综合输出规则

### 绿灯计数（吸取自 etf-three-lights）

统计四灯中绿灯+蓝灯数量（0-4，蓝灯也算正面信号），输出分级操作建议：

| 绿灯数 | 操作建议 | 说明 |
|--------|---------|------|
| 4 | 可考虑加仓/持有 | 四重确认，趋势+估值+资金+环境全绿 |
| 3 | 继续持有，观望 | 三灯确认但尚有不足 |
| 2 | 谨慎持有 | 两灯确认，关注变化 |
| 1 | 观望，准备减仓 | 仅一灯亮，趋势不明 |
| 0 | 减仓/离场 | 全灭，趋势走弱 |

### 冲突规则（就高不就低，仅前三灯参与）

前三灯参与冲突判定，第四灯作为计时器独立运作，不参与冲突判定：
- 同时触发红灯和绿灯 → 取红灯（立即减仓）
- 同时触发黄灯和蓝灯 → 取黄灯（不操作）
- 蓝灯仅在全部条件满足时才触发，不存在与红灯冲突的情况
- 第四灯红灯不改变冲突灯判定，只附加"禁止新建仓+微调时机"提醒

### 灯变转换规则

| 转换路径 | 触发条件 | 说明 |
|---------|---------|------|
| 绿→黄 | 任一黄灯条件触发 | 正常降级 |
| 黄→红 | 红灯条件触发，或黄灯持续3日 | 升级预警 |
| 黄→绿 | 连续2日主力流入+委比转正 | 恢复确认 |
| 红→黄 | 已执行减仓后，主力流出收窄至单日-5000万以内 | 风险缓解 |
| 绿→蓝 | 连续2日主力流入+PE分位<10% | 加仓信号 |
| 蓝→绿 | PE分位回升至>10% | 估值修复 |

## 工作流程

1. 接收持仓标的列表（股票代码+止损价+持仓类型）
2. 对每只股票用 neodata-financial-search 查询：
   - 实时行情（价格、涨跌幅、委比、量比）
   - 主力资金流向（3日累计净流向）
   - 估值数据（PE/PB 5年分位、ROE）
   - 技术指标（MA20方向、RSI）
3. 按前三灯规则判定每只股票的灯号
4. 按持仓类型分流检查第四灯
5. 汇总四灯状态+绿灯计数，输出操作建议

## 使用方式

```bash
python scripts/four_lights.py --holdings "300059:17.22:金融,600276:50:医药,603605:0:消费"
```

参数格式：`代码:止损价:持仓类型`，多个用逗号分隔。止损价传0表示不设止损线。

## 数据获取

使用 `neodata-financial-search` skill 查询数据。注意：先用 `which python3 || which python` 确认系统可用的 Python 命令。

需查询的数据维度：
- 实时行情：价格、涨跌幅、委比、量比、成交额
- 主力资金：主力净流入、超大单、大单、3日累计
- 估值数据：PE(TTM)、PB、PE 5年分位、PB 5年分位、ROE
- 技术指标：MA20方向、RSI(14)、距止损线距离
- 板块数据：所属板块涨跌幅、板块3日涨跌
- 市场环境：上证/创业板/科创50/板块指数的MA120/MA20/当日跌幅

## 输出格式

JSON数组，每只股票包含：
- code, name, holding_type, latest_price, stop_loss_price
- capital_light（资金灯）: {status, reason, main_flow_3d, bid_ratio, volume_ratio}
- valuation_light（估值灯）: {status, reason, pe_percentile, pb_percentile, roe, safety_margin}
- technical_light（技术灯）: {status, reason, ma20_direction, rsi, dist_to_stoploss}
- market_light（市场环境灯）: {status, reason, applicable, index_details, relief_progress}
- green_count, conflict_light, advice

## 使用规则

1. **前三灯个股级，第四灯市场级**——每只股票独立计算前三灯，第四灯按持仓类型统一判断
2. **计时器原则**——第四灯只微调时机±1-2天，不推翻执行计划
3. **就高不就低**——多灯并存取最保守灯
4. **卖涨不卖跌**——红灯执行减仓时，选择反弹日卖出，不在下跌日割肉
5. **蓝灯分批建仓**——不一次性建仓，分3-4笔，每笔间隔2-3个交易日
6. **红灯解除需3日确认**——不靠单日信号翻转
7. **每日执行时间表**：
   - 09:25-09:30：查看集合竞价，预判开盘方向
   - 10:00-10:15：查第一波盘面数据，判定各灯
   - 11:20-11:35：上午收盘前复核，决定午后操作
   - 14:45-15:00：尾盘确认，记录收盘信号

## 与 etf-three-lights 的关系

- `etf-three-lights`：适用于 **ETF 趋势交易**（纯技术面，判断进出场时机）
- `stock-holding-lights`：适用于 **个股持仓管理**（多维数据，监控持仓风控）
- 两者可配合使用：ETF 用 etf-three-lights，个股用 stock-holding-lights
