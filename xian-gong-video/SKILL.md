# 云上仙宫 / 中式天庭 AI 视频生成

面向内容创作者的国风仙宫视频生产规则。源自三篇爆款拆解的共性提炼，重点不是"堆形容词"，而是把场景拆成可落地的物理位置，让 AI 照着"施工"。

## 核心认知（先读，决定成败）

1. **图片是命门。** 视频是图片的连续帧，能稳定复刻那张"图"，视频只是顺手的事。先死磕图，再谈视频。
2. **模型 > 提示词。** 模型是地基，提示词只是装修。同一套提示词换模型可能两码事。要复刻某张图，先搞清它用的什么模型——不知道模型，背下提示词也只是照猫画虎。主流三模型（GPT image / 即梦 5 Pro / Midjourney）对同一提示词输出可能完全不同。第四篇《7套天宫仙境提示词》实测用本地部署 **Z-Image Turbo**（中文长描述式提示词），再次印证这类强风格化仙宫图多为本地 ComfyUI / Z-Image 出图，用即梦 / Seedream / GPT 都能复刻，只是风格微调。
3. **"大"靠对比，不靠建筑本身大。** 巨物感来自人物与建筑的夸张尺寸反差——把人物占比用数字钉死：**仅占画面高度的 1% 至 2%**。只写"人物极小"不够，要写死比例。
4. **GPT 出图有致命伤。** 噪点重、破碎感强，拿去跑视频一糊就废。要跑视频优先选即梦 / Seedream。
5. **多场景靠"变量矩阵"，不靠重写。** 同一套万能公式，换「场景主体 / 框景 / 时段 / 人物行为 / 情绪」五个变量就能产出完全不同的仙宫图（见 Step 0）。要一批不同场景的图，先排组合再批量出，不要每张从零写。

## 反同质化：破单一的铁律（实测痛点）

测试中发现：按默认模板每张都"极低机位仰拍 + 古松框景 + 古装背影 + 冷蓝灰暖金 + 宋代审美 + 胶片颗粒"，出来的图像同一个模子——场景骨架像、人物像、味道像。根因是**把风格加成当必加项焊死了，变量矩阵列了却没真正轮换**。破局 5 条：

1. **机位必须轮换。** 机位是视觉差异最大的来源，绝不要每张都"极低机位仰拍"。轮换：极低仰拍 / 俯瞰云海 / 平视长廊 / 月洞门内望 / 长阶一点透视 / 半环绕（见 Step 0 机位列）。
2. **人物别永远背影。** 行为、姿态、数量都要换：并肩品茗、席地阅书、独行天梯、侧坐龙背、撑伞独立、仰望。背影只是选项之一，不是默认。
3. **风格加成最多挑 2 项。** "宋代山水审美 / 胶片颗粒 / UE5 写实 / 丁达尔光"是调味不是主料，全加必趋同。每次最多选 1–2 项，其余删掉（见 Step 3 模板标注）。
4. **相邻图至少换 3 个变量。** Step 0 矩阵六列，批量出时相邻两张至少 3 列不同（机位 + 主体 + 时段 是最低组合），否则看着雷同。
5. **模型混用破同款感。** 同一批图用 2 个模型出（如即梦 + Seedream / MJ），各自带不同"模型味"，立刻丰富。单模型批量必带同款感。

## 万能公式

主体明确 + 空间关系清楚 + 人物极小（占画面 1%–2%）+ 光影明确 + 材质真实 + 镜头质感 + 负面约束

## 工作流

### Step 0 — 选场景变量（多场景批量生成的关键）

要一次产出多张**不同场景**的仙宫图，先排变量矩阵再套模板，而不是每张从零写。六个变量各选一项组合 = 一张独特图；选 N 种组合 = N 张差异化图。

| 变量 | 可选项（挑一个） |
|------|----------------|
| **机位** | 极低机位仰拍 / 俯瞰云海全景 / 平视长廊纵深 / 月洞门内望 / 长阶一点透视推进 / 半环绕侧拍 |
| 场景主体 | 迎客松平台 / 满月露台 / 藏书阁秘境 / 白玉长桥 / 钟楼拱门 / 苍龙遨游 / 中央仙宫群 / 天瀑神树峡谷 / 蓝金巨殿 / 金龙穹顶天门 / 镜面长廊 / 龙柱天桥 |
| 框景 | 古松横亘天然框 / 立柱飞檐画框 / 连续拱门环绕 / 圆形月洞门 / 长阶一点透视 / 无框全景 |
| 时段 | 清晨暖光 / 晨昏柔调 / 日出丁达尔 / 夜空星点 / 满月夜 |
| 人物行为 | 独立远望 / 并肩品茗 / 席地阅书 / 独行天梯 / 侧坐龙背 / 撑伞独立 |
| 情绪 | 空灵清冷 / 庄严神圣 / 书香气韵 / 巨物震撼 |

**用法**：把每列变量代入 Step 3 模板的对应槽位即可。例：『满月露台 + 圆形月洞门 + 满月夜 + 并肩品茗 + 空灵清冷』= 一张差异化图。完整可抄组合见 `references/prompts.md` 第五节 7 套 + 第六节云宫仙阙 6 组。

**避坑**：每张图至少改 **3 个变量**（如机位 + 主体 + 时段），否则容易雷同（见翻车点）。

### Step 1 — 定主题与场景要素

明确六要素：机位、巨构建筑类型、人物设定、环境、光影方向、框景元素。从 `references/prompts.md` 的范例里挑一组最接近的当底，改要素而非重写。

### Step 2 — 选模型与比例

- **先确认目标模型。** 复刻某张爆款图前，先搞清它用的什么模型；不知道模型就照搬提示词只是照猫画虎。这类强风格化图大概率是本地 ComfyUI 出的，但用下面的模型都能复刻。
- 比例锁 **21:9**（电影宽屏，纵深感关键，不要改 16:9 裁剪）。
- 生图首选：**即梦 5 Pro / Image 2.0** —— 光影更柔、质感更稳，超大全景与超远景深"撑得开、冲得狠"，最适合仙宫巨构；或 **豆包 Seedream 5.0 Pro**（效果佳、人物占比控制好）。
- 生图慎选：**GPT-image2** —— 强模型，但做"视觉庞大"的仙宫有绕不开的噪点 / 破碎感，一跑视频就糊；若坚持用，出图后转即梦 / Seedream 再跑视频。可试 **Midjourney**（风格化强）。
- 本地部署：**Z-Image Turbo**（第四篇 7 套实测模型，中文长描述式提示词最适配；本地 ComfyUI 部署，可完全复刻，无云端限制）。
- 视频：**Seedance 2.5**（付费，21:9，5 秒）或 **2.0**（免费）；追求更好效果用 **即梦 / 可灵** 付费。

### Step 3 — 写生图提示词（套模板）

套用下方模板，将 `[ ]` 替换为具体场景，最后接负面约束。写完自检：有没有"唯美 / 震撼 / 梦幻"这类虚词？有就拆成物理位置重述（柱在哪、桥在哪、人站哪、光从哪来）。构图要点：让建筑占满画面中心、人物压在画面下方偏下，压迫感与巨物感最强（参考 `references/prompts.md` 第三节对称柱廊写法）。

**两种提示词写法（都可用，按模型选）：**
- **英文短词式**（即梦 / 海外模型）：上述模板，结尾接英文负面约束。
- **中文长描述式**（Z-Image Turbo / 豆包 / 即梦中文）：不堆形容词，按"机位 → 建筑主体 → 纵深雕饰 → 人物作尺度锚点 → 环境 → 光影色彩 → 最高细节分层 → 材质 → 避免项"顺序写满物理位置。第四篇 7 套即此风格，可整段抄（见 `references/prompts.md` 第五节）。

**构图与写实手法（来自第四篇 7 套实测，强烈建议照做）：**
- **框中框**：用拱门 / 栅格 / 半圆拱在画面边缘裁切，强化峡谷 / 长廊的巨型尺度。
- **中轴对称**：长廊、天顶、天门用严格对称，所有结构线向中央主殿 / 天缝汇聚。
- **一点透视**：长阶 / 天梯直通远方主殿，纵深感拉满。
- **人物作尺度锚点**：压在画面下方 / 下沿、背对镜头、占画面 1%–2%，只承担尺度与生活感，不抢主构。
- **空气透视分层**：最高细节集中在前景主构（中央仙宫 / 巨殿立面 / 双龙穹顶），远景经云雾与空气透视降低对比、退入薄雾。
- **仙宫配色体系**：深青琉璃瓦、暗红立柱、白玉台基 / 栏杆、蓝金立面（深蓝 + 嵌金龙凤云纹）、钴蓝天空、奶油白云顶、冷蓝灰云底；主光一侧暖金、背光清冷蓝灰，不用无来源轮廓光。
- **画幅**：原文多为 16:9；走 GUMIHO 视频分发改 **21:9**，纯出图可保留 16:9。

> **生图提示词模板**
> [机位，必轮换] 任选 Step 0 机位之一（**不要永远极低仰拍**），[巨构建筑] 悬浮于无尽云海之上，[建筑细节/纵深/雕饰]，[人物] 极微小、仅占画面高度 1%–2% 立于 [位置]（**姿态行为从矩阵选，不默认背影**），[框景，从矩阵选] 任选框景之一（古松仅为选项之一），[环境] 云海翻涌、体积雾/薄雾弥漫；[光影] 冷蓝灰天空与云海，暖金晨光/夕阳从侧后方逆光透出，[镜头] 24mm 超广角、低机位宽画幅、电影摄影、超远景深，[材质] 真实白玉/石材/木构/古松/云海质感，[审美，可选·最多2项] 宋代山水审美（与胶片颗粒二选其一即可，不必齐加），空旷、宁静、神圣、庄严，[质感，可选] 细微胶片颗粒（或 UE5 写实渲染）。[负面约束]
>
> ⚠️ **风格加成是调味不是主料**：宋代审美 / 胶片颗粒 / UE5 写实 / 丁达尔光 每次最多挑 1–2 项，全加必导致所有图"一个味"。机位、框景、人物姿态必须按 Step 0 矩阵轮换，否则图必然单一（见"反同质化铁律"）。

**多场景批量生成**：将 Step 0 变量矩阵每列选项代入上方模板槽位——`[机位]` 从机位列选（必轮换）、`[巨构建筑]` 对应场景主体、`[人物]` 对应人物行为、`[审美]` 对应情绪。批量产出 N 张时，保证相邻两张至少 **3 个变量**不同（机位 + 主体 + 时段 是最低组合）。走 GUMIHO 分发时统一改 21:9。

### Step 4 — 图生视频提示词（四段式）

按"保留原图主体 + 动态效果 + 运镜方式 + 风格氛围"四段写，动作要轻、画面要稳：

> **图生视频提示词结构**
> 保留原图主体：[列出建筑 / 人物 / 环境]
> 动态效果：[云海翻涌、衣袍随步伐摆动、飘带拂动、仙鹤滑翔、薄云掠过满月、地面倒影晃动]
> 运镜方式：[从牌坊/拱门中间缓慢推进 / 横向平移跟拍 / 轻微环绕 / 向下摇移，始终保持画框构图]
> 风格氛围：[神圣庄严 / 温润雅致 / 清冷仙气]，电影级自然光影，画面平稳无畸变

### Step 5 — 剪辑与交付

剪映拼接所有片段；加 **丁达尔光线 / 梦幻辉光** 特效；配古风 BGM（如《壁上观》）；能卡点更带感。成品走分发流程，配四平台差异化文案。

## 负面约束（二选一，必加）

- 英文版（即梦 / 海外模型常用）：
  `no text, no watermark, no black bars, no neon, no glow effects, no 3D render, no CGI`
- 中文版（豆包 / Seedream / Z-Image 常用）：
  `低画质，模糊，变形，扭曲，人物比例过大，石阶过短，石墙矮小，现代建筑元素，杂乱多余物体，污渍破损，比例失调，透视错误，面部崩坏，多余肢体，水印，文字，锯齿边缘，卡通，二次元，手绘，昏暗`
- 中文"避免"长段（第四篇实测 negative，覆盖更全，可直接做 negative prompt）：
  `现代城市，科幻飞船，西方城堡，网游UI，发光法阵，过度金碧辉煌，满屏光效，建筑变形，人物正脸，多人群像，文字，字幕，标志，水印，圆形播放按钮，视频界面，进度条，塑料CG，过锐纹理，云海变海水，全画面金色滤镜，玻璃幕墙，赛博朋克，鲜艳彩虹，强烈发光特效`
- 反向提示词（第五篇云宫仙阙实测，即梦 / MJ / SD / Nano banana 通用，必清 PANACEA 水印）：
  `文字，PANACEA 水印，logo，畸形树木，扭曲人物，残缺肢体，模糊，低清晰度，二次元，卡通，鲜艳高饱和色彩，飞鸟，山石，地面泥土，杂乱杂物，画面裁切，多余人物`

## 翻车点与止损

- **虚词翻车**：删"唯美 / 震撼 / 梦幻"，改写物理位置（柱在哪、桥在哪、人站哪、光从哪来）。
- **没"感觉"**：多次抽卡直到出氛围感，比例坚持 21:9；一个模型不满意就换另一个（提示词可能更适配下一模型）。
- **人物太大**：巨物感消失，重写出"占画面 1%–2%"，并压在画面下方 / 下沿作尺度锚点。
- **配色翻车**：全画面金滤镜、云海变海水蓝、宫殿像现代摩天楼 / 玻璃幕墙 / 赛博朋克 → 退回深青 + 暗红 + 白玉 + 蓝金体系，主光暖金、背光冷蓝灰。
- **多场景雷同（最常见翻车）**：每图只换主体、机位/框景/时段全没动 → 图看着一模一样，像同一个模子。破局：① 机位轮换（别永远极低仰拍）；② 人物姿态行为轮换（别永远背影）；③ 风格加成（宋代审美/胶片颗粒/UE5）每次最多挑 1–2 项，别全加；④ 相邻图至少换 **3 个变量**；⑤ 同一批图用 2 个模型出破同款感（见"反同质化铁律"）。
- **GPT 噪点**：换即梦 / Seedream 出图，再跑视频。
- **免费 vs 付费**：免费别追求太多；要质感用即梦 / 可灵付费。
