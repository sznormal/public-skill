## 需求

选取参考文献时，按综述类型提供选取理由，让用户确认或修改——即 P3 结束处
新增一道人工把关：**未获明确确认不得进入 P4**。

## 改动明细（4 个文件）

### 1. stages/03-screening.md（主要改动，§五 Hard Stop 重写）

- **理由口径按 T1–T5 分流**，格式统一为「类型专属维度 + 可验证事实」，
  明确列出无效理由（"重要文献""被引很高""与主题相关"等空洞表述）：

| 类型 | 合法理由维度 |
|------|------|
| T1 叙述性 | 主题覆盖（每子主题≥1篇代表）+ 路线代表性 + 时间代表性（奠基+前沿两端）+ 权威出处 |
| T2 系统综述 | **逐条对照纳排条款**（引用条款编号）；纳入数与 PRISMA 流程图一致 |
| T3 范围综述 | 概念/证据图谱覆盖 + 证据类型多样性（含灰色文献）+ 服务缺口识别 |
| T4 文献计量 | 只认计量清洗决策（去重/合并/修正规则），不按相关性挑 |
| T5 批判性 | 论点支撑 + **反方代表强制在场** + 争议里程碑文献 |

- **展示格式**：筛选漏斗数 + 聚类树 + 逐篇（逐组）理由清单 + 红旗自检
  （自引/同团队 >20%、来源单一、年龄断层、孤儿文献——命中须说明或整改）
- **用户四选项**：全部确认 / 删除某篇（记理由；删后子主题失去覆盖则提示补搜）/
  补充文献（走 P2 补搜+雪球后回到本确认点）/ 调整理由
- **留痕**：增删与确认全部写入 `screening_decisions.md`（决策阶段=「用户确认」）；
  未确认前 HUD `literature.final_selected` 不得写入
