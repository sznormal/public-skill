# 候选空白池模板（P2）

> 目标：产出 8–10 个候选，每个标定**竞争地形 + 空白性质 + 支持证据**；收敛到 2–3 个进 P3。

## 一、双轴速查

**轴一 · 竞争地形**：🔴热点饱和（慎入）/ 🟠方法升级（友好）/ 🟢空白·交叉机会（首选，先验真）/ ⚪冷门停滞（过三问闸）

**轴二 · 空白性质**：证据 / 知识 / 方法 / 实证 / 情境 / 评价 / 理论 / 工程约束

⚠️ **顺序不可颠倒：先定地形，再判类型，最后进 P3 验伪。**

## 五、交叉机会区专项：机理相容铁律

对每个交叉类候选填一条：

- [ ] 物理相容：场景物理量与方法假设一致
- [ ] 几何/结构相容：方法结构假设与场景构型一致
- [ ] 计算相容：方法复杂度与实时性要求匹配

**三条都填不出 → 这题只能投应用类刊，或改做实证/约束空白。**
