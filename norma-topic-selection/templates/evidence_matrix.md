# 证据矩阵模板（P1）

> 建议 ≥40 行（文献条数）；**<20 行不要往下走**。所有格子必须有出处，未核实的写 `[待核：查什么]`。

| 文献 | 研究问题 | 方法 | 机理 | 数据/设备 | 场景条件 | 对照基线 | 评价指标 | 主要结论 | 证据强度 | 局限性(原文) | 未验证条件 | 可复现性 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| [作者年] | | | | | | | | | | | | |
| | | | | | | | | | | | | |

## 填写要点

- **机理**：方法成立的物理/数学/因果前提。留空 = 可能是纯拼装（P3 门 F 会卡）。
- **局限性**：摘**原文**，不要自己的概括。
- **未验证条件**：真实环境 / 跨设备 / 跨场景 / 少样本 / OOD / 低算力……
- **可复现性**：数据/代码/参数/设备是否公开。
- 建议用 Excel 或 Notion 维护，最终导出为同名 markdown 供脚本体检：

```bash
python scripts/matrix_lint.py outputs/topic-selection/evidence_matrix.md
```

## 三个挖掘动作（体检后手工做）

1. **看稀疏列**——脚本会标出空值率 ≥70% 的列，这些是候选矿脉的坐标。
2. **看矛盾格**——标出结论相反的文献对，逐对判断冲突来源（数据集/条件/指标/参数/版本/质量）。
3. **看孤证区**——只有一篇文献提出、缺乏独立验证的结论。
