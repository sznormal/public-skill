# 引用规范速查

> Norma理工科文献综述 · Module
> 加载条件：用户询问引用格式或 P5 阶段需要确定引用规范

---

## 一、GB/T 7714-2015（中文期刊通用）

### 期刊论文
```
[序号] 作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.
```
例：
```
[1] 张三, 李四. 基于深度学习的嵌入式视觉系统设计[J]. 电子学报, 2024, 52(3): 456-462.
```

### 会议论文
```
[序号] 作者. 题名[C]// 会议名称. 会议地点: 出版者, 年: 起止页码.
```

### 学位论文
```
[序号] 作者. 题名[D]. 城市: 学校, 年.
```

## 二、IEEE（英文工程类通用）

### 期刊论文
```
[序号] A. Author, B. Author, and C. Author, "Title," Journal Name, vol. x, no. x, pp. xxx-xxx, Month. Year.
```
例：
```
[1] J. Smith and L. Wang, "Real-time object detection on embedded platforms," IEEE Trans. on Industrial Electronics, vol. 71, no. 2, pp. 1234-1242, Feb. 2024.
```

### 会议论文
```
[序号] A. Author and B. Author, "Title," in Proc. Conf. Name, City, Country, Year, pp. xxx-xxx.
```

### arXiv 预印本
```
[序号] A. Author, "Title," arXiv:xxxx.xxxxx, Year.
```

## 三、理工科引用原则

### DO
- 优先引用一次文献（原始研究），少引二次文献（教科书、综述转引）
- 用数字序号引用（正文中的 [1]、[2-5]），方括号包围
- 多篇文献同时引用时按序号升序排列：[1],[3],[5-7]
- 技术论断必须有引用支撑

### DON'T
- ❌ 引用维基百科、博客、知乎作为技术论据
- ❌ "很多研究表明……" 不加引用
- ❌ 幽灵引用：参考文献列表有但正文从未提及
- ❌ 漏引：正文引了但参考文献列表没有
- ❌ 过时引用：用 10 年前的综述支撑"当前最新进展"

## 四、引用管理提示

P5 生成综述时，自动：
1. 正文引用处标记文献 ID
2. 生成参考文献列表时按引用出现的先后顺序编号
3. 同时输出 `.bib` 文件（BibTeX 格式），可直接导入 Zotero/EndNote

---

## 五、❌ 真实性红线（P6 会逐条联网核验）

以下任何一项出现，该参考文献视为**不合格**，必须修正/删除后才可提交：

- ❌ **占位符编号**：`arXiv:2409.x` / `arXiv:24xx.x`（`.x` 后缀一律无效，必须填完整号）
- ❌ **编造作者**：`Anonymous`、无依据的首字母缩写推断（如 `Z. Zhang et al.` 无来源）
- ❌ **推断标题**：根据正文内容"猜"出的论文标题，未在 arXiv/DOI/Crossref 核实
- ❌ **未证实 venue**：标了 `ICRA 2025` / `NeurIPS 2024` 但无法在 OpenReview/官网核对
- ❌ **技术报告冒充论文**：把公司系统/博客写成正式署名论文

> 正确做法：引用编号/标题/作者/venue **必须来自 P2 已核验的 `verifiable_id`**，
> 或经 P6 WebSearch 联网确认。每一篇都应是"能搜到、能对上"的真实发表物。
