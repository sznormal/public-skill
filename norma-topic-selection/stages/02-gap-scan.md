# P2 · 空白扫描与双轴定位

> 目标：把证据矩阵里的信号变成 **8–10 个候选空白**，并为每个候选标定"地形"与"性质"。

## 一、双轴分离（顺序不可颠倒）

| 轴 | 回答什么 | 取值 | 来源 |
|---|---|---|---|
| **轴一：竞争地形** | 这片地有多挤？还剩多少时间窗？ | 🔴热点饱和 / 🟠方法升级 / 🟢空白·交叉机会 / ⚪冷门停滞 | 本文下表 |
| **轴二：空白性质** | 这洞是什么性质？决定研究方法与叙事模板 | 8 类 | `modules/gap-taxonomy.md` |

**先定地形，再判类型，最后进 P3 验伪。** 反过来（先归类再想挤不挤）是学生最常栽的跟头——"我这是个漂亮的理论空白"经常等于"冷门停滞区，没人要"。

### 竞争地形四区

|  | 方法趋同度高 | 方法趋同度低 |
|---|---|---|
| **发文热度高** | 🔴 热点饱和区：无硬创新慎入 | 🟠 方法升级区：改进型选题，友好度高 |
| **发文热度低** | ⚪ 冷门停滞区：先过"三问闸" | 🟢 空白区 / 交叉机会区：首选，先验真 |

判定数据来自 P1 矩阵：逐列统计指标趋同度、统计近三年发文密度与年份分布（拐点后 1–2 年为窗口期）。

## 二、空白性质 8 类（速查）

| 类型 | 典型问题 | 常用方法 |
|---|---|---|
| 证据空白 | 不同论文结论不一致 | 复现、对比实验、元分析、统一评价 |
| 知识空白 | 某重要问题缺少系统研究 | 探索性实验、调查、模型建立 |
| 方法空白 | 现有方法在本场景不适用 | 方法改进、方法迁移、结构设计 |
| 实证空白 | 只有仿真或理论，缺真实验证 | 真实设备、真实数据、现场实验 |
| 情境空白 | 只验证了单一场景 | 跨场景、跨设备、跨数据集 |
| 评价空白 | 指标不能反映真实目标 | 新评价协议、综合指标、基准测试 |
| 理论空白 | 现象存在但机制不清 | 理论分析、可解释性、因果实验 |
| 工程约束空白 | 效果好但成本/延迟/能耗不可接受 | 轻量化、部署优化、资源—性能权衡 |

**消歧三问**：缺结论 → 证据；缺机制 → 理论；缺手段 → 方法/实证。归为"理论空白"时必须能说出**要解释的具体机制**，否则多半是没做出来而非没做。

## 三、五条矿脉（候选空白来源）

1. **limitations / future work 高频抱怨 Top 5**——被反复吐槽还没解决的才是真缺口。但须回答：**为什么过去没被解决？解决它会改变什么结论或应用结果？**（Future Work 可能只是礼貌性展望或技术上不可行）
2. **应用域 × 方法矩阵空格**——横轴方法、纵轴场景，文献填格，**空格是候选线索不是自动成立的空白**
3. **矛盾结论与指标口径打架处**——缺统一基准或缺系统性研究
4. **孤证集中区**——结论多、单篇证据多的方向缺扎实验证
5. **时间拐点后 1–2 年窗口**——新硬件/新数据集/新政策出现后的发文突增拐点

## 四、⚠️ 交叉机会区专项：机理相容铁律

把 A 领域方法引入 B 领域场景（交叉机会区的典型形态）时，**必须回答"为什么非它不可"**——给出场景特性与该方法的物理/几何/计算契合机理。无脑的 A+B 缝合怪是审稿人最常见的拒稿理由。

## 五、⚠️ "为什么没人做"三问闸（落入知识空白或冷门停滞区时必过）

1. 是**做不出来**（技术/设备卡死）？
2. 是**做出来没人要**（没有使用场景、没有评价口径）？
3. 是**已经被证否**（老文献里早就试过）？

答不出就换题。空白太大往往意味着别人试过做不出来，或者根本没人在乎。

## 六、产出

- `outputs/topic-selection/gap_candidates.md`：8–10 个候选，每个含「一句话描述 + 空白类型 + 竞争地形 + 支持证据（矩阵行号/文献）+ 初步方法方向 + 为什么没人做（若适用）」

## 七、Hard Stop

向用户确认并排序：
1. 8–10 个候选的**优先级**（用户可删可增，主导权在用户）；
2. 每个候选的**地形判定**是否合理（用户最了解圈内实情，可纠正"以为是空白其实饱和"）；
3. 哪些候选落入冷门/知识空白区——当场过三问闸，答不出直接剔除。
收敛到 **2–3 个**进入 P3。

## 八、常见坑

- ❌ 直接从矩阵空格跳到定题 → 空格是线索，必须过 P3 六重门；
- ❌ 归类先行 → "理论空白"最易成为借口（见消歧三问）；
- ❌ 候选池按"新颖度"排 → 应按**可发表性**（地形 + 重要性 + 可行）排；
- ❌ 候选只有 3 个 → 说明矩阵太小或只盯一个方向，回去补 P1。
