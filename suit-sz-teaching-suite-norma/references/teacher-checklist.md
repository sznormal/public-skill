# 老师需提供内容清单

供 P2（课标）与 P3（教案/授课计划）向老师收集素材时使用。✅=大纲/模板可抽取自动填；⚠️=必须老师直接给，不可臆造。

## A 头部信息栏（课标）
- A1 课程名称
- A2⚠️ 课程类别（专业拓展课/必修课…）
- A3⚠️ 适用专业 + 学制（如 智能机器人技术 三年制）
- A4⚠️ 授课单位（中德机器人学院）
- A5⚠️ 学分
- A6⚠️ 总学时
- A7⚠️ 编写执笔人 + 编写日期
- A8⚠️ 审定负责人 + 审定日期
- A9⚠️ 覆盖范围（是否含前置模块）

## B 一、定位设计
- B1⚠️ 课程性质（是否校企 / 是否混合 + 网址）
- B2 先导后继课程 ✅ 大纲可抽
- B3 人才培养作用（据 B1 写）
- B4 设计思路（OBE/PBL + 模块/任务数）

## C 二、课程目标
- C1⚠️ 素质目标 / 思政点
- C2 能力目标（知识/技能/岗位）✅
- C3⚠️ **课程思政融入表**（知识点 / 思政融入点 / 思政案例）——三列逐行，案例须具体可感

## D 三、内容与要求
- D1 模块清单 ✅
- D2 每模块 内容 + 重点 + 难点 ✅
- D3 学时分配表 ✅

## E 四、实践教学
- E1 课内实践项目表 ✅
- E2 独立实践（无则说明）

## F 五、课程实施
- F1⚠️ 软硬件条件
- F2⚠️ 师资条件
- F3 教法建议（参考模板写）
- F4 教材使用

## G 六、考核
- G1 评价方式
- G2⚠️ 考核组合（教师/企业/自评互评）
- G3⚠️ 总评比例

## H 七、线上资源
- H1⚠️ 平台 / 网络课 / 参考书 / 企业案例

## I 八、其他说明
- I1 其他事项（无则免）

---

## P3 教案/授课计划 必问清单（一次性问全）

| # | 问题 | 示例 |
|---|------|------|
| 1 | 学年学期 | 2026/2027学年第1学期 |
| 2 | 班级及各班上课星期 | 3-1班周三、3-2班周四 |
| 3 | 第一周周一日期 | 8月31日（周一） |
| 4 | 教案覆盖周次范围 | 第9-16周 或 全部16周 |
| 5 | 每教案学时 | 4学时（=每周1个教案） |
| 6 | 教师姓名、院部、教研室主任、通过日期 | |
| 7 | 线上教学平台及课程 URL | 雨课堂 + URL |
| 8 | 教案编号方式 | 按周次编号（教案9~教案16） |

> 范围确认最高频返工：课标总学时可能是教案实际覆盖学时的数倍。授课计划必须覆盖学期全部周；教案只覆盖指定范围。
