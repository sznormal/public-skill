## 一、先确认综述类型与结构（Hard Stop）

读取 HUD `review_type`（由 P0 锁定），展示**该类型专属的写作结构模板**
（要素定义见 `modules/review-types.md`）。若用户想换类型，提示需回 P0 重选并可能返工。

### T1 叙述性 / 最新进展综述
```
## 1. 引言（领域重要性 + 本文综述范围与边界）
## 2. 应用域 / 主题章（每章：代表工作 + 核心机制 + 局限）
### 2.1 {主题A}   ### 2.2 {主题B}   ### 2.3 {主题C}
## 3. 跨域模式提炼（≥3 条可复用范式）
## 4. 研究缺口与未来方向（与正文证据对应）
## 5. 结论
```
**特点**：按域叙述、带批判、提炼范式；**不得**声称 systematic / PRISMA。

### T2 系统综述
```
## 1. 引言（证据问题与背景）
## 2. 方法（Methods）
    2.1 预注册号   2.2 检索式与数据库 + 时间窗
    2.3 纳入/排除标准   2.4 偏倚评估工具
## 3. PRISMA 2020 流程图（检索→筛选→纳入+排除理由）
## 4. 结果（Results）：证据综合 + 性能/效应对比表
## 5. 讨论（Discussion）：偏倚、异质性、局限
## 6. 结论
```
**特点**：方法学透明、可复现；缺 PRISMA / 质量评估不得声称 systematic。

### T3 范围综述
```
## 1. 引言（为何 scoping、范围）
## 2. 方法（检索广、遵循 PRISMA-ScR 清单）
## 3. 证据地图（evidence map）：分布、聚类、概念边界
## 4. 空白与机会定位
## 5. 结论与启示
```
**特点**：摸全貌、定位空白；**不做**因果 / 理论综合（越界会被退修）。

### T4 文献计量综述
```
## 1. 引言（量化目标）
## 2. 数据与方法（数据源 WoS/Scopus/arXiv、清洗规则、时间窗）
## 3. 引文年度趋势图
## 4. 关键词共现 / 聚类图
## 5. 演进时间线 + 突现词
## 6. 国家 / 机构贡献（可选）
## 7. 结论
```
**特点**：图表驱动；**必须**声明数据来源与清洗规则。

### T5 批判性 / 观点综述
```
## 1. 立场陈述（核心论点）
## 2. 对现有路线的批判（有据）
## 3. 我的主张 / 框架 / 假设
## 4. 前瞻与开放问题
```
**特点**：观点导向、不追求全面；论点须有证据支撑。

> 结构确认后，按 P4 分析结论 + 本类型模板生成大纲，再进入第二节撰写规范。

## 二、撰写规范（理工科）

### 2.1 引用格式

| 场景 | 格式 | 示例 |
|------|------|------|
| 中文论文（GB/T 7714）| 序号引用 [1] | "张三等[1]提出了..." |
| 英文论文（IEEE）| 序号引用 [1] | "Zhang et al. [1] proposed..." |
| 多文献引用 | [1-5] 或 [1],[3],[5] | 自动排序 |

### 2.2 技术描述规范

- 首次出现的缩写给出全称："Convolutional Neural Network (CNN)"
- 性能数据给出绝对值而非相对提升："准确率从 85.2% 提升到 92.1%"
- 比较文献时使用客观句式，避免 主观判断词

### 2.3 理工科引用句式参考

```
基础描述："{作者} [{文献号}] 提出了...，该方法..."
对比总结："与 [{文献A}] 的方法相比，[{文献B}] 在...上有显著改进"
定位空白："然而，现有工作主要集中在...，对...方向的研究仍然不足"
```

## 三、生成流程

1. **逐段生成**：按大纲顺序，逐段撰写（确保每段不超过 200 字，段落之间逻辑衔接）
2. **引用自动标注**：每提到一篇文献，自动插入正确的引用序号
3. **论断-证据回填（强制）**：写作中每写一个"判断句"，立即在 P4 的预备论断清单中
   回填正文位置与证据编号（规则见 `modules/evidence-mapping.md` §一/§三）：
   - 证据强度与措辞必须匹配（E2/E3 不得用"已证明/已成为主流"等 E1 措辞）；
   - 写不出证据的判断句 → 当场删除或改写为"展望"并标注为本文推测；
   - 完成后落盘 `claim_evidence_map.md`（论断-证据映射表，含 ⚠️/❌ 处置方式）。
4. **交叉核对**：生成后检查引用列表是否与正文一致（无幽灵引用、无遗漏引用）
5. **参考文献列表**：按目标期刊格式生成完整 References/BibTeX

> ⚠️ **参考文献真实性硬约束（防止占位符/编造）**
> - 引用编号（arXiv / DOI）、标题、作者、年份、venue **必须来自 P2 已落盘的
>   `raw_literature_list.json` 中记录的 verifiable identifier**，不得凭记忆新造。
> - **严禁**生成以下任何一项：
>   - 占位符编号：`arXiv:2409.x` / `arXiv:24xx.x`（`.x` 后缀一律无效）
>   - 推断标题：根据正文内容"猜"出的论文标题
>   - 编造作者：`Anonymous`、无依据的首字母缩写（`Z. Zhang et al.`）
>   - 未证实 venue：标了 `ICRA 2025` 等但 P2 未核实
> - 若某条文献在 P2 未记录可核验标识，**直接留空并标注 `[待核验]`**，由 P6 补全，
>   绝不在草稿中填入疑似编造的信息。
> - P5 完成后，P6 会**逐条联网核验**每篇参考文献的真实性，未通过不得提交。

## 三-B、跨语言版本生成（中→英等，2026-09-07 实战沉淀）

为已有中文稿生成英文投稿版（或反向）时，**不是逐段翻译，而是"翻译 + 重定位 + 重校准"**：

1. **重定位**：默认读者从"国内教师/学生"换成"国际研究者"，摘要与引言的定位段
   （贡献声明）必须重写，不能直译（实战：中文版"职教本科教学案例库"定位改为
   "application-domain taxonomy with engineering-selection value"）。
2. **字数口径切换**：中文按汉字数（见 P7-C），英文按 **word 数**（正则
   `[A-Za-z][A-Za-z'-]+` 统计正文、不含参考文献）——T1 英文目标 4,000–8,000 words。
   两口径数值不可互比，禁止用"全部字符数"冒充任一口径。
3. **残留中文字符扫描**：生成后正则 `[\u4e00-\u9fff]` 扫正文；允许保留的仅限
   中文数据库检索词、中文文献原名等**有意保留项**——其余一律是翻译残留（实战抓到
   英文句中嵌着"反思"两字）。
4. **引用编号沿用**：沿用原稿编号体系并保持逐条引用（同一条文献在新语言版中
   引用位置可能增减），生成后必须重跑孤儿/缺失检查。
5. **图表与口径同步**：图题、表格计数（如"49 篇文献按域分布"）必须与新语言版
   实际引用集合一致，不得沿用旧语言版的数字。
