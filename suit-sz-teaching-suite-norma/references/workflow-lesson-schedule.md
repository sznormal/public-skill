# 工作流 · 撰写教案与学期授课计划

把**一份已写好的《课程标准》**转成每周教案 .docx + 学期授课计划 .docx。
核心约束：教案的"教学过程"必须回溯课标的课程思政点与素材，不能凭空编。

排版默认值见同目录的 `format-rules.md`；思政点映射句式与反模式见 `politics-integration.md`。

## 输入、产物与停止条件

- **输入（硬性）**：一份已写好的《课程标准》.docx。**未提供则先回到课标工作流，严禁凭空编造教案。**
- **产物**：`<课程名>-教案N.docx` × N + `<课程名>-课程计划.docx` + 每份教案对应的数据 JSON。
- **停止条件**：范围与日期基准未经用户确认时不调用渲染脚本；课标思政融入表缺失时先补课标，不用自拟案例顶替。

## 总体顺序

```
课标 .docx
  → ① 确认模板与信息（一次性问全）
  → ② 解析课标（模块 / 学时 / 重难点 / 学时分配表 / 课程思政融入表）
  → ③ 代码推算各周上课日期
  → ④ 备份空白模板 → 写数据 JSON → 渲染
  → ⑤ 回读校验（必要时转 PDF 逐页看）
  → ⑥ 交付（列出全部教案 + 假日冲突提醒）
```

## 一、必问清单（一次性问全再动手）

| # | 问题 | 示例 |
|---|------|------|
| 1 | 学年学期 | 2026/2027学年第1学期 |
| 2 | 班级及各班上课星期 | 3-1班周三、3-2班周四 |
| 3 | 第一周周一日期 | 8月31日（周一） |
| 4 | 教案覆盖周次范围 | 第9–16周 或 全部16周 |
| 5 | 每教案学时 | 4学时（= 每周1个教案） |
| 6 | 教师姓名、院部、教研室主任、通过日期 | |
| 7 | 线上教学平台及课程 URL | 雨课堂 + URL |
| 8 | 教案编号方式 | 按周次编号（教案9~教案16） |

**范围确认是最高频返工点**：课标总学时可能是教案实际覆盖学时的数倍。授课计划必须覆盖学期全部周，教案只覆盖用户指定范围。若只要部分周教案，仍须确认授课计划写全部周还是部分周。

## 二、确认门（硬性，写前必过）

把"范围 + 日期基准"回显给用户并等待确认，未确认不调用任何渲染脚本。回显内容：

- 授课计划覆盖范围（全部周 / 部分周）+ 教案覆盖周次
- 第一周周一日期与推算结果（"周次 → 各班日期"对照表）
- 时数勾稽：周数 × 周学时 = 计划时数 = 课标总学时？不一致先报告

确认后用 `scripts/progress_dashboard.py` 刷新进度（章节为：课标解析 / 日期推算 / 各教案 / 授课计划）。

## 三、解析课程标准

用 python-docx 提取并核对：

1. 课程基本信息：名称 / 类别 / 适用专业 / 总学时 / 学分
2. 模块列表：模块名 / 学时 / 主要教学内容 / 要求 / 重点 / 难点
3. **课程思政融入表**：知识点 → 思政融入点 → 思政案例（三列逐行）
4. 学时分配表：每模块 讲授 / 实践 / 其他 学时及总计
5. 实践项目表（如有）

**核对公式（不一致必须报告，不得擅自调和）**

```
总学时 = Σ模块学时 = 教学周数 × 周学时
授课计划时数统计行的 讲授 + 实验 = 总计 = 课标学时分配表总计
教案覆盖学时 = 覆盖周数 × 周学时
```

## 四、日期推算（必须用代码，严禁手算）

```python
import datetime
monday_w1 = datetime.date(2026, 8, 31)        # 第一周周一
for n in range(1, 17):
    mon = monday_w1 + datetime.timedelta(weeks=n - 1)
    wed = mon + datetime.timedelta(days=2)     # 周三 = 周一 + 2
    thu = mon + datetime.timedelta(days=3)     # 周四 = 周一 + 3
```

推算后输出"周次 → 各班日期"对照表请用户确认，再写入。跨月日期（如"9月30日/10月1日"）按推算结果写。

## 五、模板与渲染

- 内置空白模板：`templates/教案模板.docx`、`templates/课程计划-空白模板.docx`。
- 先把空白模板另存备份，每次生成都从空白模板加载，不在已填充文档上二次填充。
- 排版从模板提取，公共函数用 `scripts/docx_helpers.py`。
- 教案 `--profile lesson`、授课计划 `--profile schedule` 用 `scripts/validate_docx.py` 回读校验。

## 六、教案内容规则

### 单元教学目标（三段式）

`#1、素质目标` / `#2、能力目标` / `#3、教学要求`。素质目标含课程思政（科技报国 / 工匠精神 / 自主可控 / 开源生态等，与该模块匹配）；能力目标对应课标"教学要求"，动词开头。行首 `#` 表示该行顶格，渲染时剥离。

### 教学过程必须回溯课标思政点（核心硬规则）

1. **抽取映射**：从课标《课程思政融入表》取出本教案对应模块的"思政融入点 + 思政案例 + 素材"。
2. **教学过程内嵌思政**：每个学时的实训或讲解环节至少安排 1 处与课标思政点对应的落点（可放在"三、实训N"或知识点讲解收尾），用 1~2 句话点出**思政融入点 + 该模块具体案例**，不空喊口号。
3. **独立"思政融入"栏目**：每份教案须含该栏目（思政融入点 + 思政案例），**须与课标思政表对应行一致**，案例来源标注。
4. **素材驱动**：行业数据、人物、事件优先取自课标思政表与课标"教学要求"；需补充时按课标工作流的检索兜底规则处理（标注来源、经确认）。

### 教学过程结构（每学时 40 分钟）

```
第X学时（40分钟）：
一、<知识点标题>（15分钟）
1. <子项>（5分钟）
2. <子项>（5分钟）
二、<知识点标题>（20分钟）
三、实训N：<实训名>（10分钟）   ← 此处嵌入思政落点
```

规则：每学时一个"第X学时（40分钟）："标题；学时内"一、二、三"标分钟数；子项"1. 2. 3."可标分钟；**每学时分钟数合计 = 40**；实践课讲解占 1/4–1/2，其余为实训条目；4 学时教案约 8–12 个"一、二、三"级条目；首次课含课程介绍 / 教学计划 / 考核要求；每模块首次课融入思政；末周含课程总结 + 综合测试。

### 课外作业 / 教学资源 / 线上环节

- 作业 3–4 题，含实操（"完成XX并截图上传<平台>"）。
- 资源：线上平台完整 URL（向用户索取）+ 官方手册 / 官网 + 配套微课课件。
- 线上环节：教学过程约 6 条并标分钟（合计约 90 分钟），平台在线答疑，线上作业 1 条。

## 七、授课计划内容规则

结构：封面 → 表格0（标准名称 / 讲授内容起止 / 教材 / 参考资料 / 网络资源）→ 时数统计行 → 周次表（周次 / 日期 / 内容提要 / 课型 / 时数 / 平台 / 作业 / 备注）。

- 周次表内容提要统一格式：`讲解：1.…；2.…。` + 换行 + `实验：…`
- **有教案的周次取教案内容浓缩；无教案的周次按课标对应模块撰写**
- 时数统计行须与课标学时分配表严格一致
- 首周固定含"课程介绍、教学计划与考核要求"+ 课程思政点；末周含"课程总结与考核要求"+ 综合测试

## 八、教案粒度：按 2 学时一个教案（可选模式）

高校常见要求"一次课 2 学时一篇教案"。此时把每周 4 学时（或其他连排学时）按半周拆分为多篇：

- 序号连续编号（1…32），表头"周次"仍填所属周次，"时数"填 2。
- 单元格里写两行：第一行 `<模块名>`，第二行 `课题：<本半周课题>（本周第X—Y学时）`，便于追溯又保持单篇独立。
- 每篇教学过程为"第一学时 / 第二学时"两段（各 40 分钟），**不要沿用原周课的第3、4学时编号**。
- 教学目标 / 重点 / 难点 / 作业 / 线上环节必须按半周重写；素质目标仍须挂靠课标思政融入表对应知识点。
- 线上环节原按 4 学时约 90 分钟编写，拆分后每篇约 45 分钟。
- 改版前把旧方案整体移入备份目录（如 `教案_备份_每周4学时`），再清空现教案目录重新生成，避免新旧编号混杂。

## 九、填教案模板的四个坑

1. **先裁剪再写**：模板单元格常带多个占位空段（"教学目的及要求："后带"（需包括但不限于以下内容：）"与多个空段）。正确做法是先删 `cell.paragraphs[1:]`，再用第 0 段写第一行、其余 `add_paragraph()`。若"先写后按行数裁剪"，模板遗留空段会把**最后一行正文顶出裁剪范围而被删掉**。用 `strip_cell` + `write_cell` / `append_cell` 即按此实现。
2. **行首 `#` 必须在渲染时剥离**：数据里用 `#1、素质目标` 表示"该行顶格"，渲染时必须去掉 `#` 且不缩进，否则 `#` 会原样印进正式文档。
3. **`append_cell`（保留标签）与 `write_cell`（覆盖）要分清**：带标签行的单元格（教学目的、重点、难点、教具、课后作业、线上作业）用 `append_cell`；空单元格（教学单元值、周次/时数/班级、资源、在线环节、答疑）用 `write_cell`。
4. **模板路径按本技能目录解析**：用 `Path(__file__).resolve().parent.parent / "templates"`，禁止写死绝对路径。缺 python-docx 时按 `setup-guide.md` 配置，或按降级策略产出 Markdown，不停工等安装。

## 十、交付与验证

- **回读校验**：`scripts/validate_docx.py <docx> --profile lesson|schedule`。
- **数字勾稽**：周数 × 周学时 = 计划 = 实际；讲授 + 实验 = 总计。
- `present_files` **必须列出全部教案**（不只代表件），避免"以为没写"。
- 提醒与法定假日重叠周（国庆、元旦等）确认停课与"预计假日缺课时数"填法。
- 说明空白模板备份位置。
