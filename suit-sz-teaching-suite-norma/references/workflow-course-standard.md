# 工作流 · 撰写《课程标准》

把"参考范本 / 校版模板 + 课程信息 + 教学大纲"转成**排版严格对齐模板**的《课程标准》.docx。
核心价值是排版零返工，最容易漏的是首行缩进与"标题必须在表格上方"。

排版默认值见本文件同目录的 `format-rules.md`，本文件不重复列规则。

## 输入、产物与停止条件

- **输入**：课程信息（可分批给）+ 教材/大纲/知识点清单（可无，允许检索补充）+ 可选的校版模板。
- **产物**：`课程标准-<课程名>.docx` + 结构化草稿 JSON（便于改后重跑）。
- **停止条件**：头部信息栏未经用户显式确认时停止，绝不进入正文撰写；用户明确不允许联网且无任何素材时，只产出章节骨架与待补清单，不臆造课程内容。

## 步骤

### Step 1 需求澄清

用一次提问锁定四项：①用途范围（通用模板 / 锚定新课）②课程层级（职业本科 / 高职专科 / 应用型本科）③产出形态（可填 docx / Markdown 版式说明）④章节范围（沿校版 8 章 / 可裁剪 / 以官方为准）。

随后按 `teacher-checklist.md` 的 A~I 分区逐章要内容。**大纲常缺、必须追问的四项**：头部基础信息、素质与思政目标、软硬件条件、考核比例与线上资源。

素材来源要先确认：

- 用户有教材 / 大纲 / 知识点清单 → 以之为准解析，缺口仍须追问。
- 用户无素材 → 明确询问是否允许检索官方课标框架、教材目录、行业规范、课程思政典型案例。**检索结果须标注来源并经用户确认，检索是补充不是替代。**

### Step 2 解析参考模板

用 python-docx 读取模板（优先内置 `templates/课程标准.docx`）。不只看字体字号，必须同时提取：字体（eastAsia）、字号、对齐、行距、段前段后、**首行缩进（`w:firstLineChars`）**。

旧版 `.doc`（OLE2）用 `scripts/doc_extract.py` 提取文本。提取方法与字段含义见 `format-rules.md` 第六节。

### Step 3 学时与模块规划

- 模块学时尽量取 4 的倍数（4/8/12…）。
- 合并 / 拆分模块必须用户确认，并核对总学时一致（口头总学时与大纲累加不符时先解决，不擅自调和）。
- 前置模块也拆成子模块，按"安装 → 使用 → 项目"递进拆成 4 的倍数。

### Step 4 撰写草稿并按章回显

按模板顺序：头部信息栏 → 一、课程定位和课程设计 → 二、课程目标（素质目标 + 能力目标 + **（三）课程思政融入表**）→ 三、课程内容与要求（每模块含内容/要求/重点/难点 + 学时分配表）→ 四、实践教学 → 五、课程实施 → 六、考核 → 七、线上资源 → 八、其他说明。

**课程思政融入表（必含，独立表格）**：置于「二、课程目标」章内，作「（三）课程思政融入表」，三列：**知识点 / 思政融入点 / 思政案例**。按模块或关键知识点逐行映射；案例须具体可感（人物 / 事件 / 数据，如大国工匠胡双钱、高凤林，或制造业自主攻关案例）。

> 此表是后续教案"教学过程"与督导核对的**唯一权威来源**，必须完整准确。

### Step 5 生成 docx

把草稿写成 JSON，再用确定性脚本渲染，不临场拼代码：

```
<python> scripts/render_course_standard.py --data draft.json --out 课程标准-XXX.docx
```

- `<python>` 取 `scripts/check_environment.py` 输出的 `recommended_interpreter`。
- 脚本以内置空白模板为外壳（保留页面设置与页边距），清空正文后按规则重建，模板遗留的括号提示文字不会混进成品。
- 需要往用户自带模板里灌内容时，改用 `scripts/docx_helpers.py` 的函数：`add_header_para`（头部双层 run）、`insert_heading_table_before`（标题+表格）、`write_cell` / `append_cell`（单元格）。

### Step 6 回读校验后交付

```
<python> scripts/validate_docx.py 课程标准-XXX.docx --profile course-standard
```

判 PASS 才交付；FAIL 时按输出的"期望 / 实测"逐条修，改完重跑校验。

## 确认门（硬性）

头部信息栏必须经用户显式确认才能写入正文：

1. 收集名称 / 类别 / 专业+学制 / 授课单位 / 学分 / 总学时 / 编写人+日期 / 审定人+日期 / 覆盖范围。
2. 按"仿宋加黑标签 + 仿宋不加黑值"原样回显，注明"以下头部信息将写入文档，请确认"。
3. **等待确认或修正；未确认前不调用任何生成脚本。**
4. 确认后用 `scripts/progress_dashboard.py` 把"头部信息栏"标为 `done`。

八章每完成一章刷新一次进度仪表盘（状态 `done` / `confirming` / `pending`）。

## 边界

- 默认版式对应深信院校版模板；其他院校必须先拿到其模板并按实际提取值调整。
- 不处理普通文档排版、单页讲义、PPT、论文、公函。
- 生成文件一律另存新文件，绝不覆盖用户正在编辑的模板。
