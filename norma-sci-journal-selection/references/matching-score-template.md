# SCI 选刊评分细则（证据等级 · 打分 · 退稿风险）

本文件是阶段 5「匹配打分」的判据来源。三个部件：**证据等级门槛 → 双维打分 → 退稿风险**。

---

## 部件一 · 证据等级 E0–E3（进入终选的硬门槛）

SCI 沿用"打分必须挂证据"的原则：分数不是凭印象给的，而是挂在**实际读过的材料**上。

| 等级 | 判定标准（满足其一） | 允许动作 |
|---|---|---|
| **E0** | 几乎没有证据：只有刊名、模糊印象、说不出该刊发过什么 | ❌ **不得进入终选评分** |
| **E1** | 基本信息级：读过该刊 Scope / 征稿范围 + 近期文章**标题** | ❌ **不得进入终选评分** |
| **E2** | 近期文章级：**精读过该刊近两年 10–20 篇同类文章**（题名 + 摘要级理解） | ✅ 可进入终选评分 |
| **E3** | 深度理解级：在 E2 基础上，另读过该刊**高被引文章、编辑社论或 Author Guidelines 全文** | ✅ 可进入终选，标注"证据充分" |

**门槛规则**：阶段 5 要求"下载近两年 3–5 篇同类文章"——**这仅达到 E2 的下限**。若实际未达 10–20 篇精读，**停在 E1/E2 之间，不允许打最终分**，应先补齐材料或把该刊降入"待观察"。

**升级路径**：E0 →（读 Scope）→ E1 →（精读 10–20 篇）→ E2 →（读高被引文章/社论/作者指南）→ E3。

**评分卡写法**：每本进入终选的刊，必须在评分卡顶部标 `证据等级：E__`；**E0/E1 不出总分**，只列入"待观察"。

### ★ E2 精读 → 打分维度的映射（v1.5.0 新增）

E2 不是"多读几篇"，它**专供两个维度的依据**——不读 E2，这两项只能靠印象给分：

| E2 实测指标（见 `journal-tools.md` 同名小节） | 喂给哪个维度 | 判读 |
|---|---|---|
| **图件常规量**（该刊综述实测 N 张） | **篇幅与体量** | 本文图件 ≪ N → 3 分及以下；≈ N → 5 分 |
| **附原创基准 / 元分析的比例** | **实验深度** | 比例高（≥40%）且本文无实证 → 3 分及以下；该刊以纯梳理为主 → 不扣分 |
| **参考文献区间与中位** | **篇幅与体量** | 本文 refs 低于该刊中位 → 4 分（在区间内但偏下）；低于区间下沿 → 3 分及以下 |
| **是否反复发表本文这一类形态**（如跨域/跨模态整合型） | **创新点匹配** | 有同类形态先例但选题不同 → 4—5 分（**正向证据**）；无任何先例 → 4 分 |
| **该刊 scope 是否逐字点名本文主题词** | **方法契合** | 逐字点名 → 5 分；仅隐含 → 3—4 分 |

> **纪律**：E2 后分数若与 E1+ 初判分差异显著，**必须在交付物中写出「修正记录」**——哪一维度、由几分改到几分、依据哪一篇具体文章。**只报新分数不报修正依据 = 不可审计。**

> 为什么要这道门槛：仅凭刊名相关就打分，等于把用户送进一轮无谓拒稿。分数必须与证据量匹配。

## 部件二 · 双维打分（内容 60% + 偏好 40%）

沿用 v1.2.0 的双维结构与 60/40 权重（比例可在 G1 调整）。**依据不足的项标"待核（不计分）"，不得用推测值填充。**

### 第一部分 · 内容匹配（默认 60%）

| 维度 | 权重 | 1 分 | 3 分 | 5 分 |
|---|---|---|---|---|
| **创新点匹配** | 25% | 该刊近两年未发过同类创新 | 发过相近创新但切入点不同 | 该刊近两年反复发该类创新，是其常规贡献形态 |
| **方法契合** | 25% | 方法论层面不对路 | 方法可用但需大幅补充论证 | 方法正是该刊主流方法，近两年大量文章同法 |
| **实验深度** | 20% | 数据量/对比基线明显低于该刊常规 | 达到常规下限 | 与该刊近两年同类文章同级（数据量、基线、对比维度） |
| **篇幅与体量** | 15% | 篇幅/图表数远低于或高于常规区间 | 在边缘 | 落在该刊常规区间中位 |
| **受众匹配** | 15% | 该刊读者与你的研究无交集 | 部分读者相关 | 该刊核心读者群明确关心你的问题 |

### 第二部分 · 偏好匹配（默认 40%）

维度与权重取自 G1 偏好卡的"加分项"（如速度 4 / 分区档 3 / 类型 2 / 接收率代理 2），逐项按偏好卡计分，每项依据须标来源或"待核"。

### 分档

| 总分 | 定位 |
|---|---|
| ≥ 85 | 冲（命中率偏低但值得一试） |
| 70–84 | 稳（主投档） |
| 55–69 | 保（兜底） |
| < 55 | 不建议投（体量或方法不对等） |

## 部件三 · Desk Reject Risk（退稿风险 H/M/L）

在五关排雷（`red-flags.md`）基础上，汇总为 High / Medium / Low 三档，**供阶段 5 打分时参考、随评分卡一起交付**。

### 五类判据

| 类别 | 强指示（命中即为强） | 弱指示 |
|---|---|---|
| **1. 收录与分区口径** | On Hold 标记；in 预警名单 / under review；学校不认该索引 | 仅 Scopus 收录；分区口径未确认 |
| **2. Scope 匹配** | Scope 明确排除本稿主题；主题在射程外 | 主题在 Scope 边缘，需编辑特批 |
| **3. 文章类型与体量** | 综述稿遇"仅限邀稿"条款；类型错配（投 Letter 但刊只收 Regular） | 篇幅/图表数处于该刊区间边缘 |
| **4. 撞题** | **目标刊自家近两年发过同题/同视角**（最强指示） | 他刊同题（需显式对标）；arXiv 同题 |
| **5. 编辑胃口** | 命中 Author Guidelines 明确拒稿条款；贡献形态与该刊要求对不上 | 贡献类型表述可包装但需重构 |

### 判定规则

- **High（高）**：**跨类别出现 ≥2 个强指示**（如"撞题最强指示 + Scope 边缘"）
- **Medium（中）**：1–2 个指示，或若干弱指示
- **Low（低）**：五类基本全对齐且证据充分（达 E2/E3）

> 跨类别计数是关键：同一类别内多个弱信号不等于高风险；**两个不同类别各命中一个强指示，风险就可叠加**。

### 写法要求

风险等级后面必须跟**具体命中项**，不能只给字母：
- ✅ `高 —— 目标刊自家 2025 年已发同题综述（撞题）；且该刊 Author Guidelines 写明综述仅限邀稿（编辑胃口）`
- ❌ `高`

## 常见打分陷阱（自查）

| 陷阱 | 表现 | 纠正 |
|---|---|---|
| **超打分** | 凭"希望投上"给高分 | 依据必须挂具体文章题名+年份 |
| **低打分** | 对好匹配刊过于保守 | 检查是否因缺证据而误判，可升 E 等级重评 |
| **Scope 偏置** | 只看主题，忽略方法/体量不对等 | 三类分维度独立打分 |
| **IF 偏置** | 让分区/IF 盖过真实匹配 | 分区只作参考值，见 SKILL.md 量化数据纪律 |
| **近因偏置** | 过度看重最新一篇文章 | 看近两年整体pattern，不看单篇 |
| **证据错配** | E1 证据打了高分 | 未达 E2 不出总分，先补材料 |

## 评分卡交付模板（阶段 5 用）

对每本进入终选的刊各出一张：

```markdown
证据等级：E__（依据：____）
Desk Reject Risk：High / Medium / Low —— 命中：____

| 部分 | 维度 | 权重 | 评分(1-5) | 依据（引该刊近两年具体文章题名+年份，或"待核"） |
|---|---|---|---|---|
| 内容60% | 创新点匹配 | 25% | | |
| 内容60% | 方法契合 | 25% | | |
| 内容60% | 实验深度 | 20% | | |
| 内容60% | 篇幅与体量 | 15% | | |
| 内容60% | 受众匹配 | 15% | | |
| 偏好40% | （按 G1 偏好卡逐项） | | | |
| 偏好40% | | | | |

加权总分 = 内容 × 60% + 偏好 × 40% = __
定位：冲 / 稳 / 保 / 不建议
待核字段：____（不计分）
```
