# OPC 商业定位方法

## 总体结构

用三个外层问题组织课堂体验：

1. **怎么赚**：选择商业象限，确定产品与交付结构。
2. **凭什么**：校准优势甜蜜区和商业原力，确认能力与跑法。
3. **服务谁**：把优势放进真实需求，锁定客户及其问题。

最终定位由“具体变现载体 + 核心优势 + 目标客户 + 具体问题 + 期望结果”构成。

## 一、商业象限

### 判断轴

四象限的横轴是**产品形态**（虚拟产品 / 实体产品），纵轴是**交付场景**（线上交付 / 线下交付）。

**判断重点不是物理地点，而是客户能否在你不实时在场的情况下完成使用：**
- 客户买到一个模板、录播课、数字工具，自己就能使用 → 线上交付。
- 客户需要你依据他的情况做诊断、给判断、陪他推进，即使通过视频会议完成，交付仍然高度依赖你这个人 → 更接近线下虚拟。

课堂解释时优先使用"可脱离本人重复交付 / 高度依赖本人实时参与"，再标注对应象限，避免学员按视频或见面地点误判。

### 四个象限

象限表达必须同时标注编号和名称，例如「Q1 第一象限 线上虚拟」，不能只用编号或只写名称。

四象限的横轴是产品形态（虚拟/实体），纵轴是交付场景（线上/线下）。判断重点在于：客户能否在你不实时在场的情况下完成使用。同一项能力进入不同象限，产品形态、交付方式、时间成本和收入结构都会跟着变。

| 象限 | 核心定义 | 典型形态 | 核心价值 | 主要风险 |
|---|---|---|---|---|
| Q1 第一象限 线上虚拟 | 虚拟产品+线上交付。客户能脱离你独立使用。一次生产可多次使用，把经验装进可重复交付的产品。 | 数字模板、工具包、电子资料、录播课程、订阅内容、规则化的数字服务 | 经验可重复交付，有机会把经验沉淀成资产 | 信任建立、使用门槛、易模仿、流量需长期建设 |
| Q2 第二象限 线上实体 | 实体产品+线上获客和交易。客户买的是看得见摸得着的东西。审美、品牌感、故事感和细节体验影响价格。 | 手作、文创、设计产品、生活用品、选品和实物商品 | 客户容易理解、容易建立价格参照，产品本身包含材质/设计/包装/场景 | 供应链稳定性、库存压现金、物流售后、打样与品控 |
| Q3 第三象限 线下虚拟 | 虚拟产品+交付依赖经营者本人实时参与。客户购买的是你对具体处境的理解和判断。即使通过视频会议完成，交付仍高度依赖你这个人。 | 咨询、诊断、陪跑、训练、定制方案、深度服务 | 启动成本低、客户反馈直接、能快速获得真实需求和早期现金流 | 时间即产能、服务边界易失控、收入与可投入时间高度相关 |
| Q4 第四象限 线下实体 | 实体产品+线下交付。客户购买的是产品、服务和现场环境共同形成的体验。空间是否舒适、过程是否有参与感、服务是否有温度。 | 工作室、体验活动、本地服务空间、主题活动、小型工作坊 | 信任建立快、现场体验可传达线上文字难以传达的东西、关系深度高 | 固定成本（房租/设备/装修）先发生、地理半径限制、客户容量有限 |

### 五笔账

1. **产品账**：是否能稳定生产和交付？服务边界是否清楚？
2. **获客账**：第一批客户最容易从哪里来？流量能否进入成交场？
3. **现金流账**：投入何时发生，收入何时回来？
4. **时间账**：台前交付与台后准备、沟通、售后共占多少时间？
5. **资产账**：做完后能否留下产品、案例、流程、客户语言或关系资产？

### 选择原则

- 选择当前主象限，不做终身定型。
- 优先考虑已有能力、可承受资源和第一批客户来源。
- Q3 第三象限 线下虚拟常适合有专业经验者低成本起步，再把高频重复部分沉淀到 Q1 第一象限 线上虚拟。
- Q2 第二象限 线上实体和 Q4 第四象限 线下实体先小批量或借场测试，避免过早承担库存和固定成本。
- 跨象限时重新检查需求、交付、成本和获客，不做简单搬运。

## 二、优势甜蜜区

### 三个优势信号

1. **被反复求助**：别人遇到哪类问题会来找用户？
2. **被反复认可**：哪些评价在不同场景中重复出现？
3. **自己顺手、别人费劲**：哪些专业动作已被用户当作常识？

### 校准公式

> 优势甜蜜区 = 做得比多数人好 + 有长期积累 + 愿意持续做 + 有机会解决他人问题

### 证据链

将每项候选优势写成：

> 经历 → 采取的行动 → 展现的能力 → 帮助谁解决什么 → 产生的结果

“善于沟通、学习能力强、责任心强”等词不能直接作为商业优势，必须转化为可观察的行动和结果。

## 三、商业原力

商业原力属于“凭什么”的第二层：优势甜蜜区说明有什么牌，商业原力说明怎么打这副牌。能力和需求对上之后，还要问一个更容易被忽略的问题：你准备怎样跑。

同样做咨询、做产品、做内容，有人通过持续分享获得客户，有人依靠好服务积累口碑，有人擅长连接资源，也有人喜欢快速尝试多个小项目。方法没有高低，关键在于它是否符合你的天然能量来源。这种天然跑法归纳为四种商业原力：推力、引力、接力和弹力。

### 推力型

推力型的人，愿意持续分享。他们乐于表达观点，愿意把经验写出来、讲出来、展示出来。推力可以通过文章、视频、直播、公开分享、案例拆解等形式发生。对这类人来说，表达本身会带来能量，内容获客就更容易成为主渠道。

### 引力型

引力型的人，更重视把服务做深。他们未必喜欢高频公开表达，却愿意把每一次交付做扎实，让客户愿意复购、推荐和背书。引力型业务的核心是可信赖的成果和长期口碑。对于需要高信任的专业服务，这种跑法往往更稳。

### 接力型

接力型的人，擅长连接。他们知道谁需要什么，也知道谁能够提供什么，能够在两端之间建立可靠关系。接力型的价值不只是介绍资源，而是提高匹配效率，减少双方试错。它要求经营者守住边界、兑现承诺，也要求资源关系本身经得起检验。

### 弹力型

弹力型的人，喜欢小步测试。他们对新机会敏感，愿意快速做出一个小产品、小服务或小项目，观察反馈后再决定是否加大投入。弹力型适合在不确定中探索，但要避免同时启动太多事情，最后没有一件真正跑完。

### 主原力与辅助原力

多数人并非只有一种原力。你可以有主原力，也有辅助原力。重要的是先认出占比最高的那一种，再让其他能力为它服务。一个偏引力型的人，可以适度做内容作为补充；一个偏推力型的人，也需要靠交付和口碑把客户留住。

用不适合自己的方式经营，动作会越来越重。找到合适的跑法，经营才更容易成为长期习惯。

### 判断原则

- 依据过去持续发生的行为，不依据理想化自我描述。
- 先识别主原力，再选至多一个辅助原力。
- 性格不决定赛道，只影响表达、交付、获客和节奏。
- 观察社交后的能量变化，以及结构与即兴偏好。
- 选择能连续做五十次的动作，而不是只靠热情做两次的动作。

## 四、真实需求与目标客户

需求判断的核心不是市场是否巨大，而是：

> 是否有一小群人，正在被一个明确问题困住，并愿意为解决它付出成本？

### 具体化结构

将客户写成：

> 人群身份或特征 + 所处阶段 + 触发场景 + 关键问题

将问题写清：

- 在什么节点必须做决定？
- 拖下去会损失什么？
- 现在用什么方式解决？
- 现有方法为什么没有解决？
- 客户愿意为哪一种结果付出成本？

### 证据等级

- **已验证**：有真实咨询、购买、交付或复购证据。
- **有迹象**：公开讨论和访谈中反复出现，但尚无付费。
- **待验证**：主要来自用户个人判断。

课堂结果允许存在待验证假设，但必须显式标注。

## 五、因果链

`当前资源与目标 → 选择主商业象限 → 确定最小变现载体`

`反复行为与案例 → 提炼优势甜蜜区 → 识别可交易能力`

`能量与行为偏好 → 识别商业原力 → 选择可持续经营跑法`

`能力价值 → 匹配客户场景 → 锁定具体问题`

`四项判断 → 合成一句话定位 → 发现证据缺口 → 给出下一步验证`

## 六、黄金三角定位

OPC 商业定位的三个核心问题——怎么赚、凭什么、服务谁——不是三条平行线，而是一个互锁三角。三角中任意一个顶点脱节，定位就不成立。

### 三角结构

```
        怎么赚
       （产品/象限）
        /       \
       /   定位   \
凭什么 —————————— 服务谁
（优势/原力）    （客户/问题）
```

### 三角互证规则

三角成立的前提是三条边都能对齐：

| 边 | 检查问题 | 对齐信号 | 脱节信号 |
|---|---|---|---|
| 怎么赚 ↔ 凭什么 | 你的产品是否由真实优势支撑？ | 客户选择你，正是因为你会做这件事且做得比别人好。 | 产品是"市场上流行的"，但你说不出自己凭什么比别人做得好。 |
| 凭什么 ↔ 服务谁 | 你的优势是否能解决某类客户的具体问题？ | 你的能力恰好卡在客户最痛的那个点上，不是泛泛"我能帮到他"。 | 你能做的事很多，但说不清谁最需要、在什么场景需要。 |
| 服务谁 ↔ 怎么赚 | 目标客户是否愿意为你定义的产品形态付费？ | 你定义的产品形式（咨询/课程/工具/服务），客户已经在用类似方式解决同类问题。 | 客户需要的是轻咨询，你却做了录播课；客户习惯找熟人，你却在做公域投放。 |

### 三角失衡诊断

三角失衡时，不同脱节方向对应不同的典型问题：

- **怎么赚 ↔ 凭什么脱节**（产品与能力不匹配）：常见于追逐热点方向，产品形态与核心优势无关。解决方向：从已有能力重新推导最小变现载体。
- **凭什么 ↔ 服务谁脱节**（能力与需求不匹配）：常见于有专业但找不到付费人群。解决方向：把技能拆分为具体结果，反向匹配谁在为这个结果买单。
- **服务谁 ↔ 怎么赚脱节**（客户与产品不匹配）：常见于产品形态与客户购买习惯冲突。解决方向：不改变客户，改交付方式或产品形态。

### 课堂诊断步骤

在完成十问、合成定位前，执行三角互证检查：

1. **画三角**：把"怎么赚→产品/载体"、"凭什么→优势+原力"、"服务谁→客户+问题"填入三个顶点。
2. **验三边**：逐边用"三角互证规则"表格检查，标注对齐/脱节状态。
3. **定方向**：若只有一条边脱节，标记为"可修复"，给出定向调整建议。若有两条及以上边脱节，标记为"需重启"，回到对应阶段重新问答，不强行合成。
4. **补证据**：每条边的判断依据必须来自十问中的真实回答，不能凭空补充或编造。
5. **留记录**：在最终定位卡中增加"三角校准状态"字段，标明每条边的对齐情况和依据来源（哪一题的回答）。

### 三角迭代原则

定位不是一次画好的。三角会随以下变化而需要重新校准：

- 能力积累使"凭什么"变强 → 可能打开新的"怎么赚"方向。
- 客户反馈使"服务谁"更精准 → 可能发现原来选的产品形态不对。
- 市场变化使得原有"怎么赚"失效 → 需要从"凭什么"重新推导。

每次迭代只需调整一个顶点，再重新检查与之相连的两条边。不因为一个顶点变化就全盘推翻。

### 三角定位与课堂十问的对应关系

| 课堂问题 | 填入三角顶点 |
|---|---|
| Q1 能力入口 + Q2 变现载体 + Q3 起步约束 | 怎么赚 |
| Q4 优势证据 + Q5 商业原力 | 凭什么 |
| Q6 目标客户 + Q7 客户问题 + Q8 目标结果 | 服务谁 |
| Q9 定价与收费 | 怎么赚（定价闭环，验证客户付费意愿） |
| Q10 差异化锚点 | 服务谁（防御性，验证"凭什么是你"） |

三角检查在 Q10 完成后、合成定位前执行，作为从"问答"到"定位"的质检关口。
