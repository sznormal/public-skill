# 测试 Prompt 与干跑

## 真人干跑回归点

- 用户以数字选项作答时，必须按上一轮原文映射，不能把第 3 项误写成第 4 项。
- 示例：若第 3 项为“让账号定位、直播内容和销售产品匹配起来”，用户回答“3”后，期望结果必须保留“匹配”含义，不能改写成“形成持续运营方向”。
- 从第一个诊断问题开始累计核心问题数；第 8 个问题后直接进入合成与确认，最多使用 2 次补充追问。

## v1.1 八问真人回放

**案例**：视频号账号定位诊断。

| 题号 | 承载信息 |
|---|---|
| 1 | 曾帮助商家诊断视频号定位并给运营策略 |
| 2 | 选择 45 分钟一对一定位诊断，依赖本人判断，归入 Q3 第三象限 线下虚拟 |
| 3 | 首客来自行业社群；避免重资金、库存和场地投入 |
| 4 | 能快速抓住定位问题、给出具体建议，客户调整后定位更精准 |
| 5 | 深度服务为主原力（引力型），公开表达为辅助（推力型） |
| 6 | 已开始做视频号的实体产品或线下门店经营者 |
| 7 | 用户、内容、直播和产品之间不匹配 |
| 8 | 期望账号定位、直播内容和销售产品形成一致；证据为 1 个真实案例 |

**预期定位**：

> 我凭借快速识别定位问题并制定具体运营策略的能力，服务已开始做视频号内容或直播的实体产品和线下门店经营者，在账号定位混乱的情境下解决用户、内容、直播与产品不匹配的问题，通过一对一视频号账号定位诊断交付。

**回归结论**：8 个诊断问题可覆盖完整信息；只需 1 次最终确认；无重复询问；数字选项按原文映射，不再出现第 3 项误写为第 4 项。

## 测试 Prompt

1. “帮我完成一人公司商业定位。我做了八年企业培训，擅长把复杂内容讲清楚，但不知道应该卖课还是做咨询。”
2. “我适合哪个商业象限？我会做手工香薰，预算有限，也不想租工作室。”
3. “帮我分析优势和商业原力。我觉得自己会运营，但不知道能服务谁。”

## 干跑一：信息较充分

**输入摘要**：八年企业培训经验；擅长课程设计和复杂内容转化；已有企业学员案例；不喜欢高频直播，重视深度交付；目标客户为准备开发内部课程但缺少方法的中小企业培训负责人。

**执行路径**：

1. 怎么赚：实时诊断和定制占比高，推荐 Q3 第三象限 线下虚拟；产品为"企业内部课程诊断与设计服务"。
2. 凭什么：优势为课程结构化和复杂内容转化；行为更符合引力型，推力型作为辅助。
3. 服务谁：锁定首次搭建内部课程体系的中小企业培训负责人，问题是内容零散、课程难以落地。

**预期定位**：

> 我凭借八年企业培训和复杂内容结构化能力，服务首次搭建内部课程体系的中小企业培训负责人，在内容零散难以体系化的情境下解决课程落地困难的问题，通过企业内部课程诊断与设计服务交付。

**结果**：通过。仍需验证客户是否愿意为完整设计服务付费。

## 干跑二：信息不足

**输入摘要**：“我擅长沟通，想帮助女性成长。”

**执行路径**：

1. 不直接生成定位。
2. 追问沟通曾推动什么具体结果。
3. 要求提供一个帮助对象、行动和结果明确的案例。
4. 收窄女性所处阶段和必须解决的问题。
5. 在产品未确定前，不判断商业象限。

**结果**：可恢复。信息补齐前标记为待验证，不输出空泛定位。

## 干跑三：多方向冲突

**输入摘要**：会做手工香薰；既想线上卖货，又想租工作室办体验课；预算有限；第一批客户来自朋友圈；喜欢快速测试新品。

**执行路径**：

1. 五笔账显示 Q4 第四象限 线下实体固定成本不适配当前资源。
2. 推荐主象限为 Q2 第二象限 线上实体，以小批量预售香薰产品验证需求。
3. 未来可延伸到借用场地的线下体验，不先租工作室。
4. 商业原力暂定弹力型，适合小批测试和反馈迭代。

**结果**：通过。避免同时启动两个重交付方向。
