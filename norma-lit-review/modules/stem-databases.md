# 理工科文献数据库配置

> Norma理工科文献综述 · Module

## 一、中文数据库

### 1.1 中国知网（CNKI）

| 属性 | 说明 |
|------|------|
| 覆盖范围 | 中文学术期刊、博硕论文、会议论文、报纸、年鉴 |
| 理工科优势 | 工程技术、计算机、电子电信类中文文献最全 |
| 检索方式 | WebFetch 高级检索页 / API |
| 特殊功能 | 被引频次、参考文献追溯、关键词共现分析 |
| 限制 | 部分论文需要机构订阅或付费下载全文 |

**推荐检索字段**：`SU=主题` 包含标题+摘要+关键词，覆盖面最广

### 1.2 万方数据

| 属性 | 说明 |
|------|------|
| 覆盖范围 | 期刊、学位论文、会议、专利、标准 |
| 理工科优势 | 专利和标准类资源更全，适合工程实践类检索 |
| 检索方式 | WebFetch |

## 二、英文数据库

### 2.1 Semantic Scholar（推荐首选用）

| 属性 | 说明 |
|------|------|
| 覆盖范围 | 2亿+学术论文，全学科 |
| 理工科优势 | CS/EE/物理/数学覆盖极好 |
| API | 免费、无需认证、不限频率 |
| 检索字段 | title, abstract, year, venue, citationCount, authors, externalIds (DOI, arXiv) |
| 特色 | TLDR 自动摘要、引用图谱 |

**API 示例**：
```
GET https://api.semanticscholar.org/graph/v1/paper/search?
  query=embedded+computer+vision+teaching&
  year=2019-2026&
  limit=100&
  fields=title,authors,abstract,year,venue,citationCount,externalIds
```

### 2.2 arXiv

| 属性 | 说明 |
|------|------|
| 覆盖范围 | 物理学、数学、计算机科学、电子工程、统计学等预印本 |
| 理工科优势 | 最快获取前沿研究（比正式出版早6-12个月） |
| API | 免费、开放 |
| 分类限定 | `cs.*`（CS）`eess.*`（EE/信号处理）`stat.*`（统计）`math.*`（数学）`physics.*`（物理） |

### 2.3 IEEE Xplore

| 属性 | 说明 |
|------|------|
| 覆盖范围 | IEEE/IET 期刊、会议、标准 |
| 理工科优势 | 电子工程/计算机工程领域权威来源 |
| 限制 | 全文需要机构订阅 |

### 2.4 OpenAlex（正式刊出首选，免订阅）

| 属性 | 说明 |
|------|------|
| 覆盖范围 | 4.5 亿条：正式刊出论文 + 预印本 + 学位论文 |
| 理工科优势 | 期刊/会议正式刊出文献覆盖好，可直接取 `cited_by_count`、主题、机构 |
| API | 免费、**无需注册、无需 API key**；填邮箱进 polite pool 后限额更高 |
| 限速 | 无邮箱约 1 万积分/天（列表请求 10 分/次）；上限 100 req/s，脚本默认 0.5 秒/请求 |
| 特色 | CC0 授权，可商用；`cited_by_count` 可替代 WoS/Scopus 做被引统计 |
| 脚本 | `scripts/fetch_lit.py search` / `enrich` |

### 2.5 Crossref（DOI 核验的权威源）

| 属性 | 说明 |
|------|------|
| 覆盖范围 | 1.5 亿+ DOI 记录，DOI 的**注册源** |
| 用途 | P6 按 DOI 核验标题/作者/年份/venue，比 doi.org 更适合批量 |
| API | 免费、**无需注册**；填邮箱进 polite pool（单条 10 req/s、列表 3 req/s） |
| ⚠️ 坑 | 用共用邮箱（如 `info@`）会被**连坐限流**，必须填个人邮箱 |
| 脚本 | `scripts/fetch_lit.py verify` |

### 2.6 OpenCitations（引文网络，T4 计量）

| 属性 | 说明 |
|------|------|
| 覆盖范围 | 16 亿条 DOI→DOI 引文关系，CC0 |
| 用途 | 共引 / 参考文献网络 / 施引分析，补 WoS/Scopus 订阅缺口 |
| API | 完全开放、无 key、无邮箱 |
| ⚠️ 坑1 | `metadata` 端点**已下线（HTTP 410）**——取元数据请用 OpenAlex（`enrich`） |
| ⚠️ 坑2 | **高被引 DOI 的施引查询常超时**（实测 60s）；属服务端限制，改用 `cited_by_count` 兜底 |
| ⚠️ 坑3 | **返回空数组 ≠ 零被引**，只表示未被索引，不得据此判定文献不存在 |
| 脚本 | `scripts/fetch_lit.py citing` |

## 三、数据库选择决策树

```
用户场景
├── 中文核心期刊投稿
│   └── 知网（必选）+ 万方（可选）
├── 英文会议/SCI期刊
│   └── Semantic Scholar（必选）+ IEEE Xplore（如有订阅）
├── 快速了解前沿
│   └── arXiv（必选）+ Semantic Scholar
├── 正式刊出检索 / 被引统计（无订阅）
│   └── OpenAlex（必选）+ Crossref（核验）+ OpenCitations（引文网络）
├── 学位论文方法论参考
│   └── 知网博硕（必选）+ ProQuest（可选）
└── 工程实现/专利参考
    └── 万方专利 + Google Patents
```

## 四、理工科 vs 文科检索差异

| 维度 | 理工科 | 文科 |
|------|--------|------|
| 文献半衰期 | 短（3-5年）| 长（10年+） |
| 主要来源 | 会议+期刊+预印本 | 期刊+专著 |
| 语言偏好 | 英文为主 | 中英文并重 |
| 关键指标 | 性能数据、实验可复现性 | 论证逻辑、理论框架 |
| 检索重点 | 方法+实验结果 | 理论视角+论证结构 |
