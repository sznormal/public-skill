# 技术教材出版规范四维审查（Textbook Review）

## Overview

本技能为技术类教材、讲义、实验指导书提供结构化的"出版就绪度"审查。它**不替代**学科专家的技术终审，而是提供一套可复用的四维检查框架与自动化预检脚本，帮助作者在投稿、交稿或内部评审前**系统性地发现缺陷**，并产出可追踪的审查报告。

审查对象优先为 Markdown 源文件（DOCX / PDF 可先转写或人工抽取后再审）。输出为结构化审查报告（红 / 黄 / 绿 三档问题清单 + 总评 + 放行结论）。

四维定义：

1. **小白可执行性**（权重 25%）——零基础读者能否独立照做、不卡死。
2. **技术严谨性**（权重 35%）——概念、代码、公式、数据是否正确、自洽、可复现。
3. **教学法有效性**（权重 20%）——结构、认知负荷、循序渐进是否符合认知规律。
4. **出版规范性**（权重 20%）——体例、格式、图表、版权是否符合出版要求。

## 适用场景与触发

- 用户上传或指向一份教材 / 讲义 / 实验指导书（Markdown / DOCX / PDF 均可，优先 Markdown）。
- 用户说"审一下这篇教材""出版规范检查""能不能给零基础学生看""小白测试""教材质量评估"。
- 课程材料在投稿、交稿、申报前做质量把关。

## 四维审查框架

### 维度一：小白可执行性（25%）

目标：一个没有前置知识、但具备基本计算机操作能力的读者，能否独立照着做完。

核心审查项（判据详见 `references/four_dimensions.md`）：

- 命令 / 操作是否给出完整上下文（当前目录、前置依赖、环境版本）。
- 是否存在"以此类推""显然""读者自证"等断层。
- 第一步是否有明确起点（环境准备、原料清单）。
- 报错 / 异常是否有对应排障指引。
- 专业术语首次出现是否解释。

### 维度二：技术严谨性（35%）

目标：内容在技术上正确、自洽、可复现。

- 概念定义准确、无歧义。
- 代码片段可运行、与正文一致、无复制粘贴错误。
- 公式 / 参数 / 单位正确。
- 数据 / 版本号有来源、未编造。
- 引用与事实可核查。

### 维度三：教学法有效性（20%）

目标：符合认知规律，便于学习迁移。

- 由浅入深，无跳跃式递进。
- 每节有"为什么学 / 学什么 / 怎么用"闭环。
- 示例与练习匹配目标。
- 抽象概念有具象类比。
- 小结 / 检查点齐备。

### 维度四：出版规范性（20%）

目标：符合技术图书出版体例与可排版规范。

- 标题层级连续（H1→H2→H3 不跳跃）。
- 图表有编号、标题、正文引用。
- 代码块标注语言。
- 无残留占位（TODO / FIXME / 待补充）。
- 术语 / 单位 / 标点统一。
- 版权与引用合规。

## 审查工作流（四步）

**Step 1 接收与范围确认**

- 明确审查对象（文件路径或目录）、目标读者层级、本次重点维度。
- 确认输出形态：审查报告（Markdown）/ 问题清单 / 直接修改建议。

**Step 2 自动化预检**

- 运行 `scripts/review_check.py <教材文件或目录>`。
- 脚本输出规范类问题（标题层级跳跃、占位残留、代码块无语言、空链接、图片缺失、表格分隔符异常）。
- 人工核对脚本结果，排除误报（如代码块内被误判的伪标题）。

**Step 3 四维精读**

- 按 `references/four_dimensions.md` 的评分细则逐项打分（红 / 黄 / 绿 三档）。
- 对每项问题记录：位置（章节 / 行号）、问题、修改建议、严重级。

**Step 4 产出审查报告**

- 套用 `assets/review_report_template.md` 生成结构化报告。
- 给出总评与放行结论（可投稿 / 需修改 / 重大返工）。

## 评分与放行标准

- 每维按 红(0) / 黄(0.5) / 绿(1) 三档，加权求和得 0–100 分。
- **≥85 且技术严谨性无"红"** → 建议放行。
- **60–84 或存在非关键"红"** → 需修改后复审。
- **<60 或技术严谨性存在"红"** → 重大返工。
- 技术严谨性的"红"项（事实 / 代码错误）为**一票否决项**，必须清零方可放行。

## Resources

- `scripts/review_check.py`：出版规范性自动化预检（标题层级、占位残留、代码块语言、空链接、图片引用、表格分隔符）。
- `references/four_dimensions.md`：四维审查详细评分细则（审查项、权重、三档判据、常见反例）。
- `assets/review_report_template.md`：审查报告模板。
