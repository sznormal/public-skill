# 中文稿 → 英文投稿版（Elsevier 系）· 格式转换与本地化

> 适用：已有定稿中文综述，需按目标英文刊格式产出投稿版。
> 来源：机器视觉综述（17,733 汉字 / 138 refs / 12 表 / 5 图）→ Neurocomputing（Elsevier）英文版，
> 2026-10-02 实测。英文版自检 **39/39 通过**。
> **本模块的前提判断**：中文版与英文版是**重构而非翻译**——面向不同读者群，**不构成重复发表**；
> 两版可共用同一套题录台账，做法是**保持引用编号 1—N 一一对应**（正文引用号相同 → 题录同号同源 → 可交叉核对）。

## 三、参考文献：GB/T 7714 → Elsevier 编号制

### 3.1 转换规则（按类型标记分流，不要按位置猜）

沿用本 skill 已验证的原则：**只有 `[J]` 是期刊**。逐条分流：

| 类型标记 | 输出形式 |
|---|---|
| `[J]` | `作者, 题名, 刊名缩写 vol (issue) (year) pages. https://doi.org/DOI` |
| `[C]//` | `作者, 题名, in: 会议名, year, pp. a–b. https://doi.org/DOI` |
| `[EB/OL]` | `作者, 题名, arXiv:id, year.` |
| 作者 | `SURNAME A` → `A. Surname`；多字母缩写逐字母加点（`SAOUD LS` → `L. S. Saoud`） |
| 页码 | 区间用 **en dash**（`9992–10002`） |

### 3.2 三个必须写的正则陷阱

1. **页码必须容纳字母数字文章号**。Nature 系用 `nwae403`、eLife 用 `e00205`。
   若页码正则写成 `([\d\-–]+)`，整条会落到 fallback 分支**原样输出**（刊名不缩写、年份不去括号），
   而且**不报错**。实测 `Natl. Sci. Rev. 11 (12) (2024) nwae403` 就卡在这里。
2. **"期刊位"实为论文集时要改 `in:` 形式**。ECCV / ICPR Workshops / 书名章节常被著录成 `[J]`，
   用黑名单正则（`ECCV|Workshop|Pattern Recognition\.|Low-Power`）识别后改
   `in: Computer Vision – ECCV 2024, 2024, pp. 38–55.`。
3. **`re.sub` 的替换串里不能写 `\u2013`**（会抛 `bad escape \u`）。用
   `lambda m: m.group(1) + "\u2013" + m.group(2)`。

### 3.3 中文题录

Elsevier 不排斥非英语文献，但需可读。做法：**补英文译名 + 拼音人名**，并在刊名后标注。
- 人名用**人工映射表**（`CN_REF`）而非自动拼音——多音字（解/单/曾）会自动出错。
- **必须留下"待人工复核"标记**：本轮 10 条中文题录涉及 28 个拼音人名，全部建议用户逐条过一遍。
- 作者数沿用源题录的「前三作者 + et al.」时，在投稿清单里**声明**（本刊 74.8% 的文献实际著者 >3 位，
  展开全集需走 Crossref 批量补全）。

## 四、图表本地化：容器感知字号自适应（关键）

**中文 1 字 ≈ 拉丁 2 字宽**。把中文标签直译成英文后，**必然溢出原有方框/表头**。
凭空手调既慢又易漏，正确做法是把"能不能放下"变成可计算的判据：

1. **反推可用宽度**：扫描 SVG 的 `<rect>`，取**最小包含矩形**的宽度减内边距；
   **必须排除整幅背景矩形**（宽度 ≥ 900 者），否则所有元素都会拿到近满幅的预算。
2. **构造 fallback 预算**（无矩形可依时）：`text-anchor="end"` → `x - 左边距`；
   `start` → `右边界 - x`；`middle` → `2 × min(x-左, 右-x)`。
   ⚠️ `middle` 的 fallback 在**窄列头**上会过于宽松（fig3 列宽 94.5 但算出 438）→
   这类窄列必须**逐项显式指定预算**。
3. **等比缩字号**：`new_fs = max(FLOOR, fs × 预算 / 英文实宽)`，`FLOOR≈9.0`。
   估算公式：CJK 记 `1.0em`，其余记 `0.52em`。
4. **缩不动的就用缩写 + 题注补全**。这是比"把字缩到 6px"更好的解法：列头 `Found./Ind./Agri./Med./Sec./Trans./Rob./Dep.`，
   然后在**图表题注**里给出全称对照（题注不占图内宽度）。同理 fig5 的 `Backbone/Anomaly det./BEV repr./VLA/Lightweight`。
5. **长标签允许拆两行**：`<text>` 拆成上下两个元素（y−5.5 / y+8.5），既不缩字也不溢出。

### 另一类必查项：内嵌 `<tspan>` 的复合 `<text>`

`<text ...><tspan>G1</tspan>  标注稀缺与数据异构</text>` 这类元素**会被逐元素正则整条漏掉**
（因为 `[^<]*` 遇 `<` 即止），而且**不留任何报错**。
兜底做法：正文替换完再跑一趟**"中文片段级"**替换——用 `[\u4e00-\u9fff][...]*` 抓残留片段，
命中译文表即换，未命中则**报告**（本轮就是这样抓到 fig5 的 6 个缺口名）。
最后必须做一次**全量残留断言**：图件中 `grep -c "[一-龥]"` 必须为 0。

## 五、配套文件清单（Elsevier 投稿实际要传的东西）

| 文件 | 必要性 | 说明 |
|---|---|---|
| Manuscript | 必须 | 含 Title page / Abstract / Keywords / 正文 / 声明 / 题录 |
| **Highlights** | **Elsevier 强制** | 独立文件；3—5 条、每条 ≤85 字符 |
| Cover Letter | 必须 | **必须写"与已有同题综述的差异"**——不写等于把新颖性质疑递给审稿人 |
| Tables（独立文件） | 常见要求 | "tables at end"；从正文自动抽取，保证与正文一致 |
| Figures（EPS/TIFF） | 必须 | **EPS/PDF 矢量优先**（无分辨率上限）；位图按图类型取材：combination art（线条＋文字＋色块）**500 dpi**、halftone 300 dpi、line art 1000 dpi（详见 §9.4） |
| Graphical abstract | 可选 | — |

**Cover Letter 必含的"对标三件套"**（本轮写法可直接复用）：
1. **他组同题综述**（逐篇一句：对方做了什么 → 本文增量是什么）；
2. **目标刊自家的章节级重叠综述**（逐篇一句：本文把它们当"约束条件"纳入跨域框架，而非重做同题）；
3. **方法学声明**（类型＝narrative survey、不声称 PRISMA、预印本占比、数据库不可达的如实交代）。

## 七、本轮实测抓出的 4 处缺陷（都属"静默"类）

| # | 缺陷 | 为什么静默 |
|---|---|---|
| 1 | 摘要首版 **251 词**，超 250 上限 | 不计数就发现不了 |
| 2 | 正文 §2.2 沿用中文旧计数（**131 篇 / 45 篇预印本**），与并入后实际（138 / 52）不符 | 数是"上一版的真相"；门禁只查编号连续与引用覆盖，不查叙述性计数 |
| 3 | Cover letter 预印本占比写成 64 篇（46.4%），实际 52 篇（37.7%） | 靠印象写数 |
| 4 | **中文图 fig5 内遗留「表 8」**（应为表 12） | 并入时表格整体后移，**只改了题注与正文，没改图内文字**；门禁只查"图件存在 + 题注连续"，**图内文字不在检查范围** |

> **规律**：**任何"绝对计数"与"图内文字里的编号"都是静默缺陷高发区**。
> 前者要在每次结构调整后从权威产物（bib / 门禁输出）**重新推导**，不能沿用上一版文字；
> 后者要在**换一种产出方式**（如做英文版、导出 PDF）时才暴露——所以**多产出一道版本本身就是一次检查**。

## 八、反模式

| 反模式 | 后果 | 正确做法 |
|---|---|---|
| 逐句直译中文 | 英文冗长、术语不统一、段落逻辑中式 | **按目标刊结构学术重写**，以中文稿为内容底本 |
| 凭感觉写摘要/预印本数 | 静默超标、静默失真 | 一律**计数**；计数从 bib/门禁输出**重新推导** |
| 图内标签直译 | 溢出方框、列头互相压盖 | 容器感知字号自适应 + 缩写 + 题注补全 |
| 逐元素替换后就收工 | `<tspan>` 复合元素整条漏译且不报错 | 补"中文片段级"兜底 + 全量残留断言 |
| 中文版与英文版各自维护题录 | 两版无法交叉核对 | **保持引用编号一一对应**，共用同一套题录台账 |
| 只改题注与正文的图号 | 图内文字里的表号/图号残留 | 改编号时**连图件文件内文字一起改**，并列入交付前检查 |
| **修订版往正文中间插引用** | 后续题录整体位移，两版编号失配 | **全量重排 + 按题名建映射同步另一版**（见 §9.1），不要"手工把新引用塞到最后" |
| **按编号索引的译文/映射表** | 一旦重编号，键全部失效且**静默返回原文** | 键改用**稳定标识**（中文题名 / DOI / 原文片段），见 §9.2 |
| **用公式估算文本宽度做字号自适应** | 低估粗体字，估算通过而实际满格/相撞 | 交付前跑**真实渲染测量**（`getBBox`）复核，见 §9.3 |
| 图件只出位图 | 线条与文字在 300 dpi 下毛边；combination art 不达标 | **EPS/PDF 矢量优先**；位图按组合图 **500 dpi** |

## 九、修订版重编号：一轮改动，两版连锁（v2.0 实测）

### 9.1 往正文中间插引用 = 全量位移

题录编号若按**正文首次出现顺序**排（GB/T 7714 顺序编码制、Elsevier 编号制皆然），
则在 §1.3 这类靠前位置补一条引用，会让**其后所有题录整体后移**（本轮实测 113/138 条位移）。

**两版同步的两条路**（两条都要走）：

| 版本 | 做法 | 为什么 |
|---|---|---|
| 衍生版（中文，源用 `[VID:]` 标记） | 重跑 `finalize_submission.py` 即可自动重排 | 编号由脚本从标记顺序重新生成 |
| 手写版（英文，正文是硬编号） | **按题名建立"旧号→新号"映射**后等值替换 | 英文正文不依赖中文句序，**无法对齐重译**，只能重映射 |

映射脚本的四个自检（缺一不可）：
1. 旧题录条数与新题录条数可比（`138 → 140`）；
2. **可映射数 == 旧条数**（本轮 138/138，无未命中）；
3. **映射是双射**（`len(set(values)) == len(mapping)`）；
4. 替换前后**引用 token 数不变**（本轮正文 245 → 245、独立表 55 → 55）。
   再叠加门禁的"正文引用覆盖全部题录（无缺失、无越界）"——四项同时通过才可交付。

> ⚠️ 别用"把新引用编号直接写成 [139][140]"绕开：编号制要求按首次引用顺序，
> 靠前位置出现末位编号本身就是格式错误。

### 9.2 键控表不能按"题录编号"索引

`make_elsevier_refs.py` 里给中文题录做人工英译的 `CN_REF` 表，最初按**题录编号**索引。
重编号后键全部失效，后果是**10 条中文题录静默退回中文原样**——
脚本不报错、`残留类型标记` 检查也是 0，因为数字键"命中"了**错误的题录**（或根本没命中）。

- 识别信号：门禁的「正文无中文残留」突然报出**题录区**的行（题录区的 CJK 本应只因中文题录而存在）；
- 修法：键改为**中文题名**（也可用 DOI，但中文刊 DOI 注册在 chndoi、Crossref 查不到，未必拿得到）；
- 通则：**凡"以题录编号为键"的映射/覆盖表，都是下一次重编号的定时炸弹**。

### 9.3 字号自适应要"实测驱动"，不要只靠公式

§4 的估算式（CJK 1.0em / 拉丁 0.52em）**低估粗体拉丁**。实测：
`"Intelligent transportation"` 12.5px 粗体实宽 **147.6 px**，而容器仅 148 px（几乎零边距）；
同图三处「粗体小节标题 + 紧随说明」直接**相撞 65—95 px**（说明文字的 x 是按中文标题的短宽度定的）。

**正确流水线（顺序不可颠倒）**：

```
① 词表替换 + 容器感知估算自适应   （快，先粗排）
② 实测驱动拟合 fit_figures.py     （getBBox 实测 → 说明文字右移 / 字号按实测下调）
③ 溢出复检 check_figure_overflow.py（须为 0 项）
④ 导出 EPS / PDF / TIFF
```

实测拟合的两类修复与容器匹配纪律：
- **同行碰撞**：紧跟在粗体标题后的说明（以「— 」开头）右移到 `标题实测右端 + 10`；
- **容器溢出**：`实测宽 > 容器宽 − 2×PAD` 时按实测比例缩字（`PAD` 取方框实际留白的一半左右，本轮取 6）；
- **容器匹配必须严**：文本中心**真落在 rect 内**，且 `rect.h ≥ 1.2 × 文本高`
  （否则数据条、色块这类小矩形会被当成容器，算出"预算 −12.5"这种荒谬值并**把好字缩坏**——本轮踩过，已回滚重做）。

### 9.4 用 Chromium 做图件测量/导出的三个坑

| 坑 | 现象 | 解法 |
|---|---|---|
| `file:///xxx.svg` 直接打开 | 被当 **HTML 文档**解析，`querySelectorAll('text')` 只返回个位数元素（实测 49 → 5），测量结果完全不具代表性 | 读文件后 `page.set_content()` **内联进 HTML** 再测 |
| `<marker>` 箭头 | svglib **不支持 marker**，EPS 里箭头全部消失且不报错 | 按 marker 几何展开为显式 polygon：`markerUnits` 默认 `strokeWidth`，缩放 = `线宽 × markerWidth/viewBox宽`；再按线方向旋转、平移到线端点 |
| 字体 | ① 英文图仍继承 CJK 字体族 → 渲染走回退字体，且 EPS 通道注册 CJK 后**拉丁字形被换成等宽**；② reportlab 只内置 base-14，`Arial` 被映到未注册的 `ArialMT` → `KeyError` | 英文化时**统一字体族为拉丁字体**；EPS 变体再降级为 `Helvetica` |

**另一个易漏的期刊硬指标**：Elsevier 图件分辨率分三档——halftone（照片）300 dpi、
**combination（线条＋文字＋色块，本类综述图几乎全属此档）500 dpi**、line art 1000 dpi。
按 300 dpi 出图**不达标**。按 **190 mm 双栏宽**折算，combination art 需约 **3740 px**。

## 十、投稿前能不能挂预印本（2026-10-03 核实，**先查平台、再查出版社**）

**一句话：CS 类综述/立场论文，投稿前挂 arXiv —— 不行；录用后 —— 可以；投稿前想锁时间戳 —— 走 SSRN 或其他预印本平台。**

### 10.1 最常见的误判方向

直觉上会先去查出版社政策，但**障碍通常不在出版社一侧**。以 Elsevier 为例，其侧几乎全开：

- 官方 FAQ：「you can post your preprint … **anywhere at any time**」；「Sharing preprints … will not count as prior publication」。
- 期刊提交声明原文把预印本排除在"已发表"之外：「the work described has not been published previously **except in the form of a preprint**, an abstract, a published lecture, academic thesis or registered report」。
- 预印本公开作者身份**不破坏匿名性**的前提是该刊为**单盲**（single anonymized review）；双盲刊才需另行评估。
- 录用后可「immediately update this version with your accepted manuscript」，条件：CC BY-NC-ND 许可 + 链回出版社正式页。

**真正卡人的是平台侧的内容类型政策。** 所以核实顺序应是：**平台内容类型政策 → 再出版社共享政策**。

### 10.2 决定性障碍：arXiv CS 分类不收未经同行评审的综述

arXiv 2025-10-31 公告《Attention Authors: Updated Practice for Review Articles and Position Papers in arXiv CS Category》：

> "Before being considered for submission to arXiv's CS category, review articles and position papers must now be accepted at a journal or a conference and complete successful peer review. … authors must include documentation of successful peer review to receive full consideration. Review/survey articles or position papers submitted to arXiv without this documentation will be likely to be rejected and not appear on arXiv."

要点四条：
1. **必须先被期刊或会议正式录用并完成同行评审**，投递时附**同行评审期刊文献 + DOI 元数据**。
2. **workshop 不算**——「the review conducted at conference workshops generally does not meet the same standard of rigor of traditional peer review」。
3. 这不是"新政策"而是**收紧既有裁量**：综述与立场论文**从来就不在** arXiv 官方接收内容类型清单里（`content-types` 页的 accepted 列表确无此类），过去靠版主自由裁量放行。
4. 动机是量：CS 每月收到**几百篇**综述，多数「little more than annotated bibliographies」。例外 =「研究科技对社会影响的科学论文」（cs.CY / physics.soc-ph 一类），**技术综述不适用**。

**不要换分类绕开**：会被重分类或拒收，而 moderation 政策写明「Submitters who have had works previously delayed or declined by arXiv should anticipate closer scrutiny on future submissions」。

### 10.3 替代通道

| 通道 | 投稿前可发 | 备注 |
|---|---|---|
| arXiv（录用后） | ✅ | 附期刊文献 + DOI；Elsevier 允许同步用 ACC 更新 |
| **SSRN**（Elsevier 自家） | ✅ | Editorial Manager 投稿时勾选 "Free Preprint Service"，**通过初审进入外审后**公开，带独立 DOI；官方明确 opt-in 不影响审稿结果。**逐刊确认是否开通**（其 Preprints 节正文常为 JS 渲染，脚本抓不到） |
| ChinaXiv / Preprints.org / TechRxiv / OSF Preprints / 机构库 / 个人主页 | ✅（出版社侧允许） | **各平台自身收录政策须逐一核实，不做假设**；中文稿另需确认目标中文刊对预印本的态度与是否进入查重范围 |

### 10.4 顺带解决的第二个问题：可编辑源文件

两件事指向**同一个动作**，不要分两次做：

- **arXiv 只收 TeX 源码**，明确拒收由 TeX/LaTeX 生成的 PDF（「a PDF file created from a TeX/LaTeX file will typically be rejected」）。
- **Elsevier 要可编辑源文件**，原文「A PDF is not an acceptable source file」；Word 用 `.doc/.docx`、LaTeX 用 `.tex`。

→ 所以**从 Markdown 稿转出一份 `elsarticle` LaTeX 版**，一次满足投稿源文件 + arXiv 复用。**在交付 Markdown 时就该提示用户这一点**，否则将来返工。

### 10.5 arXiv 2026 其他新规（可能影响交付策略）

| 时间 | 规则 |
|---|---|
| 2026-01-21 | 新投稿者须**机构邮箱 + 该领域既往合著记录**，或取得有背书权者的**个人背书**（仅机构邮箱不再自动过关） |
| 2026-02-11 | 所有分类须包含**完整英文译本** |
| 2026-05 | 对「有明显未经核查的 LLM 生成证据」（如幻觉参考文献、残留 LLM 元话语）的**作者 1 年禁投**，此后投稿须先经同行评审渠道录用 |
| 2026-10-01 | 速率限制：每人每月 **≤2 篇**，同时活跃投稿 **≤3 篇** |

**反用**：正因为 arXiv 在查幻觉引用，**题录全量核验就成了合规资产**——本类稿的「零编造、零占位编号、每条可回溯」应在交付说明里明确写出来，这是能兑现的信任凭证，不是套话。

### 10.6 交付时的动作

查完政策后，**必须回写投稿清单**，而不是只在对话里答一句：把「建议投稿前挂 arXiv」这类**会过期的建议**改成有依据、带日期的结论，并新增"可编辑源文件"检查项（本轮即在 `en/submission_checklist_en.md` 修正 P2-4、新增 P1-6 与「预印本策略」小节）。
