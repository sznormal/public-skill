# 选题评分与分类指南

> **底层框架**：内容获客的两条主线 = 流量型（广告牌管进门）+ 线索型（销售员管转化）。十种类型是这两条主线下的具体建构法。
> **总原则**：**让正确的人看见你 + 让有需求的人选择你，缺一不可。**
> 来源：OPC 线下实战训练营 DAY1 下午「内容获客·十种类型建构」。

---

## 一、流量型 vs 线索型（战略框架）

| 维度 | 流量型 | 线索型 |
|------|--------|--------|
| 一句话比喻 | 广告牌管进门 | 销售员管转化 |
| 核心任务 | 扩入口：广撒网，让更多人被看见 | 促转化：让有需求的人选择你 |
| 流程 | 筛 → 转化 | 直接转化 |
| 子类数 | 6 种 | 4 种 |
| 子类 | 借势·共鸣·观点·盘点·日常·跨界 | 问题解决·教程·对比评测·案例复盘 |

**判定口诀**：
- 选题主要在**扩大认知/借势热点/引发讨论/借日常拉近距离**？→ 流量型
- 选题主要在**解决具体问题/给可操作步骤/帮用户做选择/展示你的真实交付**？→ 线索型
- 两者兼有 → 混合型（hybrid-主倾向-子类），单日占比 ≤30%

**结构原则**：一条内容选**一种类型做主结构**，其他做辅助入口。组合不是叠加，是主次。

## 三、流量型 6 种建构法

### ① 借势 — 把热点翻译成目标用户关心的问题

**4 步流程**：
1. **事件**：交代发生了什么（钩子即可，省掉长复述）
2. **影响**：解释影响谁、影响什么
3. **判断**：给出选择标准（带条件，不说"所有人都该"）
4. **动作**：安排下一步（按认知梯度分段入口）

**关键点**：
- 热点只是钩子，不是内容主体。直接给影响，跳过事件复述。
- 判断要带条件，避免"所有人都应该"这种空话。
- 收口按认知梯度分三段（刚知道 / 想深入 / 找专业诊断）。

---

### ② 共鸣 — 把模糊焦虑写成可识别的处境

**4 步流程**：
1. **处境还原**：具象一个瞬间动作（不写"做内容很累"，写"交付忙到晚上 8 点才想起来晚饭"）
2. **原因拆解**：给这种困境命名一个概念（情绪 → 命名 → 出路）
3. **方向指引**：给一个可尝试的小动作
4. **连接入口**：延展同一处境的入口（让焦虑被看见后有处可去）

**关键点**：
- 切口落到**具体动作**，不要说"做内容很累"这种概括。
- 情绪要靠专业问题兜底——被误解后要看得出你有解释和处理能力。
- 避免只有安慰没有出路，也避免只有成功没有挣扎。

---

### ③ 观点 — 用有条件的判断建立辨识度

**4 步流程**：
1. **一句讲主张**：不搞圆滑绕弯（直接给立场）
2. **写满条件**：讲清楚适合/不适用、前提是什么
3. **给出论据**：为什么这样判断（不是站队，是论证）
4. **说明边界**：什么情况下不适用

**关键点**：
- 区分**纠正误解**（澄清大众常见误区）vs **挑战惯例**（提出与行业不同做法，需要扎实论据）。
- 越有条件的观点 = 越靠谱，单纯站队会掉可信度。
- 评论区应围绕你的判断展开讨论，而不是人身攻击。

---

### ④ 盘点 — 替用户完成一次有标准的筛选

**4 步流程**：
1. **范围界定**：一个任务 / 年级 / 人群（不写"好用的工具"，写"2026 年做小红书必装的 10 个工具"）
2. **分类标准**：每类的判断标准/条件
3. **逐条展开**：每条标准 + 解决方案
4. **对照工具**：自查表 / 评分卡 / 自测（替用户完成一次筛选）

**关键点**：
- **数字必须具体**，每条有明确判断标准，不只列名词。
- 收口按完成程度分级：自己对照 → 看更详细的 → 找你诊断。
- 盘点类在小红书天然适合分类卡片，**收藏率是长期价值信号**。

---

### ⑤ 日常 — 让人格信任成为专业信任的粘合剂

> **核心定位**：调味品不是主菜。专业内容再多，读者对你这个人模糊，日常就是把人拉近的那一笔。**占比 ≤ 20%。**

**两条路径**（按使用时机选）：

| 路径 | 适用时机 | 3 步结构 |
|------|---------|---------|
| **反事体** | 场景观察，适合**事后回味的场景/事/物** | 场景观察 → 专业回味 → 轻连接 |
| **触发体** | 日常细节，适合**当场被击中的场景/事/物** | 日常细节 → 触发专业判断 → 轻连接 |

**关键点**：
- 核心底线：**必须有态度**，不酸、不只流水账。专业身份自然流露。
- 不要掉类服务——让用户在生活切片中对这个人产生亲近感。
- 没有跨界与专业增量的日常 = 流水账。

---

### ⑥ 跨界 — 用大众话题外壳包装专业内核

**结构模板**：
1. **大众话题切入**（用大家关心的开头）
2. **平移至专业视角**（自然过渡到你的领域）
3. **给出专业判断**（尊重信息、换个角度）
4. **回归大众收尾**（主诉承接，不硬推广产品）

**核心测试**：把跨界里的专业分析部分**单独拎出来**，它本身有独立成段的价值吗？
- ✅ 有 = 好跨界，借到了注意力又贡献了增量
- ❌ 没有 = 硬蹭，读者一眼看穿

## 四、线索型 4 种建构法

### ⑦ 问题解决 — 五步法回答客户正在追问的具体问题

**5 步流程**（顺序可微调）：
1. **痛点开场**：用具体场景让对方认出自己，3 秒内判断"这是否在说我"
2. **问题拆解**：把表面现象拆成可定位的结构性问题，**拆得越准越显专业**
3. **方案框架**：给方向和判断依据，**不写足够细**——"看懂做不出"的落差制造需求
4. **案例佐证**：展示诊断过程而非结果，读者想的是"他也会用同样思路帮我"
5. **钩子收尾**：与认知程度匹配的钩入口，入口与开头痛点呼应

**关键点**：
- 每一步都在建立信任，**切口决定精准度**。
- 不要在第 3 步把答案全说完——留出"我需要你帮我"的缺口。

---

### ⑧ 教程 — 帮用户完成一个小结果，借"看懂→做到"落差制造需求

**5 步流程**：
1. **明确起点终点**：谁来做 + 我到什么阶段 + 完成感长什么样
2. **步骤展开**：每一步骤 "为什么 / 而且只 / 操作命令"
3. **预判卡点**："看到这一步你可能就会发现……"
4. **边界说明**：做不到什么，不就试什么——**越诚实越能引发进一步垂询**
5. **收口**："卡在哪了 / 留言 + 深入入口"

**关键点**：
- 一次带用户完成一个小结果，**步骤不超过 5 个**。
- 适合缺期器小例子 / 用户具备某项结果 / 走到对路径成功等场景。

---

### ⑨ 对比评测 — 帮用户在选项清单中做出适合当前阶段的选择

**4 步流程**：
1. **确定问题**：用户纠结的同一个问题
2. **同维度比较**：2-4 个维度逐一展开（**不在不同层面比**）
3. **明确推荐**：答案条件化——"这种情况下选 A，那种选 B"
4. **个体适配**：无法确认 → 测评或咨询

**三大关键要点**：
- **同维度比较**，不在不同层面比。
- **必须给明确推荐**——敢说建议才有判断力。
- **承认限制**：某方案在某场景下可能不适用，说出来反而增加可信度。

---

### ⑩ 案例复盘 — 展示你怎样识别和处理问题 🏆 信任效果最强

> **前提**：已有真实交付经历，且获得客户公开许可。代入感 × 可信度。

**6 步流程**：
1. **对象 + 处境**
2. **想达到的结果**
3. **表层 vs 深层问题**
4. **解决方向 + 关键动作**
5. **可观察变化**
6. **相似读者自我判断**

**金句**（贯穿全文）：
> 主动暴露过程中的**困难和调整**——一帆风顺的复盘读起来像广告，**只有真正做过的人才知道哪里曾出问题**。

**关键点**：
- 不粉饰、不报喜不报忧。
- 复盘的关键不是结论，是**识别和处理问题的过程**。

## 五、常见类型组合（主次而非叠加）

> 模板是图示化的，好内容经常同时用多种类型——但**一条内容选一种类型做主结构，其他是辅助入口**。

| 组合 | 分界线（主 vs 次） | 配合逻辑 |
|------|-------------------|---------|
| **借势 + 观点** | 主：观点（建立辨识度）；辅：借势（拉注意力） | 事件打开注意力，观点建立辨识度 |
| **共鸣 + 观点** | 主：观点（立论）；辅：共鸣（入口） | 共鸣拉近距离，观点让你被记住 |
| **日常 + 跨界** | 主：跨界（深度）；辅：日常（入口） | 日常降低距离感，跨界展示思考深度 |

> 组合不是叠加，是主次。**没有跨界与专业增量的日常 = 流水账**。

## 六、评分标准（沿用）

| 分数段 | 含义 | 说明 |
|--------|------|------|
| 90+ | 真实痛点 | 用户当下急需解决的问题，搜索意图明确 |
| 85 | 竞品差异 | 有明确的竞品差异点，独特视角可形成壁垒 |
| 70-79 | 热点加工 | 可借助热点做有价值的内容加工 |
| 60 | 无差异竞品 | 竞品来源但无差异点，不入库 |
| <60 | 不合格 | 不入库 |
