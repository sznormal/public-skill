# 评分卡模板（P5）

> 学生与导师**分别独立打分**（先各自打分再看对方的，避免锚定），分歧 >20 的维度必须重议。

## 一、8 维打分

| 维度 | 权重 | 打分锚点 | 学生打分 | 导师打分 | 分歧 | 依据（不能只给数字） |
|---|---:|---|---:|---:|---:|---|
| 空白真实性 | 20% | 六重门 A–C 全过=80+；单库=50；发现同题预印本=≤30 | | | | |
| 重要性 | 15% | 能点名 3 个使用者/引用者=80+；无人使用=50；"研究较少"=≤40 | | | | |
| 新颖性 | 15% | 差异能一句话讲清=80+；仅换数据集=50；与最近邻实质相同=≤30 | | | | |
| 机理深度 | 10% | 理论界/闭式解=90；因果+消融=75；仅相关性=50；说不清=≤30 | | | | |
| 可行性 | 15% | 四项全有=85；缺一项=60；缺两项=35 | | | | |
| 可验证性 | 10% | 公认基线+公开数据+指标+消融=85；基线需自建=55 | | | | |
| 期刊匹配与撞题 | 10% | 持续发同主题+无撞题=85；持续发但有同题=45 | | | | |
| 退路设计 | 5% | 证伪后仍有可发表副产物=80；转分析型=60；无退路=≤40 | | | | |

## 二、脚本核对

```bash
python scripts/score_topic.py outputs/topic-selection/scorecard.json
```

`scorecard.json` 格式：

```json
{
  "scores":         {"空白真实性": 0, "重要性": 0, "新颖性": 0, "机理深度": 0,
                    "可行性": 0, "可验证性": 0, "期刊匹配与撞题": 0, "退路设计": 0},
  "scores_advisor": {"空白真实性": 0, "重要性": 0, "新颖性": 0, "机理深度": 0,
                    "可行性": 0, "可验证性": 0, "期刊匹配与撞题": 0, "退路设计": 0},
  "weights":        {"空白真实性": 20, "重要性": 15, "新颖性": 15, "机理深度": 10,
                    "可行性": 15, "可验证性": 10, "期刊匹配与撞题": 10, "退路设计": 5}
}
```

退出码：`0` 通过 / `1` 触发否决 / `2` 输入不完整
