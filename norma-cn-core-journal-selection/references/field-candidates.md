# 分领域候选刊方向（只列方向，不标注层级）

> ⚠️ **本表严禁用于断言"这本是不是核心"**。所有刊物必须走 `red-flags.md` 第 1–2 关：官方目录核验 + 三库收录 + 增刊套刊排除。
> 目录层级随版本变动，**本表只提供建池方向**。刊物更名、停刊、合并、退出目录均以官方目录与期刊官网为准。

## 使用说明

- 候选池按**认定体系 × 学科类目**交叉筛选——本表仅在"该学科领域有哪些刊可考虑"层面提供方向。
- 教学类稿件另见「教育教学与职业教育」专节：**这是职业本科/高职教师投稿的主战场**，且常被 SCI 选刊流程完全忽略。
- 目标刊若与用户单位要求的体系/版本不符，无论多契合也须排除。

## 教学改革 / 课程思政 / 职业教育

| 方向 | 刊物类型举例 |
|---|---|
| 高等教育教学研究 | 高等教育类学术期刊、高等教育研究类刊 |
| 职业教育研究 | 职教论坛类、职业教育类专门刊物 |
| 课程思政与思政教学 | 思政教育类刊、高校育人类刊 |
| 实践教学 / 实训 / 产教融合 | 实验室与实训类刊、实验教学类刊 |
| 教育技术 / 虚拟仿真实训 | 教育技术类刊、现代教育技术类刊 |
| 应用型本科人才培养 | 应用型本科研究类刊、地方高校教育研究类刊 |

> 提示：这一领域**大量刊物的录用门槛显著低于科研类核心刊**，且高职/应用型背景作者占比不低——对职业本科教师通常是性价比最高的落点。但仍须逐刊核验目录与真伪。

## 嵌入式 / 物联网 / 智能制造（工学·计算机技术、控制科学与工程、机械工程）

| 方向 | 刊物类型举例 |
|---|---|
| 计算机与信息技术 | 计算机类学术与技术期刊 |
| 自动化与控制 | 控制工程、自动化技术类刊 |
| 智能制造 / 机器人技术 | 制造业自动化、机械与制造类刊、智能制造类刊 |
| 嵌入式系统 / 边缘计算 | 电子技术、测控技术、系统工程类刊 |
| 工业视觉 / 机器视觉 | 光学精密工程类、仪器仪表类、图像处理类刊 |

## 人工智能 / 大模型 / 智能体（2026-2027 高热方向）

| 方向 | 刊物类型举例 |
|---|---|
| 人工智能理论与应用 | 人工智能类刊、计算机类刊 |
| 大模型与智能体应用 | 计算机应用类刊、软件类刊（⚠️ 此方向同主题刊发密集，栏目级撞题风险高） |
| 教育技术中的 AI 应用 | 教育技术类刊（跨刊领域，注意归类到教育学还是工学） |

> ⚠️ 该方向**中文刊同题饱和度快速上升**，且常有"专刊/增刊集中发表 AI 主题"的信号——建池后必须严格走第 4 关栏目级撞题分级。

## 综述类稿件（跨领域）

| 需确认的关键点 | 说明 |
|---|---|
| 该刊是否收综述 | **部分中文核心刊明确不收综述**，直接排除 |
| 体量惯例 | 中文核心综述的**字数与参考文献量要求普遍高于英文刊惯例**，不足先补 |
| 栏目 | 综述常有独立栏目，或挂在"研究述评""文献综述"栏目下 |

## 跨领域通用备选

- 各高校学报（**注意：专科/职业院校学报在部分单位不计核心**，须先问口径）
- 学会主办的学会刊（周期性刊、审稿规范）
- 行业专业刊（工信部、教育部主管的行业类刊物，部分单位认）

> ⚠️ 通用刊"好发"属性使其成为**增刊套刊重灾区**——**必须逐本走 red-flags 全套核查后才能推荐**。
