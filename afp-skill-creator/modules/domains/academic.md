# 学术研究领域模块

> AFP Skill Creator · Domain Module
> 领域：学术研究（论文、综述、方法论、投稿）
> 适用用户：博士/硕士生、青年教师、期刊作者、学术编辑
>
> 本模块在 AFP-skill-creator P1 用户识别自己是"学术研究"领域后被 Read on demand

---

## 一、领域概述

**学术研究 skill** 目标：帮助学术研究者完成学术内容生产的结构化流程——从选题到成稿。

**典型场景**：
- 博士/硕士论文写作
- 期刊论文投稿
- 文献综述系统梳理
- 研究方法选择与论证
- 学位论文各章节撰写
- 学术演讲/答辩准备

---

## 二、AFP 三支柱在学术领域的具象化

| AFP 支柱 | 学术具象 |
|---|---|
| **Auto · 自主决策** | agent 自主推进综述/框架/方法各阶段，在关键决策点（Hard Stop）请用户判断 |
| **Flow · 协同流动** | 选题 → 综述 → 框架 → 方法 → 分析 → 写作 → 投稿 跨阶段传递上下文 |
| **Prompt · 提示词工程** | 学术写作 prompt 标准化（引用规范、方法论描述、结论撰写） |

## 三、学术领域方法论参考

### 3.1 研究范式（Bundle 内部分支的判断依据）

- **理论驱动**：从已有理论出发，检验/扩展
- **经验驱动**：从数据/材料出发，归纳建构
- **敏感性概念**：概念性参照 + 保持开放
- **假设检验**：结构化数据 + 路径建模
- **多理论整合**：跨理论对话（博士论文/英文期刊）
- **实践诊断**：MBA 类论文的场论式诊断
- **案例研究**：单/多案例的结构化分析

### 3.2 数据类型

- **定性**：访谈 / 田野 / 案例 / 文本 / 二手材料
- **定量**：问卷 / 量表 / 面板数据 / 实验数据
- **混合**：解释性序列 / 并行 / 三角测量

### 3.3 典型引用规范

- APA（社科通用）
- Chicago（人文通用）
- GB/T 7714（中文期刊）
- Vancouver（医学）
- IEEE（工程）

skill 主控应根据用户目标期刊自动选择规范。

## 四、学术专属反模式（12 条）

**这些是学术领域**特有的**内容质量反模式**，与 skill 结构反模式（见 `modules/skill-anti-patterns.md` 通用 20 条）互补。

### ❌ A1. 理论贴标签

理论仅在章节开头被提及，后续分析中从未被实际运用

**症状**：第一章说"本研究基于结构化理论"，但后续 5 章分析里再也见不到该理论

**修正**：skill 应在每个分析段落检查是否呼应理论；不呼应的段落标记为"待补齐"

### ❌ A2. 越界解释

数据分析中的解释超出证据允许的范围

**症状**：样本 200 人的研究得出"全社会普遍性"结论

**修正**：skill 应验证结论范围与样本/方法的匹配度

### ❌ A3. 循环定义

用概念自身或其近义词定义该概念

**症状**："数字劳动就是数字时代的劳动"

**修正**：skill 应检查概念定义是否引入了新的解释性要素

### ❌ A4. 概念漂移

同一核心概念在不同章节含义不一致

**症状**：第 2 章说"社会资本 = 网络连接"，第 5 章说"社会资本 = 信任"

**修正**：skill 应维护"核心概念一致性表"

### ❌ A5. 反面证据被忽视

文献综述只引用支持自己观点的研究

**症状**：结论倾向 A，但从未引用支持 not-A 的研究

**修正**：skill 应主动寻找反面证据并要求作者回应

### ❌ A6. 段落孤岛

段落之间缺乏过渡句和逻辑衔接

**症状**：像独立片段的拼贴，读起来跳跃

**修正**：skill 应检查段落间是否有连接词/因果句

### ❌ A7. 数字迷信

量化研究盲目追求统计显著性（p<0.05）而忽视效应量

**症状**：报告 p=0.049 但不报告 Cohen's d 或 R²

**修正**：skill 应强制配对报告显著性 + 效应量

### ❌ A8. 忽视伦理

涉及人类被试的研究不讨论伦理考量

**症状**：访谈研究不提知情同意/匿名化

**修正**：skill 应内置伦理审查检查项

### ❌ A9. 引用虚构（AI hallucination 特有）

skill 生成的引用文献不存在

**症状**：DOI 无效 / 作者从未写过该文 / 期刊无此期号

**修正**：skill 必须在输出前用 shared primitives 的 `cnki-search` / `crossref-verify` 验证每条引用

### ❌ A10. 空泛结论

结论只是重复摘要内容，没有真正的理论对话、局限讨论或未来展望

**症状**：结论章 = 摘要 + 一句"未来研究还需深化"

**修正**：skill 应要求结论包含贡献声明 + 局限讨论 + 未来路径

### ❌ A11. 方法论未论证

研究方法直接使用，未说明为什么选它

**症状**："本文采用扎根理论。第一步是……"（跳过了为什么选扎根）

**修正**：skill 应先驱使用户论证"为什么这个方法适合我的研究问题"

### ❌ A12. 文献综述无 gap identification

文献综述只梳理不识别研究缺口

**症状**：读完综述不知道本研究要填补什么空白

**修正**：skill 应把 gap identification 作为综述强制输出字段

## 六、学术领域典型触发词

设计学术 skill 时，触发词应覆盖：

- 研究相关：研究 / 论文 / 学位论文 / 期刊 / 投稿 / 综述 / 框架 / 方法论
- 阶段相关：选题 / 开题 / 综述 / 建构 / 分析 / 结论 / 摘要 / 关键词
- 场景相关：博士论文 / 硕士论文 / MBA 论文 / SCI / SSCI / CSSCI / 北大核心
- 服务相关：帮我写 / 帮我做 / 帮我改 / 帮我审 / 帮我投

主控 SKILL.md 的 description 应根据具体覆盖场景，选取 10-15 个组合。

## 七、学术领域行文规范

skill 生成的学术内容应符合：

1. **术语一致性**：核心概念在全文保持同一定义
2. **引用密度**：文献综述 5-10 引用/千字，理论框架 2-5 引用/千字
3. **语态**：中文学术偏被动 + 客观，英文学术偏主动 + 简洁
4. **句法**：避免长句嵌套超过 3 层
5. **段落结构**：主题句 + 论证 + 例证 + 过渡

skill 应在输出后自动检查这些指标。

## 八、学术证据链标准

AFP-SPEC §6 Evidence Chain 在学术领域的具体要求：

| 证据类型 | 标准 |
|---|---|
| 期刊论文引用 | DOI + 作者 + 年份 + 期刊卷期页码 |
| 会议论文引用 | 会议名 + 年份 + 页码 |
| 图书引用 | ISBN + 作者 + 版本 + 出版社 + 页码 |
| 网络资源 | URL + 访问日期 + 归档链接（如 Wayback Machine） |
| 一手数据 | 数据源 + 采集时间 + 样本量 + 伦理审批号 |
| 政府文献 | 发文机构 + 文号 + 发布日期 |

skill 生成的所有引用必须至少满足对应类型的最低标准，否则标记为 `unverified`。

## 九、AFP-SPEC 合规目标（学术领域推荐）

学术类 skill 的合规目标：

| 合规等级 | 适用场景 |
|---|---|
| **Bronze** | 探索期、教学演示、个人练习 |
| **Silver（推荐）** | 正式贡献 AFP-ecosystem、合伙人 skill 义务 |
| **Gold** | 学术志官方 skill、期刊合作 skill、专家 agent |

Gold 级学术 skill 建议追加以下检查：
- 通过 3 位合伙人 peer-review
- 至少在 5 个真实用户案例上跑通
- 有 6 个月以上运行历史
