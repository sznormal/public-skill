# 职业本科智慧课程框架建设方法论

## 定位（30 秒看懂）

本 skill 凝练了职业本科智慧课程建设的完整方法论，覆盖从政策依据分析到教材编写的六阶段流程。适用于任何职业本科专业课程：用户输入课程名称，即可按方法论系统化构建课程框架与教材骨架。所有实质产出（政策报告、证赛清单、产业调研、课程框架、教材目录）均**落盘为具名文件**，确保可复用、可交接、可复现。

## 六阶段路由表（薄路由 · 按需 Read）

主控只做路由，各阶段执行细节延迟加载到 `references/`。

| 阶段 | 目标 | 关键动作 | 详情 Read |
|------|------|----------|-----------|
| 一 政策依据分析 | 提取课程建设脉络框架 | 分析教育强国纲要/新双高/职教司一号文件，提取能力图谱、五金建设、岗课赛证、三主编、数字化资源五维度 | `references/policy_framework.md` |
| 二 证赛标准调研 | 形成证赛标准对照表 | 搜职业技能证书+技能竞赛标准，按排除规则裁剪，提取知识点/技能点清单 | `references/cert_competition_research.md` |
| 三 产业调研 | 确定三主编行业伙伴 | 调研目标区域头部企业 3-5 家，定校企合作方向，形成三主编名单 | `references/industry_research.md` |
| 四 课程框架搭建 | 产出课程框架文档 | 项目化结构+岗位场景命名+能力图谱递进+64 学时+虚拟仿真/AI 融入 | `references/course_design_principles.md` |
| 五 迭代优化 | 优化版课程框架 | 课时压缩/内容裁剪/角色分离/验收标准/质量工具/实验对照 | 阶段四设计原则 + 阶段六模板 |
| 六 教材编写 | 三层目录结构教材 | 按项目→任务→9 模块三层目录编写，含知识准备/技能点/思政点/验收评价等规范 | `references/textbook_structure_template.md`、`theory_test_specification.md`、`task_evaluation_specification.md` |

## 使用方式

当用户输入课程名称后，按以下步骤执行：

1. **确认课程信息**：课程名称、专业方向、目标学时、目标区域、是否有已有资源
2. **按六阶段路由表推进**：每阶段完成后与用户确认，再进入下一阶段

╭─ 阶段确认点（硬停）────────────────────────────────────╮
│ 六个阶段每阶段产出物完成后，**必须停下来请用户确认/修订**，│
│ 用户签字或明确"继续"后方可进入下一阶段；不允许自动连跑。  │
╰──────────────────────────────────────────────────────────╯
3. **输出成果物**（均落盘为具名文件）：
   - 阶段一-三：政策分析报告、证赛标准清单、产业调研报告
   - 阶段四：课程框架文档（含项目/任务/学时/验收标准）
   - 阶段五：优化版课程框架
   - 阶段六：三层目录结构教材文件

## 关键设计约束

- **不使用时间标准**：验收标准使用功能验证+质量规范+交付物标准，因网络/硬件差异导致时间不可控
- **岗位场景命名**：项目以岗位角色命名，不以技术功能命名
- **虚拟仿真优先**：先虚拟后实物开发范式
- **不直接使用企业名称**：教材中使用"某企业"替代真实企业名
- **浅色背景深色字体**：所有可视化图表使用浅色背景+深色字体
- **知识准备零跳跃**：每个概念必须从基础讲起，每个命令必须逐参数解释
