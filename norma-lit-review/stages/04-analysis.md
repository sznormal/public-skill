# P4 · 文献分析与综合

> Norma理工科文献综述 · Stage 04
> 目标：对筛选后的文献做深度分析，提炼研究热点、方法趋势和缺口

---

## 一、文献计量速描

### 1.1 时间趋势
- 按年份统计发文量，识别研究热度的上升/下降趋势
- 标注关键年份拐点（新方法出现？政策驱动？硬件突破？）

### 1.2 来源分布
- 期刊/会议/预印本占比
- Top 5 发表期刊/会议
- 这是理工科特有的维度——某些方向偏会议（如CS），某些偏期刊（如EE）

### 1.3 作者/机构网络
- 高产作者/团队的识别
- 国内主要研究机构分布
- 国际合作趋势

---

## 二、方法学分析（理工科核心）

### 2.1 研究方法分布

按以下维度统计每篇文献的研究方法：

| 方法类型 | 子类 | 适用学科 |
|---------|------|---------|
| 实验验证 | 物理实验 / 仿真实验 / 混合 | EE、机械、材料 |
| 理论推导 | 数学建模 / 定理证明 / 算法分析 | CS、数学、控制 |
| 系统设计 | 架构设计 / 原型实现 / 性能评估 | CS、EE、嵌入式 |
| 数据分析 | 统计建模 / 机器学习 / 信号处理 | 各学科通用 |
| 仿真模拟 | 数值仿真 / 硬件在环 / 数字孪生 | 机械、控制、电力 |
| 用户研究 | 问卷调查 / 用户实验 / 可用性测试 | 人机交互、教育技术 |

输出方法论分布矩阵，识别"主流方法"和"少用但可能有潜力的方法"。

### 2.2 评价指标体系

提炼文献中常用的评价指标：
- 性能指标：准确率、FPS、功耗、延迟等
- 实验设计：数据集、baseline、消融实验

## 三、研究缺口分析（Gap Analysis）

交叉比对 P3 的聚类结果和方法分布，识别：

### 3.1 热点饱和区
- 定义：发文量高 + 增长放缓 + 方法趋同 → 不适合作为创新选题
- 标注：hottest cluster，建议用户审慎进入

### 3.2 研究空白区
- 定义：应用场景明确但发文量低，或方法组合未见 → 潜在选题方向
- 标注：具体的"谁 + 什么方法 + 在什么场景"空白

### 3.3 交叉机会区
- 定义：两个聚类之间的桥梁文献稀少 → 交叉创新机会
- 标注：cluster_A ∩ cluster_B 的可行性和潜在价值

### 3.4 方法升级区
- 定义：主流方法论存在明显局限，当前文献提出了改进方向
- 标注：具体的方法改进路径

## 四、理工科专项分析

### 4.1 技术路线演进
把同一问题的不同解决方案按时间排列，画出技术路线图：
```
2019: 传统图像处理方法（边缘检测+模板匹配）
2020: CNN-based方法（分类+检测）
2022: Transformer-based方法（端到端）
2024: 轻量化模型 + 边缘部署
```

### 4.2 基准性能对比
如果文献中报告了同一任务上的性能数据，整理对比表。

### 4.3 开源资源盘点
文献中提到的开源代码、数据集、预训练模型链接。

## 四-B、按 review_type 分支的分析重点

- **T1**：重点做"跨域模式提炼"（≥3 条可复用范式）+ 研究缺口（与正文证据对应）。
- **T2**：重点做**偏倚 / 质量评估汇总**（按 P3 标注的风险等级统计）+ 证据综合，为 P5 的"结果"章提供数据。
- **T3**：重点做**证据地图**（evidence map）——文献分布、聚类、概念边界与空白定位。
- **T4**：重点做**量化图谱**——引文年度趋势、关键词共现 / 聚类、演进时间线、突现词（burst detection）；产出图（可用 Mermaid / CSV 交付，供 P5 嵌入）。
  - **无 WoS/Scopus 订阅时的数据源**：被引数与主题字段用
    `python scripts/fetch_lit.py enrich --dois ...`（OpenAlex，`cited_by_count` 直接可用）；
    共引 / 参考文献网络用 `python scripts/fetch_lit.py citing --doi ... --direction both`（OpenCitations，CC0）。
  - ⚠️ 边界：施引查询对**高被引 DOI 常超时**，且**空数组 ≠ 零被引**。
    超时时以 `cited_by_count` 兜底，并在报告中**透明披露"引文网络覆盖受限"**——
    不得据此断言某文献无影响力。
- **T5**：重点做**立场论证**——提炼"现有路线的核心局限"作为你提出主张的靶子。

## 四-C、预备论断清单与证据基座（证据核查入口）

> 加载 `modules/evidence-mapping.md`。回答审稿人："你的判断有没有足够证据支持？"

1. **提取预备论断**：从本节缺口分析、范式提炼、趋势判断中，列出综述正文将要出现的
   每个"判断句"（含"已证明/显著提升/成为主流/仍然不足/未来将"等措辞），形成预备论断清单
   （claim_id + 论断文本），写入 `analysis_report.md` 专章；
2. **预挂证据**：为每个论断预挂支撑文献编号，并按 §二 标证据强度（E1–E4）；
   挂不出证据的论断此时就标 ❌（E0），P5 写作时删除或降级为"展望"；
3. **大纲推导**：按 §四 规则从证据分布推导综述大纲（章节=证据聚类、顺序=证据逻辑、
   缺口章=证据空白区），**大纲不是拍脑袋排的**——每个章节的证据基座（文献数+核心文献）
   写入大纲备注，供 P5 Hard Stop 展示。

## 五、Hard Stop

输出分析报告核心结论：
1. 这个领域现在"热"在哪里？
2. 有哪些明显的缺口或机会？
3. 你的切入点在哪里？

用户确认分析结论后进入 P5。
