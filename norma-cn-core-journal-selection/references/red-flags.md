# 排雷清单：中文核心期刊五关核查（逐刊执行）

> 与英文刊排雷的最大差异：**第 2 关"真伪核验"是中文生态独有的高风险区**——假刊、套刊、增刊、代发承诺在这条链上泛滥，**投中即成果无效，职称/毕业材料直接不被认可**。

## 第 1 关：目录收录状态（否决项）

**先确认用户单位认哪个体系（见 SKILL.md 阶段 1），再查对应目录。**

| 体系 | 核查入口 | 版本风险 |
|---|---|---|
| 北大核心 | 官网 `hxqk.lib.pku.edu.cn`（**只有电话与邮箱，无在线目录查询**）+ 纸质版《中文核心期刊要目总览》 | 现行 2023 版；**2026 版预计 2027 年 3–4 月发布**，空窗期投稿有掉目录风险 |
| CSSCI | 南京大学中国社会科学研究评价中心官网 | 区分**来源刊 / 扩展版(C扩) / 来源集刊(C集)**——三者认可度差别大，勿混用 |
| CSCD | 中科院文献情报中心 | 区分**核心库 / 扩展库** |
| 科技核心 | 中国科学技术信息研究所 | 年度更新，门槛最低 |

规则：
- **版本必须与用户单位要求的版本一致**。单位若写"须为 2023 年版北核"，2027 年新版本一律排除。
- ⚠️ **勿把《人文社会科学学科来源期刊列表》当成北核目录**——那是统计源列表，2020/2023 版都出现过此类混淆。
- 查不到收录记录 → 不是该体系核心（除非该刊尚未被收录但属新刊，此时按"待核"处理并提示用户问编辑部）。

## 第 2 关：真伪与增刊套刊核验（中文生态高危区，**必须走完整链条**）

**三号齐全 + 三库收录 + 刊期核对，任一不过即排除。**

### 2.1 三号齐全

- **CN 刊号**（国内统一连续出版物号）+ **ISSN**（国际标准刊号）+ **邮发代号**。
- 在 **国家新闻出版署**官网（`nppa.gov.cn` → 从业机构和产品查询 → 期刊）核对：**刊名、CN、主管单位、主办单位必须与期刊版权页一致**。
- 查不到备案记录 → 判定为非法期刊，**立即排除**。

### 2.2 数据库收录验证

- 检索**期刊全称**（首页收录，不是单篇文章），确认在**知网 / 万方 / 维普**中正常收录。
- **未被任一数据库收录的"学术期刊"，大概率是假刊或套刊。**
- 逐刊核对**出版周期、栏目设置**与你将要投的版本一致。

### 2.3 增刊、副刊、专刊、论文集（最高频陷阱）

| 类型 | 特征 | 后果 |
|---|---|---|
| **增刊 / 副刊** | 知网收录标注 **Z1 / S1**；封面标"增刊"；价格低、见刊快 | **职称评审、毕业答辩一律不认可**——发了等于白发 |
| **论文集** | 以会议/专辑形式出版，非连续期刊 | 通常不被认可 |
| **专刊** | 正规专刊由期刊正式出版、有 CN 刊号；但**"花钱即发的专刊"多为中介操作** | 需逐项核实是否官方出版 |
| **套刊** | 一个正规刊号出版多本刊物；新闻出版署查得到，**知网不收录** | 论文网上查不到，完全无效 |

**硬规则：收稿件时必须确认"是正刊正期"。收到刊物后核对版权页期号无"增刊/专刊"字样。**

### 2.4 代发与虚假承诺（听到即警觉）

**以下情形 100% 是骗局，不要含糊：**

- "百分百包录用""核心期刊包发表""几天就能见刊""名额有限"
- "先发表后收费""先交定金再审稿"
- 索要"审稿费""专家外审费""加急费"（正规期刊通常无审稿费；有的刊物有加急费，须以官网公示为准）
- 要求**私人账户/个人微信转账**版面费
- 宣称"内部关系""特殊通道"

**正规投稿铁律**：只走期刊官方投稿系统；版面费走官方对公账户；**先审后付**；不提前交全款；汇款记录、录用通知、邮件往来全程留存。

**用户若透露正在找代理，立即提示风险并劝停**——这是 skill 的主动责任，不是选刊问题。

## 第 3 关：高风险特征自查

以下信号曾被中科院预警名单或期刊质量评估收录，**命中 2 项以上按 🟡 处理**：

| 信号 | 参考阈值 |
|---|---|
| 年发文量异常膨胀 | 1–2 年内翻倍（尤以"专刊/增刊密集"为甚） |
| 自引率过高 | > 20% |
| 审稿极快且录用率畸高 | < 2 周出结论 + 宣称高录用率 |
| 单一单位/单一地区作者占比畸高 | 显著偏离学科常态（"内部刊物"特征） |
| 版面费与刊物层级明显不匹配 | 核心刊收明显低于同档的金额 |
| 已被数据库列入预警/整改 | 知网、维普的期刊预警与整改名单 |

## 第 4 关：栏目与稿件匹配（中文核心最常见的退稿原因）

**中文刊是"栏目制"——栏目不对，送审即退。**

- 该刊是否设**与你稿件类型对应的栏目**：教学研究 / 教学改革 / 课程思政 / 职业教育 / 应用技术 / 综述 / 科研论著等。
- **栏目级撞题三级风险**：

| 级别 | 情形 | 处置 |
|---|---|---|
| 🔴 | 该刊近两年刊发多篇同主题文章 | 换角度或换栏目 |
| 🟡 | 栏目存在但近期无同类文章 | 可投，注明"补位栏目" |
| 🟢 | 该刊无同主题文章 | 蓝海，但需确认栏目是否长期存在（可能即将撤并） |

- **综述稿额外两道关**：① 该刊是否收综述（部分刊明确不收）；② **中文核心综述的体量与文献量惯例要求**（远高于英文刊惯例，字数与参考文献不足先补再投）。
- **篇幅与图表体量**是否在该刊常规区间；**基金项目标注格式**是否符合该刊要求（中文刊对基金编号格式要求严格）。

## 第 5 关：编辑胃口（近期刊文与征稿启事）

中文刊的偏好信号比英文刊更直给，读三样东西就能定性：

1. **近 2–3 期目录与文章标题**：该刊当前在发什么主题、方法取向、篇幅长短、是否收教学类稿。
2. **征稿启事 / 选题通知**：很多刊在官网或公众号发布年度重点选题，**按选题投命中率显著更高**。
3. **栏目偏好倾向**：如偏好实证数据、偏好教学案例、偏好理论探讨。

**用法**：稿件的卖点必须能对上该刊近期某篇具体文章或某条征稿启事；对不上，"相关"也只是"可投"的错觉。

## 输出要求

每刊给出结论，**必须写明依据**：

- 🟢 通过：`北大核心 2023 版在目录内（来源+查询日期）；CN/ISSN 齐备且新闻出版署备案一致；知网收录正刊正期；栏目契合`
- 🟡 需谨慎：`命中：年发文量 2 年翻倍（来源：<已记来源>）` + 给出用户判断建议
- 🔴 排除：`命中：知网仅收录增刊（Z1），正刊未收录` + 给替代刊方向

**不得用"应该没问题""大概是核心""问题不大"替代核查。** 未核查就写"待核"，不许含糊过关。
