# SCI 选刊 Prompt 模板库

供各阶段调用的成品 LLM 提示词。**用法**：把 `[...]` 占位符替换为实际内容，与论文材料一并粘贴。

**全库通用约束（每条 Prompt 均已内置，勿删）**：
1. 信息不足的判断项，必须标注 **"待核"** 或 **"不足以判断"**，不得编造。
2. **禁止编造接收率**——期刊官方极少公开，只能用代理指标并标注"非官方来源"。
3. **IF / 分区只能作参考值**：必须附 **来源 + 查询日期 + 限制说明**，并提示"需人工进一步核查"，不得当作决策依据。
4. 不得提供任何不当建议（如一稿多投、伪造数据、篡改图像）。

## Prompt 0.1 · 论文画像扫描（阶段 0）

**服务阶段**：阶段 0 · 确认点 G0

```
角色：你是一位资深理工科期刊审稿人和科研导师。
任务：把下面这篇稿件的关键信息压缩成一份"论文画像卡"，供后续选刊使用。

要求：
1. 赛道初判：基础研究 / 工程应用 / 系统实现 / 综述 / 教学类（选其一）
2. 创新点类型：新方法 / 新系统 / 新应用 / 新数据集 / 实验对比 / 新视角整合（可多选）
3. 体量指标：参考文献条数、正文字数、图表数（综述稿此三项直接决定可投区间，务必数准）
4. 时效敏感度：主题是否属于近两年高热方向（是/否 + 判断依据）
5. 撞题风险初判：高 / 中 / 低（并列出你据以判断的同类工作线索）

稿件标题：[在此粘贴]
稿件摘要：[在此粘贴]
目录结构：[如有]
参考文献列表：[在此粘贴]

输出格式（严格照此表格，不写多余分析）：
| 维度 | 判定 | 依据 |
|---|---|---|
| 赛道 | | |
| 创新点类型 | | |
| 参考文献条数 | | 实数 |
| 正文字数 | | 实数 |
| 图表数 | | 实数 |
| 时效敏感度 | | |
| 撞题风险初判 | | |

注意：
- 体量指标必须是实际统计结果，不得估算后当实数。
- 任一维度信息不足时填"待核"，并在表外补一句说明缺什么。
```

```
- 赛道：[画像卡赛道]

- 创新点类型：[画像卡创新点]

候选目标刊：[列出目标刊与同档刊]
arXiv 检索式：[我用的检索式]

请按下列结构输出：

### 1) 撞题扫描（三级风险分级）
扫描范围 = 目标刊 + 同档刊 + arXiv，逐项列出发现的同题工作：
| 级别 | 论文题名 | 所属刊/来源 | 年份 | 与本稿的重合点 | 处置建议 |
|---|---|---|---|---|---|
| 最高危（目标刊自家近两年同题） | | | | | |
| 高风险（同赛道他刊同题） | | | | | |
| 关注（arXiv 预印本同题） | | | | | |

### 2) 选题配对矩阵
| 选题角度 | 目标刊 | 撞题风险 | 差异化支点（须引该刊编辑胃口原文） | 判断 |
|---|---|---|---|---|

### 3) 结论
- 选题是否已饱和：是 / 否（给理由）
- 建议：维持现状 / 换角度 / 换刊

约束：
- 差异化支点必须引用目标刊 Aims & Scope 或 Author Guidelines 的**原文片段**；引用不到就写"待补"，不要凭空设想编辑口味。
- 目标刊自家已发同题是最危险的情形（编辑刚发过，不会再收同题），请务必单独标出。
- 发现的竞品信息若不确定是否已正式发表，标注"待核"。
```

## Prompt 4.1 · 五关排雷核查（阶段 4）

**服务阶段**：阶段 4 · 确认点 G4（最关键阶段）

```
角色：你是一位严格把关的期刊资质审查员。
任务：按五关顺序核查候选期刊，任何一关命中即标记，命中任一否决项即进排除表。

候选期刊：[列出待查期刊]
我的稿件类型：[Regular Paper / Survey / Review / Letter]

请逐刊按以下五关输出：

### 期刊 X
**第1关 收录状态**（查 Clarivate Master Journal List）
- 在录索引：SCIE / ESCI / 未在录（待核）
- 是否有 On Hold 标记：是 / 否
- 核查日期：[必须写]

**第2关 预警与 under review**
- 新锐分区站内是否有 under review 标记：是 / 否 / 待核
- 若学校认中科院 2025 版：是否在 2025 年预警名单内（该版共 5 本，原因均为"论文工厂"）
- 若是"论文工厂"高发刊（尤其电子方向的好中刊），单独标出提醒

**第3关 高风险特征自查**（命中 2 项以上按需谨慎处理）
| 信号 | 阈值 | 命中情况 |
|---|---|---|
| 年发文量 2–3 年内翻倍 | 翻倍 | |
| 自引率 > 20% | >20% | |
| 审稿 < 2 周且宣称高录用率 | <2周 | |
| 单一国家作者占比畸高 | 偏离常态 | |
| 特刊密集征稿 | 短时大量SI | |
| 版面费与影响明显不匹配 | 偏高 | |

**第4关 征稿范围与文章类型**
- 主题是否在范围内：是 / 否（引 Scope 原文）
- 文章类型是否接收此类稿件：是 / 否（引 Author Guidelines）
- 综述稿额外两关：是否仅限邀稿（引原文）/ 体量是否达门槛
- 篇幅与图表体量是否在常规区间

**第5关 编辑胃口与选题适配**
- 逐字引用一条明确拒稿条款（引 Aims & Scope / Author Guidelines 原文）
- 逐字引用一条贡献类型要求
- 本稿形态是否对得上该刊要的贡献形态
- 撞题三级风险判定：目标刊自家同题 / 他刊同题 / arXiv 同题

**结论（三选一，必须写明依据）**：
- 通过：列举已核事实 + 查询日期
- 需谨慎：命中具体项 + 给用户判断建议
- 排除：命中具体项 + 给替代刊方向

约束：
- 不得用"应该没问题""大概率可以""问题不大"替代核查。
- 未核查的字段一律写"待核"，不许含糊过关。
- 任何数值（IF/分区/周期/APC/发文量）必须附来源与查询日期；查不到写"待核"。
```

## Prompt 5.1 · 匹配打分（阶段 5）

**服务阶段**：阶段 5 · 进入终选前必须过证据等级门槛

```
角色：你是一位严格的期刊评审专家。
任务：按内容匹配与偏好匹配两大部分，为目标期刊打分，并标注证据等级与退稿风险。

【第一步：证据等级门槛（先做，不达标即停）】
先判断我提供的材料属于哪个证据等级：
- E0 几乎没有证据：只有刊名和印象
- E1 基本信息级：读过 Scope 与近期文章标题
- E2 近期文章级：精读过 10--20 篇该刊近两年同类文章
- E3 深度理解级：另读过该刊高被引文章、编辑社论或作者指南

我的材料：[粘贴你实际掌握的材料]

**若材料不足 E2（未精读 10--20 篇近两年文章），请直接停止打分并告诉我："证据等级 E0/E1，不足以进入终选评分，请先按 red-flags 第 4/5 关补齐材料。"**

【第二步：确认口径】
- 我的偏好卡：[粘贴 G1 偏好卡]
- 内容/偏好权重：默认 60% / 40%（可按我的要求调整）
- 我确认的分区口径：[粘贴 G1 第 1 项]

【第三步：打分（仅在达 E2 后执行）】
第一部分 · 内容匹配（默认占 60%）
| 维度 | 权重 | 评分(1-5) | 依据（引该刊近两年具体文章题名+年份） |
|---|---|---|---|
| 创新点匹配 | 25% | | |
| 方法契合 | 25% | | |
| 实验深度 | 20% | | |
| 篇幅与体量 | 15% | | |
| 受众匹配 | 15% | | |

第二部分 · 偏好匹配（默认占 40%，权重取自我的偏好卡）
| 偏好维度 | 用户权重 | 评分(1-5) | 依据（来源+日期，或"待核"） |
|---|---|---|---|
| 发表速度 | | | |
| 分区档位 | | | |
| 期刊类型 | | | |
| OA / APC | | | |
| 接收率代理指标 | | | |

【第四步：退稿风险】
给出 Desk Reject Risk：高 / 中 / 低
判定规则——在以下五类中，**跨类别出现 ≥2 个强指示即为"高"**；1--2 个指示或若干弱指示为"中"；五类全对齐且证据充分为"低"：
1. 收录与分区口径（On Hold / 预警 / under review）
2. Scope 匹配（主题是否在射程内）
3. 文章类型与体量（类型错配、体量超限）
4. 撞题（目标刊自家已发同题 = 最强指示）
5. 编辑胃口（命中明确拒稿条款）

【第五步：结论】
- 加权总分（百分制）= 内容匹配 × 60% + 偏好匹配 × 40%
- 标注证据等级：E_ / _ / E_
- 一句话判断：冲 / 稳 / 保 / 不建议

约束：
- 评分依据必须引用该刊近两年的**具体文章**（题名 + 年份），不得只凭刊名印象打分。
- 依据不足的项标"待核（不计分）"，不要用推测值填充。
- 相关不等于可投：仅凭题名相关不足以给高分。
- 数值类依据必须注明来源与查询日期。
```
