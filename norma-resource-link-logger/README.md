# 资源链接记录器

把链接一键收进「资源分享链接库」在线表格，自动查重、自动从链接抓取用途说明、自动分类、自动记时间。

## 它解决什么

看到好资源想存下来，手动填表要开网页、想简介、选分类、写日期，四步都是机械劳动。现在只需要把链接丢出来，其余由它完成。

## 怎么唤起

直接说人话即可，不用记命令：

| 常见说法 | 效果 |
|---|---|
| 记个链接 https://github.com/xxx/yyy | 收录单条 |
| 记录 https://arxiv.org/abs/2401.00001 | 收录单条（极简指令） |
| 收一下这个 https://www.bilibili.com/video/BV1xx | 收录单条 |
| 存 https://mp.weixin.qq.com/s/xxxx | 收录单条 |
| 这几个都记一下 + 多个链接 | 批量导入 |
| 加到资源库 https://... | 收录单条 |

链接后面不必写说明，用途说明由它从网页抓取。

## 收录后表格长什么样

| 列 | 内容 |
|---|---|
| 序号 | 自动递增 |
| 资源名称 | 中文名 + 原始仓库名或站点名 |
| 链接 | 完整网址 |
| 主要作用 | 它是什么、关键数据、对您有什么用，尾部带热度或出处 |
| 分类 | 工具/网站、教程/课程、论文/文献、开源项目、AI 应用、其他 |
| 记录时间 | 当天日期 |
| 备注 | 可选 |

GitHub 仓库会带上真实 star / fork / 协议 / 建仓时间；论文带作者、期刊、年份；视频带 UP 主、时长。

## 首次使用要做什么

1. 在 WorkBuddy 左侧连接器管理页连接金山文档（一次性，浏览器登录授权）。
2. 说一句「记个链接 + 网址」试跑。

详细配置、权限和撤销方式见 `references/setup-guide.md`。

## 收录规则

- 先查重：链接已在库里就不会重复写入，会问您要保留、更新还是补备注。
- 分类看本质：awesome 精选列表即使挂独立域名也归「开源项目」；教学视频归「教程/课程」。
- 抓不到就不编：拿不到标题和简介时，主要作用标「待补充」，等您一句话补充。
- 写完必回读：写入后立即读回核对，字段对不上会重试并如实报告。

## 绝不做什么

- 不删除或修改表格里已有的任何行。
- 不动表头、列顺序、颜色和下拉规则。
- 不编造热度、作者、年份等抓不到的字段。
- 不在查重失败时盲写，避免重复收录。
- 不把链接、表格内容发送到表格以外的任何地方。

## 遇到限频怎么办

金山文档对调用频率敏感。提示限频时会自动暂停并等待恢复，批量导入会合并成一次提交以降低触发概率。恢复后未写入的条目会落盘保存，不会丢。
