# 综述类型定义与写作要素速查

> Norma理工科文献综述 · Module
> 被 P0（选型）、P4（分析）、P5（撰写）、P6 / P7（门禁）引用。
> 分类依据：Grant & Booth (2009) 综述分类 + PRISMA 2020 + 工程学科适配
>          （Borrego et al. 2014 / PRISMA-ScR, Tricco 2018）。

---

## 总览表

| 类型 | 一句话定位 | 需 PRISMA | 需质量评估 | 需预注册 | 典型必备产物 | 字数目标（英文 word / 中文「字」） |
|------|-----------|----------|-----------|---------|-------------|-----------------------------------|
| **T1** Narrative / SoTA | 讲清现状与趋势 | 否 | 否 | 否 | 叙述 + 批判 + 研究缺口 | 4k–8k 词 / 0.8万–1.5万字 |
| **T2** Systematic | 严谨回答证据问题 | 是(2020) | 是(ROBINS / GRADE) | 建议 | PRISMA 图 + 偏倚表 + 证据综合 | 5k–10k 词 / 1万–2万字 |
| **T3** Scoping | 摸清全貌与空白 | 是(ScR) | 否 | 否 | 证据地图 + 聚类 | 4k–8k 词 / 0.8万–1.5万字 |
| **T4** Bibliometric | 数据量化演进 | 否 | 否 | 否 | 共现图 + 演进线 + 突现词 | 4k–7k 词 / 0.8万–1.4万字 |
| **T5** Critical / Perspective | 提出立场与前瞻 | 否 | 否 | 否 | 论点论证 + 反驳 + 主张 | 6k–12k+ 词 / 1万–2万字 |

> **口径说明（必读）**：
> - 英文按 **word count**（通常指"正文"，不含摘要 / 参考文献 / 图表说明）。
> - 中文按 **「字」（汉字数）**，非 word；核心 / CSCD 多在 **1–2 万字以内**，含图表常按版面折算（约 1 版 ≈ 2,000–2,500 字）。
> - 微型 / 快速综述（Mini / Rapid）不论类型，约 **1.5k–3k 词 / 3k–6k 字**。
> - 上述为**区间**，非硬下限；具体以目标期刊「作者指南」为准（期刊差异大，见 P0 选型时提示）。

---

## 字数目标详解（审稿人视角）

> 审稿人常因"体量不符类型预期"给出 Major / Reject。以下为**按类型**的字数红区：
> - **明显偏短**（如 T1 正文 < 3k 词 / 0.6 万字）：被疑"覆盖不足、像相关工作段落而非综述"→ 一般/严重。
> - **明显偏长**（如 T1 > 12k 词 / 2.5 万字且非 T5）：被疑"流水账、缺批判聚焦"→ 一般。
> - **类型错配**（如声称 T2 systematic 但无 PRISMA 且 < 5k 词）：方法学不自洽 → 严重（见 P7 门禁）。
> - 字数统计方法在 **P7-C** 强制核查；写作目标在 **P0 选型**即告知用户。

| 类型 | 英文 word 目标 | 中文「字」目标 | 偏短红区 | 偏长红区 |
|------|---------------|---------------|----------|----------|
| T1 | 4,000–8,000 | 8,000–15,000 | < 3,000 / < 6,000 | > 12,000 / > 25,000 |
| T2 | 5,000–10,000 | 10,000–20,000 | < 4,000 / < 8,000 | > 14,000 / > 30,000 |
| T3 | 4,000–8,000 | 8,000–15,000 | < 3,000 / < 6,000 | > 12,000 / > 25,000 |
| T4 | 4,000–7,000 | 8,000–14,000 | > 见下注 | — |
| T5 | 6,000–12,000+ | 10,000–20,000 | < 4,000 / < 8,000 | —（观点类可更长） |

> T4 偏短无红区：计量综述价值在图表与数据，正文短而图表精反而更好；但若"只有图没有方法说明"→ 严重（数据来源不可追溯）。

## T1 叙述性 / 最新进展综述（Narrative / State-of-the-Art Survey）

- **使用场景**：前沿方向现状速览、相关工作章节、开题 / 赛事方案。
- **写作要素（P5 必备）**：
  1. 引言（领域重要性 + 本文综述范围与边界）
  2. 按主题 / 应用域分章，每章含：代表工作 + 核心机制 + 局限
  3. 跨域模式提炼（≥3 条可复用范式）
  4. 研究缺口与未来方向（与正文证据一一对应）
  5. 结论
- **必备产物**：规范参考文献、跨域模式小节。
- **质量门禁**：P6 真实性核验；P7 重点查"是否流水账、缺口是否有据"。
- **🔴 红线**：不得声称 systematic / PRISMA；否则类型与方法不自洽。

---

## T2 系统综述（Systematic Review）

- **使用场景**：回答"某方法是否更优"的具体证据问题；结果需可复现。
- **写作要素**：
  1. **方法（Methods）**：预注册号（PROSPERO / OSF）、检索式、数据库 + 时间窗、纳排标准、偏倚评估工具
  2. **PRISMA 2020 流程图**（检索 → 筛选 → 纳入 + 排除理由）
  3. **结果（Results）**：证据综合、效应量 / 性能对比表
  4. **讨论（Discussion）**：偏倚、异质性、局限
- **必备产物**：PRISMA 流程图、偏倚风险评估表、预注册协议。
- **质量门禁**：P6 额外核验"流程图与纳排标准一致性"；P7 必查 PRISMA 完整性 + 质量评估存在性。
- **🔴 红线**：无 PRISMA / 质量评估却声称 systematic → 直接不合格。

---

## T3 范围综述（Scoping Review）

- **使用场景**：新兴交叉、范围模糊、先摸底。
- **写作要素**：
  1. 方法（检索广、遵循 PRISMA-ScR 报告清单）
  2. **证据地图（evidence map）**：文献分布、聚类、概念边界
  3. 空白与机会定位
- **必备产物**：PRISMA-ScR 清单、证据地图。
- **质量门禁**：P6 核验来源真实性；P7 查是否**越界**做因果 / 理论综合（scoping 本身不做）。
- **🔴 红线**：声称做了理论综合或因果判断，超出 scoping 边界。

---

## T4 文献计量综述（Bibliometric / Scientometric）

- **使用场景**：量化趋势、引文网络、演进、机构贡献。
- **写作要素**：
  1. **数据与方法**：数据源（WoS / Scopus / arXiv）、清洗规则、时间窗
  2. 引文年度趋势图
  3. 关键词共现 / 聚类图（CiteSpace / VOSviewer）
  4. 演进时间线 + 突现词（burst detection）
  5. 国家 / 机构贡献（可选）
- **必备产物**：共现图、演进线、突现词表、数据来源声明。
- **质量门禁**：P7 必查"图表数据来源可追溯、清洗规则明确"。
- **🔴 红线**：不说明数据来源 / 清洗规则，结论可信度存疑。

---

## T5 批判性 / 观点综述（Critical / Perspective）

- **使用场景**：已有立场、提出新范式、顶刊邀稿。
- **写作要素**：
  1. 立场陈述（你的核心论点）
  2. 对现有路线的批判（有据）
  3. 你的主张 / 框架 / 假设
  4. 前瞻与开放问题
- **必备产物**：明确论点 + 反驳论证。
- **质量门禁**：P7 查论点是否有证据支撑、是否过度主张（overclaim）。
- **🔴 红线**：观点无证据支撑，沦为纯吐槽。
