# P3 · 六重门验伪

> 目标：把 2–3 个候选筛到 1 个，并留下**可交导师的核验记录**。门门留档是这一阶段唯一有价值的产物——空白是"验"出来的，不是"找"出来的。

## 六道门（任一红灯即止损或换角度）

| 门 | 动作 | 卡掉什么 | 关键要求 |
|---|---|---|---|
| **A 检索完备性** | 3 组检索式（同义词/缩写/上下位词）、跨库、中英文 | 检索偏差造成的假空白 | 不止查"相同题目"，要查"**同一问题的不同术语表述**" |
| **B 在研与抢发** | arXiv/SSRN 预印本、近 12 个月会议摘要与 Accepted Papers、活跃作者主页 | 别人的在投稿 | 记录**检索日期**（预印本可能几天内上线） |
| **C 最近邻与反证** | 找最接近的 3–5 篇逐维比较；**主动寻找能推翻自己判断的证据** | 差异不清的伪新颖 | 真正的空白是**主动找反例后仍然成立** |
| **D 真人确认** | 导师 + 1–2 位近 3 年活跃作者 | 圈内已知的进行中工作 | ⚠️ 专家意见是**参考性证据**："有人做"触发门 B 复查，不直接换题 |
| **E 撞题与承接** | 目标刊近 3 年目录搜同题；确认该刊持续发此主题 | desk reject 头号原因 | **按月复跑**，撞题是动态风险 |
| **F 可行性与机理** | 数据/设备/算力/周期四项打勾；**机理自洽**检查 | 做不动、做不完、只能灌水 | 无机理解释空间 → 降级为普通工程开发 |

## 门 C：最近邻比较表（必填，这是新颖性的唯一硬证据）

| 维度 | 最近邻论文 1 | 2 | 3 | 你的候选 |
|---|---|---|---|---|
| 研究问题 | | | | |
| 场景条件 | | | | |
| 数据/设备 | | | | |
| 方法 | | | | |
| 对照实验 | | | | |
| 指标 | | | | |
| 主要贡献 | | | | |
| 尚未解决之处 | | | | |
| **你的实质差异** | | | | |

**判据：只有与最近邻存在清晰、实质的差异，才具备新颖性。** "我换了个数据集"不算实质差异。

## 门 C 反证清单（逐条书面回答，不得跳过）

- 是否已有同类方法发表？
- 是否已有相同数据和实验设置？
- 是否有工作证明这个问题**影响很小**？
- 是否有人尝试过但因技术原因失败？（若有，是风险信号，要写进退路设计）
- 是否只是因为检索范围太窄才看起来没有研究？

## 门 F：机理自洽检查（理工科尤其重要）

- 你的改进能解释"为什么提升"吗？（物理定律 / 数学推导 / 明确因果 / 充分消融）
- 若答不出 → 降级为工程开发，或改做**约束空白 / 实证空白**而非方法创新。

## 产出

- `outputs/topic-selection/gate_record.md`：A–F 逐门记录（动作、日期、结论 真/伪/待定、留档链接或检索式）
- `outputs/topic-selection/nearest_neighbor_table.md`：上表填写完整

## Hard Stop

向用户确认：
1. 逐门结论是否有争议（尤其门 B 抢发、门 C 反证）；
2. 剩下的 1 个候选是否值得进入评分卡，还是再留 1 个备选；
3. **门 D 的问人结果**（若已问）——有无"正在做"的情况。
确认后进入 P4。

## 常见坑

- ❌ 六门只走 A 门 → 假空白的主要来源就是检索单一；
- ❌ 门 E 不做 → 撞题是 desk reject 头号原因，且是**动态风险**，P7 阶段要按月复跑；
- ❌ 门 C 只找完全相同的论文 → 最近邻差异才是新颖性的实际判据；
- ❌ 把"专家说没人做"当终审证据 → 只作参考，必须回到 A/B 门复查；
- ❌ 门 F 打勾不实 → 缺设备缺数据会在 P6 暴露，暴露得太晚就是几个月时间损失。
