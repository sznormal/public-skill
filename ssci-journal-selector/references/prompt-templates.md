# LLM Prompt Templates for SSCI Journal Selection

This document contains all the LLM prompt templates for augmenting the 6-step journal selection process. These prompts are designed to work with Claude, GPT-4, or other advanced LLMs.

## Step 1: Paper Fingerprint Generation

### Prompt 1.1: Generate 6-Line Paper Fingerprint

```
角色：你现在是某领域的国际期刊审稿人和科研导师。
任务：请帮我把下面这篇 SSCI 论文的关键信息压缩成"6 行论文指纹"，如果我的描述不清楚，帮我补全但要标注"待核实"。
要求：

行 1：学科口径（尽量用 SSCI 常见学科标签）；
行 2：核心问题 1 句话；
行 3：方法 & 数据简述；
行 4：贡献类型 2--3 点；
行 5：MUST-HAVE 期刊特征 3--5 点；
行 6：DEAL-BREAKER 3--5 点。

下面是论文的标题+摘要+方法概述：
[在此粘贴你的信息]

输出格式：
1. [学科口径]
2. [核心问题]
3. [方法 & 数据]
4. [贡献类型]
5. [MUST-HAVE]
6. [DEAL-BREAKER]

注意：如果某些信息不清晰，请在相应位置标注"待核实"并提供你的建议。
```

### Prompt 1.2: Refine Paper Fingerprint (User Feedback Loop)

```
角色：你是期刊选择顾问。
任务：根据我对初步指纹的反馈，帮我完善和修正 6 行论文指纹。

当前的 6 行指纹：
[粘贴当前的指纹]

我的反馈/修正：
[用户提供的反馈]

请根据我的反馈重新生成完整的 6 行指纹，确保：
1. 学科标签准确且符合 SSCI 分类
2. 核心问题表述清晰且具体
3. 方法描述准确反映研究设计
4. 贡献点突出原创性和重要性
5. MUST-HAVE 和 DEAL-BREAKER 具体且可操作

输出格式：
1. [修正后的学科口径]
2. [修正后的核心问题]
3. [修正后的方法 & 数据]
4. [修正后的贡献类型]
5. [修正后的 MUST-HAVE]
6. [修正后的 DEAL-BREAKER]
```

## Step 2: Candidate Journal Pool Building

### Prompt 2.1: Generate Initial Candidate Pool from References

```
角色：你现在扮演 SSCI 期刊的资深审稿人和编辑顾问。
请不要编造不存在的期刊名。
任务：根据我的"论文指纹"和部分参考文献，帮我列出 10--15 本**真实存在**且较可能接收此类稿件的 SSCI 期刊候选。

约束条件：
- 目标大致分区：Q1--Q3
- 必须为 SSCI 或 SSCI+SCI
- 不要纯医学、纯工程期刊
- 优先选择近 2-3 年发表过类似主题的期刊

论文指纹：
[粘贴你的 6 行指纹]

部分参考文献（列 5--10 篇代表性文章的期刊和题目）：
[粘贴参考文献信息，格式：期刊名 - 文章标题]

输出格式：表格，包含：
| 期刊名称 | 出版社 | 学科领域 | 是否OA | 推荐理由（1--2 句） |
|----------|--------|----------|--------|---------------------|

要求：
1. 所有期刊必须是真实存在的 SSCI 期刊
2. 推荐理由要具体，引用论文指纹中的匹配点
3. 学科分类使用标准术语
4. 标注是否开放获取(OA)
```

### Prompt 2.2: Keyword-Based Journal Search

```
角色：你是学术数据库搜索专家。
任务：帮我设计针对 SSCI 期刊的关键词搜索策略，并推荐相关期刊。

论文指纹：
[粘贴 6 行指纹，特别是核心问题和方法]

请帮我：
1. 生成 3-5 组关键词组合，每组包含：
   - 核心主题词
   - 方法词
   - 情境/对象词
   - 布尔运算符组合建议

2. 推荐最适合的数据库搜索策略：
   - Web of Science 搜索语法
   - Scopus 搜索语法
   - Google Scholar 搜索语法

3. 基于关键词组合，推荐可能的相关期刊（5-8 本）

输出格式：
### 关键词组合
1. [核心主题] + [方法] + [对象/情境]
   - 建议搜索式："主题词" AND "方法词" AND "对象词"
   - 预期相关期刊类型：[描述]

### 数据库搜索策略
**Web of Science:**
```
[具体搜索语法]
```

**Scopus:**
```
[具体搜索语法]
```

### 推荐期刊
[期刊名称] - [匹配理由]
```

## Step 3: Evidence-Based Journal Evaluation

### Prompt 3.1: Journal Scope Matching Assessment

```
角色设定：
你是一名熟悉 [具体学科/领域] 期刊生态的编辑顾问，任务是帮助作者评估"论文--期刊"的匹配度。

任务：
请帮我评估我的论文与期刊 X 的匹配度，并给出结构化建议。

资料：
1）期刊 X 的 Aims & Scope（原文粘贴）：
[在此粘贴期刊的Aims & Scope原文]

2）期刊 X 最近的 5--10 篇文章标题（可选，但强烈建议提供）：
[在此粘贴文章标题]

3）我的论文指纹（6 行）：
[粘贴论文指纹]

输出要求：
请按下面结构输出，不要写多余客套话。

### 1）匹配点分析（3--6 条，尽量具体）：
从主题（Topic）、方法（Method）、研究对象/情境（Context）三方面，指出期刊与论文的重合点，并用 Scope 原文或近期文章标题作为"证据引用"（例如："Scope 中提到......，与你的......对应"）。

### 2）可能的不匹配或风险点（2--4 条）：
指出在主题、方法、样本、文章类型等方面，可能导致 Desk Reject 的风险点；
区分"轻微不匹配（可通过写作调整缓解）"和"结构性不匹配（难以解决）"。

### 3）初步分级（供人工复核，不是最终结论）：
主题匹配（0--5）：[分数] - [理由]
方法匹配（0--5）：[分数] - [理由]
受众匹配（0--5）：[分数] - [理由]
综合给出 Evidence Level 建议（E0--E3），并解释"你是基于哪些信息得出的"；
预估 Desk 风险（高/中/低），并列出判断依据（例如 Scope 中的限制条款、近年文章风格）。

### 4）如果坚持投此刊，我在摘要/引言中应如何强化 Fit？
给出 3--6 条具体建议，例如：
- 标题中是否要补充某些关键词
- 摘要开头应如何对齐期刊常见问题设定
- 引言中应引用期刊近年的哪些代表性论文（只给出策略，不要编造文献）
- 是否需要在方法/场景上强调某些与期刊读者相关的方面

注意：
如果信息不足以给出某一项判断，请明确标注"不足以判断"，不要编造；
不要给出任何与伦理不当相关的建议（如一稿多投、伪造数据等）。
```

### Prompt 3.2: Batch Journal Evaluation

```
角色：你是期刊评估专家，擅长批量分析多个期刊的适配度。
任务：对我提供的 5-8 本候选期刊进行快速评估，生成初步筛选结果。

论文指纹：
[粘贴 6 行指纹]

候选期刊列表：
1. [期刊名称 1] - [出版社] - [大致分区]
2. [期刊名称 2] - [出版社] - [大致分区]
...

对于每本期刊，我需要你快速评估：
- 主题匹配度（0-5）：基于期刊名称、学科分类、出版社特征
- 方法匹配度（0-5）：基于期刊的学术定位和方法偏好
- 初步风险判断：高/中/低（基于分区、出版社声誉、学科匹配）
- 推荐理由：1-2 句话
- 是否推荐深入调研：是/否

输出格式：
| 期刊名称 | 主题匹配 | 方法匹配 | 初步风险 | 推荐理由 | 深入调研 |
|----------|----------|----------|----------|----------|----------|
| [期刊1] | [分数] | [分数] | [风险] | [理由] | [是/否] |

要求：
- 快速判断，不需要详细分析
- 重点识别明显不匹配的期刊（快速排除）
- 推荐 3-5 本值得深入调研的期刊
```

## Step 4: Submission Sequence Design

### Prompt 4.1: Create Submission Strategy

```
角色：你是期刊投稿策略专家，帮助作者设计最优的投稿序列。
任务：基于期刊评估结果，帮我设计"冲-稳-保"三档投稿策略。

我的个人约束：
- 身份：[博士/博后/讲师等]
- 时间要求：[紧急/一般/不紧急]
- 目标分区：[Q1/Q2/Q3]
- OA偏好：[必须OA/可接受/不偏好]
- 预算限制：[APC上限]

期刊评估结果：
[粘贴评估表格或主要发现]

请帮我：
1. 将期刊分为三档：
   - 冲（High）：1-2 本，较高目标但匹配度好
   - 稳（Medium）：1-2 本，匹配度很好，成功概率较高
   - 保（Low）：2 本，稳定选择，时间可控

2. 为每档期刊提供：
   - 具体期刊推荐（按优先级排序）
   - 投稿理由
   - 预期时间线
   - 失败后的应对策略

3. 设计整体投稿计划：
   - 第一投稿选择及理由
   - 预计审稿周期
   - 被拒后的转投时间线
   - 关键时间节点提醒

输出格式：
### 冲档期刊（High）
1. [期刊名称] - [推荐理由] - [预期周期]
   - 风险：[主要风险]
   - 成功指标：[接收标准]

### 稳档期刊（Medium）
[同上格式]

### 保档期刊（Low）
[同上格式]

### 整体投稿计划
- 第一选择：[期刊名称]
- 预计时间线：[月/季度]
- 关键节点：[具体日期和行动]
- 应急方案：[被拒后的具体步骤]
```

## Step 5: Journal Alignment Statement

### Prompt 5.1: Generate Journal Alignment Statement

```
角色：你是该期刊的资深审稿人。
任务：根据期刊 X 的 aims & scope、我论文的指纹以及我提供的几篇类似文章，帮我写一段 150--250 字的"期刊匹配说明"，方便我后面改写成 Cover Letter。

资料：
期刊 X 的 Scope（原文粘贴）：
[粘贴期刊的Aims & Scope]

我的论文指纹：
[粘贴 6 行指纹]

我认为和本稿最相似的 2--3 篇该期刊已发表文章（列出题目和年份）：
[粘贴信息]

输出要求：
请写一段结构清晰的期刊匹配说明，包含：
1. 开头：明确说明本研究与期刊 Scope 的对齐点
2. 主体：引用具体 Scope 内容，说明论文如何满足期刊要求
3. 证据：提及类似文章，说明本研究如何延续或拓展这些工作
4. 结尾：强调本研究对期刊读者群的价值

语言要求：
- 学术化但简洁
- 具体引用 Scope 原文
- 突出匹配度而非泛泛而谈
- 字数：150-250 字

输出格式：
[生成的期刊匹配说明]
```

```
- 期刊：[目标期刊名称]

期刊匹配说明：
[从上一步获得的匹配说明]

[列出 2-3 个关键贡献]

Cover Letter 要求：
- 包含标准结构：开头、匹配说明、贡献说明、新颖性、结尾
- 专业语气，适合目标期刊
- 长度：300-500 字
- 包含必要的声明（原创性、未一稿多投等）

输出格式：
[完整的 Cover Letter 草稿]
```

## Step 6: Execution and Resubmission Planning

```

当前状态：

**审稿人负面评价:**
- [同上格式]

### 转投准备清单
- [ ] [具体任务]
- [ ] [具体任务]
- [ ] [具体任务]

### 时间管理
- 关键节点：[具体日期]
- 缓冲时间：[建议预留时间]
- 应急方案：[紧急情况处理]
```

## General Utility Prompts

### Prompt U.1: Explain Evaluation Criteria

```
角色：你是期刊选择方法论的讲师。
任务：向初学者解释 SSCI 期刊选择的 3D 匹配评分系统。

请详细解释：
1. Topic Fit（主题匹配）0-5 分的评分标准
2. Method Fit（方法匹配）0-5 分的评分标准
3. Audience Fit（受众匹配）0-5 分的评分标准
4. Evidence Level（证据等级）E0-E3 的定义
5. Desk Reject Risk（编辑直接拒稿风险）的判断依据

要求：
- 每项评分标准都要有具体例子
- 区分不同分数段的实质性差异
- 提供实际操作建议
- 语言通俗易懂

输出格式：
### Topic Fit 评分标准
0分：[定义] - [例子]
1分：[定义] - [例子]
...
5分：[定义] - [例子]

[其他评分标准同理]
```

### Prompt U.2: Troubleshoot Common Issues

```
角色：你是期刊选择顾问，帮助解决选刊过程中的常见问题。
任务：分析我遇到的选刊困难，并提供具体解决方案。

我的问题描述：
[用户描述具体问题，如："找不到合适的期刊"、"所有期刊匹配度都很低"、"时间紧迫但想投好期刊"等]

论文指纹：
[可选，提供 6 行指纹]

请帮我：
1. 诊断问题的根本原因
2. 提供 3-5 个具体可行的解决方案
3. 推荐优先级排序
4. 给出风险提示

输出格式：
### 问题诊断
[分析问题的根本原因]

### 解决方案
1. [方案 1] - [实施步骤] - [预期效果] - [风险]
2. [方案 2] - [实施步骤] - [预期效果] - [风险]
...

### 推荐优先级
[按紧急性和可行性排序]

### 风险提示
[需要注意的潜在问题和规避方法]
```

## Usage Notes

1. **Variable Replacement**: Replace all placeholders in [brackets] with actual content
2. **Context Provision**: Always provide as much context as possible for better results
3. **Iterative Refinement**: Use feedback loops to improve outputs
4. **Fact Checking**: Verify all journal recommendations against real databases
5. **Ethical Guidelines**: Never suggest unethical practices like simultaneous submission
6. **Human Oversight**: Always require human verification of critical decisions
