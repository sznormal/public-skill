# D2 概念辨析型公众号文章模板（一文读懂 N 术语）

> 适用：知识科普 / 概念对比 / "到底差在哪"类文章。目标受众默认「泛老师/学生」小白向；可切换专业向。

## 何时用
- 用户要写含 2~4 个易混术语的科普文（如 harness / MCP / 智能体 / Skill）
- 用户账号已有「概念辨析型」爆款，想复制该配方
- 关键词：一文读懂、到底差在哪、别再混了、是什么、区别、对比

## D2 六要素（缺一个都不完整）
1. **「一文读懂」承诺式标题**（不是"到底有啥区别"式疑问）
2. **多术语并列**（≥3 个比 2 个更强）
3. **每术语标权威出处/时间**（如 Anthropic 2024.11 发布 MCP；DeepSeek 官方开源 Harness）
4. **至少 1 段可运行代码 / 伪代码**（带中文注释，小白也能看懂循环）
5. **层级框架 L1→L2→L3**（从"纯模型"到"加运行时"到"加技能"的进化）
6. **「何时用哪个」选型建议**（按读者场景分流）

## 标题 8 选 1 公式（给用户挑，标✅推荐）
- 一文读懂 X 的「A、B、C、D」：到底差在哪？ ✅
- 别再混了！A、B、C、D，一张图讲清
- 一文读懂：为什么你的 X 只会聊天，别人的能自动干活？
- 老师也能看懂：X 背后的 N 个黑话
- 一文读懂 AI 圈最易混的 N 个词：A / B / C / D
- 给 X 装上"插座(B)"和"手册(C)"，它才变成 A
- 从"问一句答一句"到"自动帮你干活"：X 差了哪几层？
- 小白向：用"XX类比"，5 分钟搞懂 X 的 N 个黑话

## 文章结构（逐段填空）
1. **开场钩子**：用反差/共鸣（"同样用 X，别人能自动干活，你只能查字典"）
2. **一句话结论 + 关系图**：ASCII 层级图，先给全貌
3. **术语逐个拆**：每个 = 说人话定义 + 生活类比 + 权威出处 + 一句记忆点
4. **串起来**：L1/L2/L3 表格（组成 / 能干啥 / 类比）
5. **代码段**：最简 harness loop 伪代码（中文注释，10 行内）
6. **选型建议**：读者对号入座表（需求→用哪层）
7. **小结**：四术语一句话各一句
8. **CTA**：资料包钩子（后台回复关键词领取）+ 留言话题 + 下篇预告

## 类比写法铁律（小白向必守）
- 每个术语必须配一个生活类比（新员工/公司/插座/SOP手册）
- 英文术语首次出现给中文全称
- 关键结论加粗；段落≤5 行；多用小标题
- 避免堆砌定义，先类比再定义

## 权威源要求
- MCP：Anthropic 2024-11 发布，2026 年中 2 万+ 公开服务
- Skill：Anthropic 2025 年底标准化（SKILL.md + 渐进披露）
- Harness：DeepSeek 官方开源 dsh；社区黑话 Agent = Model + Harness
- 任何术语先 WebSearch 核实当下用法再写，避免过时

## 可选扩写模块（按需开启，已验证）

### 模块 A：平台特有概念插播（Expert vs Skill）
适用：文章用到某 AI 平台（如 WorkBuddy）且其有「专家/角色」与「技能」双层概念时。
- 位置：术语逐个拆完之后、L1-L3 串起来之前（作为过渡插播）。
- 写法：用「手册 vs 顾问」类比——
  - Skill ＝ 桌上的"标准作业手册"（封装"怎么做一件具体的事"，照流程跑完）
  - Expert ＝ 请来的"行业顾问"（封装"以什么身份/视角协作"，给方向、做决策）
  - 一句话：Skill 是"把活干完的手册"，Expert 是"给你拿主意的顾问"；一个管怎么做，一个管怎么想。
  - 收尾记忆点：Harness=公司+主管，Skill=墙上 SOP 手册，Expert=外请顾问；三样凑齐 AI 既会干又专业。
- 注意：只讲用户可感知的产品概念，不暴露内部实现/数量。

### 模块 B：主流工具归类表（落地到读者熟悉的产品）
适用：概念讲完后，读者想知道"我用的 XX 工具算哪类"时。
- 位置：代码段之后、选型建议之前（作应用收尾铺垫），或作为收尾应用章节。
- 写法：一张表，列 工具 / 属于哪类 / 一句话说明。常见归类——
  - 纯对话 AI（豆包/新豆包）= L1 纯模型（内置部分 Skill/智能体）
  - 编程型 Harness（Claude Code / Codex / Trae Work）= L2/L3 运行时
  - 完整 Harness 平台（WorkBuddy）= L3 + 内含 Skill + Expert
- 结论句模板："你每天用的这些 AI 助手，绝大多数都不是模型本身，而是包在模型外的 Harness——它已经帮你把插座(MCP)和手册(Skill)都接好了。"

## 文风 DNA（贴合"AI理工派"）
- 中文、口语化、分段清晰、加粗关键句
- 结尾必有互动钩子（之前诊断发现缺互动是瓶颈）
- 可软植入产品（陪伴营/培训/资料包）做转化

## 产出
- 写 `AI理工派_<主题>_一文读懂.md`，开头附「标题候选 8 选 1 + 类型标签 + 建议发布时段」
- 完成后提示用户：可选 1 个标题定稿、补发布时段、加配图
