# 查询工具与核查路径（中文核心专用）

## 工具总表

| 用途 | 入口 | 口径与注意 |
|---|---|---|
| **期刊真伪（唯一权威）** | 国家新闻出版署 `nppa.gov.cn` → 从业机构和产品查询 → 期刊（纸质） | 核验 CN/ISSN、主管与主办单位；**查不到备案 = 非法期刊** |
| 北大核心目录 | 官网 `hxqk.lib.pku.edu.cn`（**只有电话与邮箱，无在线目录**）+ 纸质版《中文核心期刊要目总览》 | 官方联系方式：010-62753195 / hxqk@lib.pku.edu.cn；⚠️ 任何 QQ/微信推销《总览》的均为假冒 |
| CSSCI 目录 | 南京大学中国社会科学研究评价中心官网 | 区分来源刊 / 扩展版 / 来源集刊 |
| CSCD 目录 | 中科院文献情报中心 | 区分核心库 / 扩展库 |
| 科技核心（统计源）目录 | 中国科学技术信息研究所 | 年度更新 |
| **数据库收录核验** | 知网 `cnki.net`、万方 `wanfangdata.com.cn`、维普 `cqvip.com` | 检索**期刊全称**看首页收录；增刊标注 Z1/S1 |
| 期刊官网 / 征稿启事 | 各刊独立官网、官方公众号 | 找**年度重点选题**与栏目介绍，按选题投命中率更高 |

> 入口若失效，用搜索引擎搜工具全名直达官方站点；**不要凭记忆复述域名，不要点带"广告"标签的搜索结果。**

## 使用顺序（中文选刊专用五步）

1. **国家新闻出版署** → 定"是不是真刊"（否决项）。
2. **三大数据库** → 定"是否正常收录正刊正期"（识别假刊/套刊/增刊）。
3. **对应核心目录官方渠道** → 定"是哪个体系、哪个版本"。
4. **期刊官网 / 征稿启事** → 定"栏目与当前偏好"。
5. **预警名单** → 定"有没有被预警/整改"。

## 三库交叉验证的必要性

**任何单一数据库都可能被误判，必须交叉：**

- 知网收录 ≠ 一定是真刊（增刊也进知网）。
- 维普收录 ≠ 知网收录（同刊可能只在其中一库）。
- 三库均查不到 → 高度警惕。
- 三库收录但**版本是增刊** → 成果无效。

**判定示例（写入排雷表的标准写法）**：

```text
真伪：三号齐全，CN 11-xxxx/N 备案与版权页一致（国家新闻出版署，2026-10-02 查询）
收录：知网收录正刊正期，2025 年共出版 6 期；未见 Z1/S1 增刊收录
目录：北大核心 2023 版在目录内（来源：<已记来源>，2026-10-02 查询）
栏目：设"教学研究"栏目，近三年稳定发稿（来源：期刊官网征稿启事，2026-10-02）
版面费：待核（需以官网或录用通知为准）
```

未写来源与日期的字段，一律视为"待核"，**不得进入评分卡计算**。

## 排雷时的三条硬纪律

1. **不以刊名判断**——必须以 CN 号 + 数据库收录为识别依据（同名不同刊、增刊套刊满天飞）。
2. **不以"有人说"为据**——期刊层级必须以官方目录为据，坊间说法（"这本算核心吧"）一律不采信。
3. **不代替用户查证认定口径**——单位认哪个体系、哪个版本，只能由用户向人事处/科研处/研究生院确认。
