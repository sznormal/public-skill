# 政策依据与建设脉络框架

## 核心政策文件

### 1. 教育强国建设规划纲要

**关键要点**：
- 推进教育数字化转型升级
- 构建产教融合的职业教育体系
- 培养高素质技术技能人才

**对课程建设的指导**：
- 课程必须融入数字化教学资源（虚拟仿真、在线平台、AI辅助）
- 课程内容必须对接产业实际需求
- 培养目标定位为"高素质技术技能人才"而非学术型人才

### 2. 新双高计划

**五金建设**：

| 金项 | 内涵 | 课程中的体现 |
|------|------|------------|
| 金专业 | 专业群对接产业链 | 课程定位对接区域产业集群 |
| 金课程 | 课程内容对接岗位标准 | 项目化课程结构、岗课融通 |
| 金教材 | 新形态教材 | 活页式+工作手册式+数字教材 |
| 金师资 | 双师型教师团队 | 三主编制度（企业+学校+行业） |
| 金基地 | 实训基地建设 | 虚拟仿真+企业实训基地 |

**六维度评价体系**：
1. 思政引领度 — 课程思政融入程度
2. 需求匹配度 — 与产业需求的匹配程度
3. 条件支撑度 — 师资、设备、基地支撑能力
4. 目标可达成度 — 学生能力目标的可实现性
5. 政策保障度 — 制度、经费、组织保障
6. 成果贡献度 — 人才培养成果与社会贡献

### 3. 职教司一号文件

**能力图谱结构**：

```
课程
├── 项目（对应岗位场景）
│   ├── 任务（对应工作任务）
│   │   ├── 工作步骤
│   │   │   ├── 技能点（会操作）
│   │   │   ├── 知识点（懂原理）
│   │   │   └── 素养点（有态度）
│   │   └── ...
│   └── ...
└── ...
```

**能力图谱设计原则**：
- 每个项目对应一个明确的岗位角色
- 每个任务对应一个真实的工作任务
- 每个工作步骤分解为技能点+知识点+素养点
- 技能点强调"会做什么"
- 知识点强调"为什么这样做"
- 素养点强调"应该怎样做"（职业素养、工匠精神、安全意识等）

## 通用建设脉络框架

综合三份政策文件，提炼出五个维度的通用建设脉络：

### 维度一：能力图谱
- 来源：一号文件
- 应用：课程结构按"项目→任务→工作步骤→技能点/知识点/素养点"设计
- 关键：岗位场景驱动，不以技术功能为组织线索

### 维度二：五金建设
- 来源：新双高计划
- 应用：课程设计同时考虑专业定位、课程内容、教材形态、师资团队、实训基地
- 关键：教材采用新形态（活页式+工作手册式+数字教材）

### 维度三：岗课赛证融通
- 来源：一号文件 + 新双高计划
- 应用：课程内容对接岗位标准、竞赛标准、证书标准
- 关键：每个项目必须有"岗课赛证对接表"

### 维度四：三主编制度
- 来源：新双高计划金师资
- 应用：教材由企业技术专家+学校专业带头人+行业权威专家共同主编
- 关键：企业技术专家确保内容对接产业实际

### 维度五：数字化资源
- 来源：教育强国纲要
- 应用：虚拟仿真、在线微课、AI辅助教学工具
- 关键：先虚拟后实物的开发范式，AI工具融入教学过程

## 课程思政融入要求

根据政策要求，课程思政不是"贴标签"，而是"有机融入"：

| 思政维度 | 融入方式 | 示例 |
|----------|----------|------|
| 工匠精神 | 通过操作规范和质量标准 | 代码规范检查、编译0 warning要求 |
| 安全意识 | 通过安全操作规程 | 数据备份、权限管理、操作前确认 |
| 创新思维 | 通过问题解决和优化 | 避坑指南中的问题分析过程 |
| 团队协作 | 通过项目分工 | 团队项目、代码评审 |
| 职业道德 | 通过职业场景设计 | 保密意识、知识产权、责任意识 |

每个任务的"思政点"文件应包含3-4个思政融入点，每个融入点含：
- 思政主题（如"工匠精神"）
- 教学引导（如何在教学中自然引入）
- 价值映射（与专业技能的关系）
