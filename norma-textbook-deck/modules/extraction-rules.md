# 教材 → 课件 · 抽取规律（七条）

> norma-textbook-deck · Module
> 来源：2026-09-16 解析《Python 机器人基础编程（AI素质版·学生版）》第1章 PPT（26 页 pptx）逆向归纳，
>      并在第10章（25 页）实操复刻验证。这七条就是本课程课件风格规律，新增章节照此执行。

---

## 规律 1 · 一页一个点

每页只讲一个知识点/一个环节，不堆砌。教材里一个小节通常对应 1–3 页 PPT。

## 规律 2 · 固定板块必占页

教材中的这些板块**必然**有独立页面，不可省略：

| 板块 | 典型版式 | 备注 |
|---|---|---|
| 封面 | title-cover | 章节名 + 副标题 + 配图 |
| 本章导航/路线图 | grid numbered-cards | 5 步左右 |
| 引题（想一想/为什么） | two-column question-cards | 制造认知冲突 |
| 学习目标 | grid icon-cards | 语法/硬件/价值三卡片 |
| 核心概念 | concept / diagram | 每个工具一页 |
| 项目实战（流程图） | flow / diagram | mermaid 重绘 |
| 项目实战（逐行解析） | concept 逐步骤 | 每步一页或合并 |
| 课程思政小知识 | timeline 3-node | 独立页 |
| AI 透视窗 | diagram / concept | 独立页（用纯图形，不生图） |
| AI 素养贴士 | grid 3-cards | 独立页 |
| 工程视角 | concept assert-demo | 独立页 |
| 术语解析 | compare 两栏 | 独立页 |
| 常见报错与调试 | compare symptom-cure | 独立页 |
| 本章小结 | grid 4-cards | 独立页 |
| 下章预告 + 思政寄语 | conclusion quote | 末页 |

## 规律 3 · 代码零外贴

**PPT 正文不出现整段代码**。代码全部抽到 `<章名>_实例代码.txt`；
PPT 上只把代码的"语义角色"图表化（见 `stages/p3-page-closure.md` §二）。
必要的一两行符号性提示可以有，但不给完整代码块。

## 规律 4 · mermaid → 纵向/横向流程图

教材里的 `mermaid flowchart` **重绘为节点 + 箭头**的图形：
- LR（横向）→ 三段/四段横向流程
- TD（纵向）→ 纵向节点 + 竖线箭头
- 不贴 mermaid 源码，不贴 mermaid 渲染图（风格不统一）。

## 规律 5 · 表格原样搬

教材里的对比表、指令表、测试用例表**原样转成 PPT 表格**：
- 用形状绘制（表头行 + 条纹行 + 竖分隔线），而非 `<table>` 元素，确保样式可控。
- 表头用主强调色半透明底，行交替用极低透明度白底。

## 规律 6 · 课后习题不上 PPT

`10.9 课后习题` 等所有习题板块**不进课件**——习题属于练习册/作业，不属于课堂讲授内容。
末尾页可以一句话提示"课后记得做"，但不铺开题目。

## 规律 7 · 统一骨架

每页（除封面/末页）遵循同一骨架，保证风格一致：

```
小标签（英文，y≈46，13px，主强调色）
主标题（y≈70，30px bold，白色）
导读（y≈120，15px，次要色）
主体内容区（y≈156 起）
页脚（y≈494，11px：左"第N章 · 章名"，右页码）
讲稿 note（3–5 句）
```

---

## 附 · 标准教学弧线（排页顺序）

```
封面
→ 本章导航（五步路线图）
→ 引题（想一想：为什么要学）
→ 学习目标（语法/硬件/价值）
→ 项目预告
→ 核心概念 1..N（每个工具一页）
→ 项目实战：整体流程 / 逐行解析
→ 课程思政小知识
→ 测试用例 / 仿真运行
→ 常见报错与调试
→ 硬件增强版（若有，配图页）
→ AI 透视窗（多页）
→ AI 素养贴士
→ 工程视角（测试思维）
→ 术语解析
→ 本章小结
→ 下章预告 + 思政寄语
```

第10章实操共 25 页，即按此弧线排布。
