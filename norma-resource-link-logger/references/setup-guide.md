# 配置指南

本 Skill 依赖金山文档连接器写入在线表格，依赖公网抓取链接元数据。首次使用前完成一次配置即可。

## 金山文档连接器（依赖 id：kdocs-mcp）

- **用途**：读取资源库现有内容做查重、追加新行、回读验证。
- **支撑功能**：查重读取、写入新行、回读验证。
- **必需性**：必需。未连接时本 Skill 停止写入，不会假装成功。
- **官方主页**：https://www.kdocs.cn
- **官方文档**：https://www.kdocs.cn
- **登录网址**：https://www.kdocs.cn（浏览器内完成扫码或账号登录）
- **下载地址**：不需要安装客户端，网页版即可。
- **凭据入口**：不需要手动创建 Token 或 API Key；由 WorkBuddy 连接器在浏览器授权后托管。
- **控制台路径**：WorkBuddy 左侧「连接器」→ 金山文档 → 连接。

### 配置步骤

1. 打开 WorkBuddy 左侧连接器管理页，找到金山文档连接器。
2. 点击连接，浏览器跳转到金山文档登录页，完成扫码或账号登录。
3. 授权完成后回到 WorkBuddy，确认连接器状态显示为已连接。
4. 在会话中确认能搜到 `mcp__kdocs__sheet.get_typed_value` 工具，即视为就绪。

### 权限与最小化

只使用表格读写能力。不要授予通讯录、消息发送、云盘全量删除等无关权限。

### 凭据存储

凭据由 WorkBuddy 连接器凭据管理保存，不写入 Skill 文件、脚本、命令历史和对话记录。任何时候都不在对话中回显完整凭据。

### 验证方式

搜索到 `mcp__kdocs__sheet.get_typed_value` 并对目标表格做一次单格读取，返回表头文本即为通过。

### 实测说明（2026-09-09）

本机金山文档连接器由 WorkBuddy 连接器平台托管，**不写入** `~/.workbuddy/mcp.json`。因此不能靠配置文件判断注册状态，必须以宿主实际的最小只读调用结果为准。环境检查脚本已按此设计，判据是探测结果而非配置文件。

### 过期、权限不足与额度

- 授权过期：连接器状态变为未连接或调用返回鉴权错误。重新在连接器管理页连接即可。
- 权限不足：确认登录的账号对目标表格有编辑权限。
- 限频或熔断：按 SKILL.md 的限频规则暂停调用，等待恢复时间，不要连续重试。

### 轮换与撤销

在 WorkBuddy 连接器管理页断开金山文档连接即撤销授权；账号侧可在金山文档账号的授权管理中移除该应用。撤销后本 Skill 停止写入并提示重新连接。

## 公网访问（依赖 id：public-network）

- **用途**：抓取 GitHub 仓库、论文页、视频页和文章页的元数据。
- **支撑功能**：抓取链接元数据。
- **必需性**：可选。不可用时链接照常收录，主要作用标记为待补充。
- **官方主页**：https://github.com
- **官方文档**：https://docs.github.com
- **凭据入口**：不需要。全部为匿名只读公共接口。

### 配置步骤

1. 确认本机可访问公网，公司网络或代理未拦截目标站点。
2. GitHub 元数据统一走 `api.github.com`，不要走 `raw.githubusercontent.com`。
3. 无需配置任何密钥。

### 验证方式

```bash
curl -s -o /dev/null -w "%{http_code}" https://api.github.com
```

返回 `200` 即为可用。

### 失败处理

网页抓取失败或页面需要登录才能查看时，资源名称用域名加路径末段推断，主要作用填「（自动抓取失败，待补充）」，分类选其他，链接仍照常收录，等用户提供说明后回填。
